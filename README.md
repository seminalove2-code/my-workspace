# my-workspace

Claude와 함께 쓰는 작업 저장소입니다.

## 1. 솔루션키 지식창업 시스템

전자책 7권을 Claude가 대신 읽고 정리해 두었습니다. 책을 읽을 필요 없이, claude.ai/code에서 이 저장소로 세션을 열고 말만 하면 됩니다.

**처음이라면:** "시작하자" 라고 말하세요. 몇 가지만 물어보고 오늘 할 일 하나를 알려 줍니다.

| 이렇게 말하면 | 해 주는 일 | 근거 책 |
|---|---|---|
| "다음 뭐 해?" | 진행 상황 보고 오늘 할 일 1개 | 전체 |
| "뭐 팔지 찾아줘" | 내 경험으로 팔릴 주제 6개 + 점수 + 제목·목차·가격 | 8번 주제 발굴기 |
| "오늘 스레드 글 써줘" | 후킹 문장 + 저장 유도 구조 글 2개 | 3·7번 |
| "프로필 만들어줘" / "오픈채팅 문구" | 프로필 3단계, 7일 마감 퍼널 메시지 | 3·7번 |
| "전자책 만들어줘" | 인터뷰 → 목차 → 챕터 → 워드 파일 | 3번 6단계 |
| "상세페이지 만들어줘" | 첫 화면에 '무엇이 달라지는지' 넣은 페이지 | 4번 40분 공식 |
| "크몽에 올릴 거 준비해줘" / "왜 안 팔려?" | 제목·썸네일·가격 사다리·후기 문구·진단 | 6번 0건 탈출 |
| "웰컴 메일 써줘" | 스티비 4단계, 웰컴 3통, 제목 A/B | 5번 |
| "자동화 세팅해줘" / "주간 마감" | 자리 비움 5단계, 장애 대응, 회고 | 10번 |

### 폴더 구조
| 경로 | 내용 |
|---|---|
| `me/profile.md` | 내 정보·페르소나 (Claude가 채워 감, 직접 고쳐도 됨) |
| `me/progress.md` | 로드맵 진행 상황과 기록 |
| `playbooks/` | 책별 정리본 (공식, 프롬프트 원문, 체크리스트, 수치) |
| `.claude/skills/` | 말 한마디로 실행되는 스킬들 |
| `output/` | 만들어진 결과물 (글, 전자책, 상세페이지, 메일 등) |
| `tools/팔리는-주제-발굴기.html` | 8번 원본 도구 (claude.ai에 올려 아티팩트로 써도 됨) |

## 2. 유튜브 영상 학습

- **영상 학습시키기**: "이 영상 학습해줘 https://www.youtube.com/watch?v=..."
  - 유튜브 접속이 막혀 있으면, 유튜브에서 `...더보기 → 스크립트 표시`로 자막을 복사해 함께 붙여넣으세요.
- **배운 내용 활용하기**: "지금까지 학습한 내용 바탕으로 쇼츠 대본 아이디어 5개 줘"
- 정리본은 `notes/youtube/`, 형식은 `.claude/skills/youtube-study/SKILL.md`.
