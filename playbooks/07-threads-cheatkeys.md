- 원본: 7번 / 21페이지 (PDF)
- 성격: 본편 <자본 0원·팔로워 0명으로 통장에 1억 찍은 클로드×스레드 AI 지식창업 치트키>의 부록 9종 모음. 본편 챕터(챕터 3 페르소나 브리핑, 챕터 5 계정 정지, 챕터 6 고객의 진짜 문제)를 참조하지만 본편 본문은 이 파일에 없음.

## 한 줄 요약
클로드에 [페르소나/독자/경험담/문체/금지어] 5요소로 브리핑해 스레드 글을 매일 2개 올리고(후킹 5유형 실험), 무료 리드마그넷 → 카카오 오픈채팅(7일 마감효과) → 전체태그 판매 → 결제 자동화 → 컨설팅/VOD 확장으로 가는 12주 로드맵.

## 핵심 공식 / 프레임워크

### 1) 클로드 브리핑 5요소
- 페르소나 · 독자 · 경험담 · 문체 · 금지어 — 이 다섯 가지를 채워 브리핑. "브리핑을 대충 넘기면 결과물도 딱 그만큼만 나옵니다."
- 기본형: "너는 [분야] 선배야. 독자는 [타겟]이고, 오늘 경험은 [한 줄]이야." (+ 문체 지정)
- 페르소나는 브리핑 맨 앞에 붙인다(부록 06의 10가지 중 선택).

### 2) 후킹 문장 5유형
- 질문형 · 반전형 · 숫자형 · 경고형 · 고백형 → 하루씩 돌아가며 써서 반응 비교, 좋은 유형 찾을 때까지 순환.
- 같은 경험도 후킹 유형만 바꿔 여러 각도로 재활용(반응 좋았던 이야기는 2~3번 우려먹을 가치).

### 3) 판매 퍼널: 무료 자료 → 신뢰 → 판매
- 스레드(노출) → 무료 리드마그넷(20페이지 내외) → 카카오톡 오픈채팅(입장 안내, 1~7일차 안내 메시지, 7일 마감효과) → 전체태그 판매 공지 → 결제 자동화(자동 다운로드 링크) → 컨설팅/VOD 확장.

### 4) 스레드 운영 원칙
- 스레드는 팔로워 기반이 아니라 관심사(노출) 기반 알고리즘 → 신생 계정도 노출 가능. 초반엔 팔로워 수보다 하루 업로드 횟수와 후킹 문장의 질.
- 계정 분산: 메인 + 서브 계정(정보형). 메인·서브 업로드 간격 2시간 이상. (원고 예시 2: 계정 3개 분산 운영)

### 5) 클로드 대화 원칙 (부록 04)
- 답을 바로 요구하지 말고, 먼저 나에게 질문하도록 요청하거나 구체적 상황을 짚어 대화.
- 막연한 "전체적으로 다시 짜줘" 대신 끊기는 지점·아쉬운 점을 구체적으로 짚기.

### 6) 세일즈 문구 원칙 (부록 08)
- "내가 무엇을 아는가"가 아니라 "고객이 무엇을 얻는가"를 구체적으로: 구체적 시간 + 결과물 + 숫자 + 형식/기간.

### 7) 계정 정지 대응 5단계 (부록 05)
1. 침착하게 상태 확인: '그림자 정지'(로그인 O, 노출 X) vs '완전 정지'(로그인 X) — 대응이 다름
2. 최근 활동 되짚기: 반복 댓글, DM 과다 발송, 짧은 업로드 간격 해당 여부
3. 공식 이의제기 절차: 메타 공식 이의제기(문의)로 소명. 감정적 문구 X, 어떤 활동을 했는지 담담하게
4. 백업 채널로 즉시 전환: 서브 계정·오픈채팅방으로 안내 전환, 유입이 끊기지 않게
5. 복구 안 됐을 때의 마음가짐: 콘텐츠·노하우는 사라지지 않음, 다음 계정을 더 안전하게 운영하는 밑거름

## 실행 절차 (단계별)
[사용자] = 사용자 경험·계정 작업 필요, [Claude] = Claude가 생성 가능

1. 세팅 (1주차)
   1. [사용자] 분야, 타겟 독자, 원하는 톤, 금지어를 알려주기.
   2. [Claude] 브리핑 템플릿 [페르소나/독자/경험담/문체/금지어] 완성 → 노션 저장용으로 제공. 페르소나는 부록 06에서 선택.
   3. [사용자] 스레드 프로필 사진·한줄소개·링크 3가지 정리 ([Claude] 한줄소개 초안 가능).
2. 매일 글쓰기 (2주차~)
   1. [사용자] 오늘의 경험 한 줄 제공. 소재가 없으면 [Claude]가 부록 04 예시 1처럼 먼저 질문해 소재 끌어내기.
   2. [Claude] 브리핑 기반 스레드 원고 작성(부록 02 구조: 후킹 → 실패담/경험 → 지금의 방식/교훈 → 행동 촉구 또는 질문 마무리).
   3. 하루 2개(출근길·퇴근 후), 정보형·공감형·스토리형 골고루.
3. 후킹 실험 (3~4주차)
   1. [Claude] 같은 소재로 질문형·반전형·숫자형·경고형·고백형 버전 생성 → 하루 한 유형.
   2. [사용자] 유형별 좋아요·저장·댓글 기록 → [Claude] 상위 3개 첫 줄 패턴 분석 → 다음 주 그 패턴으로 3개+.
4. 계정 분산 (5주차): 서브 계정 세팅, 정보형 콘텐츠, 메인과 2시간 이상 간격.
5. 리드마그넷·오픈채팅 (6~7주차)
   1. [Claude] 20페이지 내외 무료 자료 주제 후보·목차 → [사용자] 1개 확정, 본인 경험 제공.
   2. [Claude] 오픈채팅방 입장 인사말·안내 문구, 1~7일차 안내 메시지(7일 마감효과) 초안. (책에 문구 원문은 없음 — 생성 필요)
   3. [사용자] 오픈채팅 개설, 스레드 링크 연결, 메시지 예약.
6. 첫 유료 상품 (8~9주차)
   1. [사용자] 고객의 "오늘 밤 당장 해결하고 싶은 문제" 하나 → [Claude] 한 문장 정의.
   2. [Claude] 20~30페이지 전자책 목차 초안 → 챕터별 브리핑 후 집필(사용자 경험 반영). 이번 주 안에 출시.
   3. [Claude] 판매 페이지 문구(부록 08 Before/After 원칙), 가격 책정 논의.
   4. 출시 전 부록 07 최종 점검 12개 확인.
7. 판매 (10주차): [Claude] 전체공지(전체태그) 문구 — 부담스럽지 않으면서 행동 유도. 구매자 피드백 3건+ 수집 → 즉시 개선. CS 답변 템플릿(부록 04 예시 4).
8. 결제 자동화 (11주차): [사용자] 결제 자동화 플랫폼(페이앱, 아임포트 등) 선정, 자동 다운로드 링크 테스트. 하루 2~3건 넘으면 필수.
9. 확장 (12주차): [Claude] 컨설팅 상품 문구 초안, VOD 커리큘럼 5~7챕터 재구성. 이후 부록 09 확장 아이디어.


### 부록 04. 클로드 대화 실전 예시 (사용자 발화 원문)
예시 1 — 스레드 글감이 안 떠오를 때 (클로드가 먼저 질문하게 유도)
```
저: 오늘 딱히 특별한 일이 없었는데, 그래도 스레드에 뭐라도 올리고 싶어. 최근 일주일 사이에 AI 관련해서 겪었던 소소한 일들 정리하는 걸 도와줘. 나는 AI 부업 콘텐츠를 만드는 사람이고, 독자는 부업에 관심 있는 30대 직장인이야.
```
→ 기대 반응(책): 클로드가 "최근에 클로드나 다른 AI 도구를 써서 시간을 아낀 경험이 있나요?", "반대로 AI를 써봤는데 기대만큼 안 됐던 경험은요?"처럼 되물음. 핵심: 답을 바로 요구하지 않고 먼저 나에게 질문하도록 요청.

예시 2 — 전자책 목차가 막힐 때
```
저: 전자책 목차를 짜고 있는데, 8개 챕터 중에 중반부 흐름이 계속 어색해. 삽질담에서 역전의 순간으로 넘어가는 게 뚝 끊기는 느낌이야. 자연스럽게 이어지도록 다시 배치해줘.
```
→ 기대 반응: 삽질담 마지막 챕터와 역전 첫 챕터 사이에 심리적 다리 역할의 문장·소제목 제안.

예시 3 — 판매 문구가 밋밋할 때
```
저: 이 상세페이지 문구가 너무 뻔한 것 같아. "AI로 수익화하는 법을 알려드립니다" 이런 식인데, 임팩트가 없어. 고객이 지금 느끼는 답답함을 자극하는 방향으로 다시 써줘.
```
→ 기대 반응: "이 고객은 이미 AI를 써봤는데 결과가 안 나온 사람인가요, 아니면 아예 시작도 못 한 사람인가요?" 같은 질문 후 재작성. 결과가 아쉬우면 구체적으로 무엇이 아쉬운지 짚어 재요청.

예시 4 — CS 답변 템플릿이 필요할 때
```
저: 구매자들한테 자주 같은 질문(환불, 사용법, 재구매 할인)을 받는데 매번 다시 쓰기 귀찮아. 자주 나오는 질문 3가지에 대한 답변 템플릿을 정중하면서도 딱딱하지 않게 만들어줘.
```
→ 기대 반응: 고객 감정을 먼저 짚고 인정한 뒤 안내 사항 전달 순서. 노션 저장, 이름·세부만 바꿔 재사용.

예시 5 — 반응 좋았던 글 재활용
```
저: 지난주에 올린 '팔로워보다 노출' 글 반응이 좋았어. 같은 메시지를 이번엔 숫자로 시작하는 문장으로 다시 써보고 싶은데, 똑같은 글처럼 보이지 않게 해줘.
```
→ 기대 반응: 메시지는 유지, 후킹 유형과 문단 순서만 변경.

### 부록 06. 페르소나 브리핑 프롬프트 10선 (브리핑 맨 앞에 붙이기)
1. AI 부업 선배
```
"너는 AI 부업 3년차 선배야. 왕초보 직장인한테 쉽게 설명해주는 게 특기야. 실패담도 솔직하게 섞어서 말해줘."
```
2. 실전 경험 코치
```
"너는 결과로 증명한 실전 코치야. 이론보다 지금 당장 써먹을 수 있는 행동 하나를 항상 먼저 제시해줘."
```
3. 다정한 언니/형 톤
```
"너는 다정하지만 할 말은 하는 친한 언니(형)야. 독자를 다그치지 않고, 공감하면서도 명확한 방향을 제시해줘."
```
4. 데이터 분석가
```
"너는 숫자와 데이터로 설득하는 분석가야. 감정적인 표현보다 구체적인 수치와 근거를 우선해서 설명해줘."
```
5. 솔직한 실패담 공유자
```
"너는 화려한 성공보다 실패와 시행착오를 먼저 솔직하게 꺼내는 사람이야. 그 실패에서 배운 점을 중심으로 이야기해줘."
```
6. 바쁜 직장인 공감형
```
"너는 본업과 부업을 병행하는 직장인이야. 시간이 없는 사람도 따라 할 수 있게, 최소한의 행동만 알려줘."
```
7. 엄격한 멘토
```
"너는 핑계를 허용하지 않는 엄격한 멘토야. 다정함보다 명확한 방향 제시와 행동 촉구를 우선해줘."
```
8. 초보자 눈높이 선생님
```
"너는 전혀 모르는 사람도 이해할 수 있게 설명하는 선생님이야. 전문용어는 반드시 풀어서 설명해줘."
```
9. 유머러스한 동료
```
"너는 가볍고 유머러스한 톤으로 이야기하는 동료야. 무겁지 않게, 웃으면서 읽을 수 있도록 써줘."
```
10. 신뢰감 있는 전문가
```
"너는 오랜 경력을 가진 신뢰감 있는 전문가야. 과장 없이 담백하게, 근거를 갖춘 조언을 해줘."
```

- 클로드에 "대본 써줘"/"글 써줘"만 입력 → 뻔한 결과(3주 좋아요 1개). → 5요소 브리핑.
- 브리핑 대충 → 결과물도 그만큼.
- 초반 팔로워 숫자에 집착 → 업로드 횟수와 후킹 질에 집중. 2주차는 숫자 대신 업로드 수만 세며 버티기.
- 완벽한 100페이지 집착 → 20페이지라도 빨리 출시, 반응 보고 수정.
- 링크만 걸면 팔린다는 착각 → 무료 자료 → 신뢰 → 판매 순서.
- 막연한 수정 요청("전체적으로 다시 짜줘") → 끊기는 지점을 구체적으로.
- 첫 결과물 마음에 안 든다고 포기 → 아쉬운 점 짚어 재요청.
- 같은 이야기 반복이 민망 → 실제로 알아채는 사람 거의 없음.
- 수동 발송 지속 → 하루 2~3건 넘으면 시간 손해, 결제 자동화.
- 계정 정지 예방: 완전 예방 불가. 반복 댓글·DM을 짧은 시간에 몰아 보내지 않기, 업로드 간격 지나치게 좁히지 않기. 서브 계정은 메인이 자리 잡기 시작할 때 미리(문제 생긴 뒤면 늦음). 이의제기 결과 나빠도 담담하게 보완 재시도 + 백업 채널 병행.
- 예약 시간대를 너무 넓게 열기 → 관리 번거로움.

## FAQ 요점
- 계정 정지 예방법? → 완전 예방은 어려움. 반복 댓글·DM 몰아 보내기 금지, 업로드 간격 너무 좁히지 않기, 서브 계정 미리 준비.
- 이의제기 실패 시? → 낙담 말고 담담한 톤으로 소명 보완해 재시도, 백업 채널 운영 병행.
- 도구 다 필요? → 지금 단계에 맞는 것부터. 클로드+스레드면 시작 가능.
- 부록 읽는 법? → 순서대로 또는 막힌 문제 하나만 골라서. 읽고 넘기지 말고 그 자리에서 하나만이라도 실행.
