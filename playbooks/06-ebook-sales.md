# 왜 내 전자책만 안 팔릴까?: 억대 실전 판매 치트키
- 원본: 6번 / 87페이지 (PDF)
- 판매 채널: 크몽(신규 확보·검증) → 래피드(이식·재구매·자동화)
- 주의: 이 책에는 AI 프롬프트 원문이 없음(AI 활용 "순서"만 제시). 후기 요청/재구매 메시지도 전문 템플릿은 없고 핵심 문구 조각만 있음 — 아래에 그대로 표기.

## 한 줄 요약
콘텐츠가 아니라 "보여주는 방식"이 문제다 — 누군가 물어본 지식을 발굴하고, 잘 팔리는 경쟁 상품 20개를 뜯어 검증하고, 목차 미리보기를 전제로 제작하고, "검색어+구체적 결과" 제목·핵심문구+신뢰숫자 썸네일·낮은 시작가로 노출하고, 크몽에서 검증된 것만 래피드로 이식하는 "0건 탈출 공식(발굴→검증→제작→노출→확장)".

## 핵심 공식 / 프레임워크

### 1) 0건 탈출 공식 5단계 (사이클)
| 단계 | 핵심 기준/행동 | 입력 | 출력 |
|---|---|---|---|
| ① 발굴 | 단 하나의 기준: "내가 최근에 누군가에게 설명해준 적 있는 것인가?" (후배·친구가 "어떻게 하는 거예요?"라고 물은 것 = 수요 있음) | 최근 한 달 내 받은 질문들 | 주제 후보 3개 이상 → 1개 선정 |
| ② 검증 | 비슷한 상품 찾아 제목·구성 분석. "이미 팔리고 있다면 오히려 좋은 신호"(아무도 안 파는 주제 = 수요 없을 수도) | 크몽·래피드 각 10개+ (3장에서는 20개) | 스프레드시트: 제목 구조, 가격대, 상세페이지 순서, 후기 내용 |
| ③ 제작 | 목차부터 먼저 짜고, 목차 각 항목을 미리보기 이미지로 공개할 걸 염두에 두고 쓰기. 순서: AI로 목차 초안 → 내 경험·디테일 채우기 → 전체 문장 톤 정리 | 주제 + 내 실제 경험(숫자·감정·에피소드) | 원고(경험 비중 30% 이상, 톤 통일) |
| ④ 노출 | 제목 = "검색어 + 구체적 결과". 썸네일 = 핵심 문구 + 신뢰 숫자. 가격 = 낮게 시작, 후기 5개+ 쌓이면 단계적 인상 | 원고 | 제목 후보 3개, 썸네일, 목차 미리보기 이미지 3장, 시작 가격 |
| ⑤ 확장 | 한 플랫폼에서 검증된 상품만 다른 플랫폼으로 이식(크몽 → 래피드). 동시 신규 출시 금지 | 크몽 후기 10개+, 판매 20건+ | 래피드 등록(카테고리·태그·톤 재조정) |
- 효과: 책 1권 제작 40시간 → 8시간 (시리즈 내에서는 더 단축).
- 한 사이클(발굴→확장) 약 3~4주.

### 2) 경쟁 상품 분석에서 찾은 4가지 패턴 (3장)
1. 제목 구조: "검색어 + 구체적 결과" (예: "엑셀 몰라도 3일 만에 자동화 시트 만들기"). 상품명 자체가 광고 카피.
2. 목차 미리보기: 상세페이지에 목차를 이미지로 공개. "뭐가 들어있는지 정확히 알아야 신뢰하고 산다."
3. 후기의 양과 타이밍: 후기가 구매 직후 며칠 안에 몰려 있음 → 판매자가 후기 요청 메시지를 보냄.
4. 상세페이지 순서: '이런 고민 있으시죠?' → '이렇게 해결됩니다' → '목차 미리보기' → '후기' → '구매 시 혜택'.

### 3) 안 팔리는 이유 4가지 점검 (2장)
1. 제목이 내가 아는 용어(보고서 언어)가 아니라 사람들이 실제로 검색하는 말인가
2. 가격이 아니라 신뢰를 줄 근거(후기, 미리보기)가 있는가 — 가격 인하로는 해결 안 됨(15,000원→5,000원 내려도 0건)
3. 썸네일이 정보 나열이 아니라 한눈에 들어오는 핵심 메시지인가
4. 상세페이지 첫머리에 "이건 당신을 위한 상품입니다"(누구를 위한 상품인지)를 밝혔는가 — 사람들은 3초 안에 "내 얘기인가?" 판단

### 4) 래피드 운영 4원칙 (6장 — 크몽과 다른 점)
1. 노출 로직: 신규 상품 초반 며칠의 조회수·찜·문의를 노출 순위에 크게 반영(크몽은 누적 판매량이 오래 반영되는 느낌). → 업로드 직후 3일 = 골든타임: 지인에게 링크 공유·솔직한 의견 요청, 관련 커뮤니티에 자연스럽게 소개, 문의에 최대한 빠르게 답변.
2. 카테고리: 래피드는 더 세분화 → 정확한 하위 카테고리 선택(대충 상위 카테고리 = 검색 자리 포기).
3. 태그: 개수 제한 → 검색량 많은 핵심 키워드 1개 + 경쟁 적은 롱테일 키워드 2~3개. (예: "보고서 작성"만이 아니라 "보고서 검토 체크리스트"도)
4. 상세페이지: 래피드 이용자는 끝까지 스크롤하는 비율이 높은 체감 → 후반부에 "실제 구매자 후기 스크린샷" 추가. (크몽은 초반 임팩트, 래피드는 끝까지 읽었을 때의 신뢰감)
- 래피드 재구매 비율이 크몽보다 약 15%p 높음 → 신규 확보는 크몽, 재구매·후속 상품 판매는 래피드.

### 5) 래피드 자동화 시스템 4요소 (7장)
1. 콘텐츠 제작 표준화: AI 도구로 목차 구조 초안 → 각 항목에 실제 경험·디테일 채우기 → 전체 문장 톤 정리.
2. 업로드 체크리스트 표준화: 제목 후보 3개("검색어+구체적 결과"), 썸네일 문구 톤 고정(핵심 문구+신뢰 숫자), 목차 미리보기 이미지 항상 3장 공개.
3. 후기 요청 자동화: 구매 알림 → 미리 만든 정중한 템플릿 메시지 곧바로 발송. 이름·상품명만 바꾸고 틀은 유지.
4. 재구매 유도 루틴: 구매 후 일정 기간 지나면 관련 다른 상품을 "이런 것도 있으니 참고하세요" 톤으로 안내.
- 예외(구매자 질문·특이사항)는 반드시 직접 답장. "자동화는 반복을 덜어내는 것이지 사람의 온도를 없애는 게 아니다."
- 결과: 래피드 자동화만으로 1,000만원 매출.

### 6) 단계적 가격 사다리 (8장)
| 조건 | 가격 |
|---|---|
| 첫 등록(목표: 후기·판매 이력) | 5,000원 (사례에서는 5,900원; FAQ "5천원 내외") |
| 후기 5개 | 9,900원 |
| 후기 10개+ | 14,900원 |
| 이후 반응 꾸준 | 19,900원 |
- 인상 기준: "내 마음"이 아니라 신뢰 지표 — 후기 일정 수 이상 + 평점 4.5 이상 유지. 후기 부족 상태 인상 → 반응 즉시 꺾임.
- 프로모션: 신상품 등록 시 짧은 기간 소폭 할인 → 래피드 프로모션 노출 영역 진입(할인보다 조회수 증가 효과가 큼).
- 번들: 비슷한 주제 2~3권 묶어 개별 구매보다 조금 저렴하게 → 객단가↑, "이득 보는 느낌".
- 시즌: 연초 = 자기계발·새로운 시작 / 방학·연휴 직전 = 시간 관리·자기 정리. 시즌에 맞춰 프로모션.

### 7) 후기·평판 관리 (9장)
- 전부 5점보다 가끔 4점짜리 솔직한 후기가 섞인 게 더 신뢰(너무 완벽하면 조작처럼 보임).
- 부정 후기: 절대 감정적 대응 금지 → 정중히 답글 → 실제로 개선(개정판).
- 후기 요청 시 "후기 부탁드려요"만이 아니라 구체적 질문 동반("어떤 부분이 가장 도움이 되셨는지 궁금해요").
- 평점과 노출: 4.5 아래 → 노출 감소 체감, 4.8 이상 유지 → 검색 상단 오래 유지.
- 좋은 후기 = 글솜씨가 아니라 기대와 실제의 간극을 줄이는 것(목차 미리보기 + 24시간 내 후기 요청).

### 8) SNS·블로그 연결 (12장)
- 전자책의 팁 하나를 카드뉴스로 블로그·SNS에 → 나머지는 전자책에서 확인 안내.
- 블로그: 목차 중 한 챕터 요약 글 + 마지막에 안내 문구와 링크.
- 무료 공개 범위: 전체의 5~10%, 가장 매력적인 부분 하나만.
- SNS 유입은 이미 톤을 경험한 상태라 검색 유입보다 전환율이 높음.
- 새 글 쓰지 말고 기존 전자책 재가공.

### 9) 시리즈 구조 (13장)
- 연결되는 주제를 큰 시리즈명으로 묶기(예: "엑셀 실무 함수" + "보고서 검토 체크리스트" + "업무 자동화 노하우" → "직장인 업무 효율화 시리즈").
- 각 상품 페이지에 "이 시리즈의 다른 책들" 문구 + 상호 링크 → 재구매율 상승.
- 완결판 패키지: 시리즈 전체를 개별 합산가보다 조금 할인.
- 같은 톤·타겟 → 제작 시간 추가 단축.

### 10) 팔리는 디테일 10가지 (14장)
1. 상세페이지 첫 문장은 질문으로 ("이런 고민 있으시죠?")
2. 숫자는 최대한 구체적으로 ("많이 팔렸어요" ✕ → "210건 판매, 평점 4.8")
3. 썸네일 글자 수 최소화: 핵심 문구 하나, 신뢰 숫자 하나
4. 구매 직후 24시간 안에 후기 요청
5. 목차 미리보기는 텍스트가 아니라 이미지로
6. 가격 끝자리는 900원 단위 (9,900원 vs 10,000원)
7. 상품명에 괄호로 보조 설명(타겟) 추가 ("엑셀 실무 함수 모음(초보자용)")
8. 업데이트 이력 표기 ("2025년 3월 개정")
9. 후기에는 반드시 답글
10. 한 번에 여러 개(제목·가격·썸네일) 동시에 바꾸지 않기 — 하나씩 바꾸고 반응 확인

## 실행 절차 (단계별)
[사용자] = 사용자 경험/정보/플랫폼 작업 필요, [Claude] = Claude가 생성 가능

### ① 발굴 (1일차)
1. [사용자] 최근 한 달 안에 누군가 "어떻게 하는 거예요?"라고 물어본 지식·노하우를 말해달라고 요청. 회사 업무·일상 모두 OK.
2. [Claude] 후보 최소 3개를 목록화하고 발굴 체크리스트로 점검 → 1개 선정.

### ② 검증 (2일차)
1. [사용자/Claude] 크몽·래피드에서 비슷한 상품 각 10개 이상(후기 많고 판매 지수 높은 것) 수집. (Claude가 웹 접근 가능하면 조사, 아니면 사용자가 캡처 제공)
2. [Claude] 스프레드시트 형식으로 정리: 제목 / 썸네일 문구 / 가격 / 상세페이지 순서 / 후기 내용·수.
3. [Claude] 4패턴(제목 구조, 목차 미리보기, 후기 타이밍, 상세페이지 순서) 공통점 요약. 경쟁 존재 = 시장 검증으로 해석.

### ③ 제작 (3~5일차)
1. [Claude] 목차 구조 초안 생성(예: "자주 쓰는 함수 5가지", "실수하기 쉬운 부분", "실무 예제" 같은 큰 틀). 각 항목은 상세페이지 미리보기 공개를 전제로.
2. [사용자] 각 항목에 실제 겪은 실수담·숫자·에피소드·구체적 팁 제공 (본문의 30% 이상이 실제 경험이어야 함 — Claude가 지어내지 말 것).
3. [Claude] 경험을 반영해 원고 확장 → 전체 말투·톤 통일 정리.

### ④ 노출 준비 (6일차)
1. [Claude] 제목 후보 3개("검색어 + 구체적 결과", 필요 시 괄호로 타겟 명시). 네이버 데이터랩 검색어 확인 권장.
2. [Claude] 썸네일 문구: 핵심 문구 1개 + 신뢰 숫자 1개(이전 판매 수 등 실제 숫자만).
3. [Claude] 상세페이지 구성: 질문형 첫 문장('이런 고민 있으시죠?') + "이런 분께 추천합니다" → 해결 → 목차 미리보기(이미지 3장) → 후기 → 구매 혜택. 업데이트 이력 표기. 래피드용은 후반부에 구매자 후기 스크린샷.
4. [사용자] 시작가 5,000~5,900원 설정(끝자리 900).
5. [Claude] 후기 요청 메시지 템플릿, 재구매 유도 메시지 템플릿 초안(책의 원칙 기반, 아래 문구 조각 활용). [사용자] 승인.

### ⑤ 업로드와 골든타임 (7~9일차)
1. [사용자] 크몽에 먼저 업로드.
2. 업로드 직후 3일: 지인 몇 명에게 링크 공유·솔직한 피드백 요청, 관련 커뮤니티 자연스럽게 소개, 문의 즉시 응답.

### ⑥ 첫 판매 이후 (10일차~)
1. 구매 직후 24시간 내 후기 요청 템플릿 발송(이름·상품명만 교체, 구체적 질문 포함).
2. 모든 후기에 답글. 부정 후기는 정중히 답하고 개정판에 반영.
3. 가격 사다리: 후기 5개 → 9,900원, 10개+ → 14,900원, 이후 → 19,900원 (평점 4.5+ 유지 조건). 한 번에 한 요소만 변경.

### ⑦ 확장 (18~25일차)

- 후기 요청을 한 번도 안 함.
- 상세페이지를 순서 없이 배치, 타겟 미명시.
- 검증 안 된 새 상품을 새 플랫폼(래피드)에 먼저 올리기 → 무반응.
- 크몽 그대로 복붙(플랫폼별 톤·카테고리·태그 조정 필요).
- 상위 카테고리 대충 선택, 아무 키워드나 태그.
- 후기 요청을 너무 기계적으로 → "너무 정형화된 느낌" 후기.
- 후기 부족 상태에서 가격 인상.
- 여러 요소 동시 변경.

### 10장 문제와 해결
| 문제 | 해결 |
|---|---|
| 콘텐츠 캡처·유출 | 감정 대응 X. 플랫폼 고객센터에 정식 신고 + 상품에 지속 업데이트로 "원본만의 가치" 강화 |
| 환불 요청("생각했던 내용과 달라요") | 어떤 부분이 기대와 달랐는지 정중히 질문. 상세페이지 설명이 애매했던 게 원인이면 흔쾌히 환불 + 문구 명확화. 단순 변심도 플랫폼 정책 범위 내 정중 안내. 상세페이지 개선 기회로 |
| 노출 급감(알고리즘·정책 변경) | 제목·썸네일 소폭 리프레시로 "새로운 신호" + 다른 플랫폼 판매 비중 조정 |
| 경쟁 상품 급증 | 가격 경쟁 X. 실제 경험담·구체적 숫자 등 "내용의 깊이"로 차별화 |
| 부정 후기 | 정중한 답글 + 실제 개선(개정판) |

## FAQ 요점 (부록 2)
- 가장 많이 하는 실수? → 내용만 채우고 보여주는 방식 소홀.
- 크몽 vs 래피드 어디부터? → 크몽에서 검증 → 래피드 이식.
- 후기가 안 달림? → 구매 직후 24시간 내 정중한 요청 메시지.
- 시작 가격? → 5천원 내외로 후기·이력 먼저, 신뢰 지표 기준 단계적 인상.
- 자동화 시작? → 가장 반복적인 작업 하나부터(저자는 후기 요청 템플릿부터).
- 주제 찾기? → 최근 누군가 "어떻게 하는 거예요?"라고 물어본 것.
- 골든타임 효과? → 초반 3일 조회·찜·문의가 이후 몇 주 노출에 큰 영향.
- 부정 후기? → 정중히 답하고 실제 개선.
- 경쟁 많음? → 시장 검증 신호. 경험담·숫자로 차별화.
- 언제까지 우려먹나? → 업데이트하며 오래 활용, 둔화 시 제목·썸네일 리프레시 또는 새 주제 발굴.
