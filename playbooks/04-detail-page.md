# 10배 더 팔리는 클로드 디자인 AI 상세페이지 실전 마스터북
- 원본: 4번 / 56페이지 (PDF)
- 대상: 전자책·VOD 강의를 혼자 만들고 파는 1인 지식창업자 (크몽·탈잉·클래스101 판매)
- 주 도구: Claude Design (왼쪽 대화창 + 오른쪽 실시간 캔버스)

## 한 줄 요약
콘텐츠가 안 팔리면 콘텐츠가 아니라 상세페이지를 의심하라 — 커리큘럼·후기 3개·레퍼런스 구조를 한 번에 Claude Design에 넣고, 첫 화면에 "이걸 들으면 무엇이 달라지는지"부터 보여달라고 요청한 뒤, 섹션별로 짚어 3~4회 수정하고, 결과를 디자인 시스템으로 저장해 재사용하는 "팔리는 40분" 공식.

## 핵심 공식 / 프레임워크

### 1) "팔리는 40분" 공식 (4단계)
| 단계 | 이름 | 소요 시간 | 핵심 행동 | 입력 | 출력 |
|---|---|---|---|---|---|
| 1단계 | 재료 모으기 | 약 10분 | 커리큘럼·후기·레퍼런스 정리해서 붙여넣기 | 커리큘럼(각 강 옆에 "무엇을 할 수 있게 되는지" 한 줄), 후기 3개(3유형), 레퍼런스 캡처 1~2개 | 대화창에 붙여넣을 재료 묶음 |
| 2단계 | 첫 대화 던지기 | 약 10분 | "무엇이 달라지는지"부터 넣어 첫 초안 받기 | 재료 + 한두 줄 요청 문장 | 캔버스 위 초안(60~70점이면 충분) |
| 3단계 | 섹션별 다듬기 | 약 15분 | 섹션별로 짚어가며 3~4회 수정 요청 (통째로 다시 만들기 금지) | 초안 + 구체적 수정 요청 | 만족스러운 완성본 |
| 4단계 | 시스템으로 굳히기 | 약 5분 | 모바일 확인 후 디자인 시스템으로 저장 | 완성본 | 재사용 가능한 "내 기본 디자인 시스템" (+ 왜 이렇게 만들었는지 메모) |

- 40분은 익숙해진 뒤의 기준 시간. 처음엔 1시간 넘어도 OK.
- 두 번째 강의부터 약 25분, 세 번째부터 20분 이하로 줄어듦(디자인 시스템 재사용 효과).
- 순서가 중요한 이유: 재료 없이 "예쁜 강의 상세페이지 만들어줘" → 내 콘텐츠와 무관한 일반적 페이지. 초안을 통째로 다시 요청 → 좋았던 부분까지 사라짐.
- 대화형 방식의 차이: 외주·독학·베끼기는 "한 번에 맞아야 하는" 구조. 대화형은 여러 번 주고받는 것을 전제로 함.

### 2) 핵심 원칙: "무엇이 달라지는지부터 보여주기"
- 첫 화면은 커리큘럼 나열이 아니라 "이 강의를 들으면 무엇이 달라지는지"부터.
- 예: 예전 PPT 첫 화면 "OO 강의 커리큘럼 안내" → 지금 첫 화면 "퇴근 후 1시간, 첫 결과물을 만들어보세요".
- 전자책도 동일: "이 책을 읽으면 무엇이 달라지는지"를 첫 화면에.

### 3) 레퍼런스 원칙: "구조만 참고, 톤은 절대 따라 하지 않는다"
- 참고 OK: 배치 순서 (예: "첫 화면에 변화 → 커리큘럼 → 후기").
- 참고 금지: 문구 어투, 색감.

### 4) 후기 3유형 선택법
1. 구체적 변화형 2. 비슷한 상황형 3. 숫자 포함형(있으면 무조건 넣기)

### 5) "강의 자료 vs 사고 싶은 페이지" 5초 테스트
- 처음 보는 사람에게 딱 5초 보여주고 무슨 내용인지 묻기.
  - "강의 목차네요" → 위험 신호
  - "뭔가 달라질 것 같은데요" → 성공
- 문장 끝: 명사로 끝남("OO 강의 안내") = 자료처럼 읽힘 / 동사로 이어짐("~할 수 있어요") = 결과가 그려짐.
- 숫자는 되도록 첫 화면에 ("전환율 2.4%", "수강생 210명").
- "쉽게 배울 수 있어요" 설명보다 실제로 만들 수 있는 결과물을 먼저 보여주기.
- (Ch1 실천 미션에서는 "3초만 훑어보기"로도 표현)

### 6) 채널별 최적화 포인트
| 채널 | 강조 포인트 |
|---|---|
| 크몽 | 첫 화면(스크롤 없이)에서 가격과 핵심 혜택이 바로 보이게 |
| 탈잉 | 강사 신뢰가 더 중요 → 자기소개를 앞쪽에, 이 강의를 만들게 된 계기를 짧게 |
| 클래스101 (큐레이션형) | 커리큘럼을 챕터별로 자세히 풀어서 |
- 기본 뼈대는 그대로, 채널 성격에 맞춰 첫 화면 강조 포인트만 조정.

## 실행 절차 (단계별)
Claude가 사용자를 대신해 수행할 때의 순서. [사용자] = 사용자 입력/경험 필요, [Claude] = Claude가 생성 가능.

0. 준비 확인
   1. [사용자] 판매할 콘텐츠 종류 확인: VOD 강의 / 전자책 / 기타. 판매 채널(크몽·탈잉·클래스101) 확인.
   2. [사용자] 브랜드 컬러·로고가 있으면 받기(없으면 건너뜀). 없으면 [Claude] "신뢰감"/"활기참"처럼 원하는 느낌을 단어로 먼저 정하게 하고, 거기에 맞는 색 하나만 고르도록 제안.

1. 1단계 재료 모으기 (~10분)
   1. [사용자] 커리큘럼(전자책이면 목차) 받기.
   2. [Claude] 각 강 옆에 "이 강의가 끝나면 무엇을 할 수 있게 되는지" 한 줄씩 붙여 재작성(아래 커리큘럼 정리 템플릿 형식). 사용자 확인 받기.
   3. [사용자] 후기 전체 받기 → [Claude] 3유형(구체적 변화형/비슷한 상황형/숫자 포함형)으로 3개 선별. 숫자 포함 후기는 반드시 포함. 후기를 지어내지 말 것.
   4. 후기가 없으면 → [사용자] "왜 이 강의를 만들었는지, 어떤 시행착오를 겪었는지" 진짜 경험을 받기. 빈칸이나 가짜 후기 금지. 후기 수집이 필요하면 [Claude] 부록 8 "후기 유도 문구"로 수강생 질문지 작성(구글 폼 활용).
   5. VOD 강사라면 → 수강생 결과물 스크린샷을 후기 대신/추가 재료로. 전자책이면 → 독자 후기 + 미리보기 3페이지 첨부.
   6. [사용자] 레퍼런스 1~2개 캡처 받기. [Claude] 레퍼런스 3가지 기준 점검(왜 좋아 보이는지 한 문장 / 구조 때문인지 톤 때문인지 / 타겟이 크게 다르지 않은지). 다른 업종 페이지도 OK.
   7. 재료를 한 폴더에 모아두도록 안내.

2. 2단계 첫 대화 던지기 (~10분)
   1. Claude Design 접속·로그인 → 새 프로젝트(새 대화) → (있으면) 브랜드 컬러·로고 업로드.
   2. 대화창에 정리한 커리큘럼 붙여넣기 → 후기 3개 + 참고 페이지 캡처 첨부.
   3. "무엇이 달라지는지부터 보여달라"는 요청 문장 한 줄 추가해 전송 (프롬프트 원문의 "실전 프롬프트 전문 예시"/템플릿 1 사용; 후기 없으면 템플릿 2).
   4. 캔버스 초안을 처음부터 끝까지 훑어보고, 초안은 캡처 저장. 마음에 안 드는 이유를 한 줄 메모.

3. 3단계 섹션별 다듬기 (~15분, 3~4회)
   1. 마음에 안 드는 섹션만 구체적으로 짚어 요청 (어느 섹션의 무엇을 어떻게).
   2. 한 번에 하나씩, 중요한 것부터 요청 (여러 개를 한꺼번에 말하면 누락됨).
   3. 이유를 짧게 덧붙이기 ("가격이 눈에 안 띄니까 키워줘").
   4. 좋았던 부분은 "그대로 유지"라고 함께 말하기.
   5. 만족스러운 버전이 나오면 즉시 캡처(이전 버전이 더 나은 경우가 있음). 대화가 길어지면 5분 쉬기.
   6. 첫 화면이 심심하면 숫자나 구체적 결과 하나 추가.

4. 4단계 시스템으로 굳히기 (~5분)
   1. 모바일 화면 4항목 점검(체크리스트 참조).
   2. 채널별 강조 포인트 조정(크몽/탈잉/클래스101).
   3. 완성본을 "내 기본 디자인 시스템"으로 저장 + "왜 이렇게 만들었는지" 메모. 상품이 여럿이면 "기본형"/"프리미엄형" 등 이름 붙이기, 채널별 캡처는 폴더 분리.
   4. 다음 콘텐츠 제작 시 "지난번 디자인과 같은 톤으로"라고 알려 재사용. 안 어울리면 뼈대만 유지하고 색·톤은 조정.
   5. 발행 전 셀프 체크리스트(부록 5) 10항목 통과 확인 후 발행.

5. 사후 관리
   1. 한 달에 한 번 전환율 확인 루틴.
   2. 반응이 좋았던 페이지의 구조를 따로 메모해 다음 콘텐츠에 재사용.

보조: Claude(claude.ai)는 문구 초안, 여러 후기 요약, 카피 다듬기에 보조로 사용(부록 1).

## 프롬프트 원문

실전 프롬프트 전문 예시 — 첫 대화(2단계)에 그대로 사용
```
[커리큘럼 붙여넣기]
[수강 후기 3개 붙여넣기]
[참고하고 싶은 페이지 구조 캡처 첨부]
"이 강의를 판매하는 상세페이지를 만들어줘. 첫 화면에는 커리큘럼 나열이 아니라, 이 강의를 들으면 무엇이 달라지는지부터 보여줘. 톤은 실전적이고 친근하게 해줘."
```

템플릿 1 — 첫 상세페이지 제작
```
[커리큘럼 붙여넣기] [후기 3개 붙여넣기] [참고 페이지 캡처]
"이 강의를 판매하는 상세페이지를 만들어줘. 첫 화면에는 커리큘럼 나열이 아니라, 이 강의를 들으면 무엇이 달라지는지부터 보여줘."
```

템플릿 2 — 후기가 없을 때
```
[커리큘럼 붙여넣기]
"아직 수강 후기가 없으니, 내가 이 강의를 왜 만들었는지와 어떤 시행착오를 겪었는지를 후기 대신 넣어서 상세페이지를 만들어줘. 문장은 [여기에 나의 경험 요약]을 참고해줘."
```

템플릿 3 — 완성된 페이지 부분 수정
```
"두 번째 섹션 후기 부분은 세 개 중 두 개만 남기고, 숫자가 들어간 후기를 제일 위로 올려줘. 나머지는 그대로 유지해줘."
```

수정 요청 예시 (막연한 요청 vs 구체적 요청) — 3단계 다듬기
```
막연한 요청 — "전체적으로 좀 더 좋게 만들어줘"
구체적 요청 — "헤드라인 문구만 더 직접적으로, 후기는 위치를 위로 올려줘"
막연한 요청 — "느낌이 좀 아닌데 다시 해줘"
구체적 요청 — "색감은 유지하고, 가격 부분 글씨 크기만 키워줘"
```

유지 지시 문구 — 수정할 때 항상 덧붙이기
```
"이 부분은 정말 좋으니까 그대로 유지하고, 이 부분만 바꿔줘"
```

이유 덧붙이기 예시
```
"가격을 키워줘" 대신 → "가격이 눈에 안 띄니까 키워줘"
```

디자인 시스템 재사용 — 다음 콘텐츠 첫 대화에서
```
"지난번 디자인과 같은 톤으로"
```

## 체크리스트

### 1단계 재료 체크 (대화 시작 전 "네 가지")
- 원본은 "아래 네 가지가 다 준비됐는지" 확인하라고 하나, 본문 텍스트에 표가 추출되지 않음(이미지로 추정). 본문 내용상 해당 항목은 다음과 같이 재구성됨(원문 그대로 아님):
- [ ] 커리큘럼(각 강 옆 "무엇을 할 수 있게 되는지" 한 줄)
- [ ] 후기 3개(구체적 변화/비슷한 상황/숫자 포함)
- [ ] 레퍼런스 캡처(구조만 참고)
- [ ] (있으면) 브랜드 컬러·로고 등 자산 / 원하는 톤 메모

### 레퍼런스 고르는 기준 (원문)
- [ ] 이 페이지가 "왜" 좋아 보이는지 한 문장으로 설명할 수 있는가
- [ ] 그 이유가 구조(배치 순서) 때문인지, 톤(문구·색감) 때문인지 구분되는가
- [ ] 내 콘텐츠와 타겟이 크게 다르지 않은가

### 모바일 화면 최종 점검 4가지 (원문)
- [ ] 글씨 크기가 너무 작아 읽기 힘든 부분은 없는지
- [ ] 표나 이미지가 화면 밖으로 잘리지 않는지
- [ ] 가격과 구매 버튼이 스크롤 안에서 잘 보이는지
- [ ] 스크롤이 지나치게 길어져 지루하게 느껴지지 않는지

### 부록 5: 발행 전 셀프 체크리스트 (원문)
- [ ] 첫 화면에 커리큘럼 나열이 아니라 "무엇이 달라지는지"가 보이는가
- [ ] 후기 3개 중 최소 1개는 구체적인 숫자가 포함되어 있는가
- [ ] 레퍼런스에서 가져온 건 구조뿐이고, 톤은 내 콘텐츠에 맞게 다시 썼는가
- [ ] 가격과 구매 버튼이 모바일 화면에서도 잘 보이는가
- [ ] 글씨 크기가 모바일에서 읽기 불편하지 않은가
- [ ] 표나 이미지가 화면 밖으로 잘리지 않는가
- [ ] 이 페이지만 보고도 강의(또는 전자책) 내용을 짐작할 수 있는가
- [ ] 경쟁 콘텐츠를 그대로 따라 한 문장이나 색감은 없는가
- [ ] 완성된 디자인을 다음에도 쓸 수 있도록 저장해두었는가

## 수치·기준값
- 전환율: PPT 상세페이지 0.9% → Claude Design 상세페이지 2.4% (콘텐츠 변경 없음)
- 월 매출: 80만 원 → 210만 원
- 제작 시간: 평균 5일 → 40분; 두 번째 강의부터 약 25분, 세 번째부터 20분 이하
- 단계별 시간: 1단계 10분 / 2단계 10분 / 3단계 15분(수정 3~4회) / 4단계 5분
- 그날의 40분 실제 배분: 재료 정리·붙여넣기 10분 → 첫 요청·초안 대기 10분 → 세부 수정 약 20분
- 외주: 건당 20만~40만 원(평균 30만 원으로 언급), 시안 약 1주일, 외주 → 0원
- 시행착오 비용: 외주비 약 90만 원, 출시 지연 최소 2주, 총 거의 한 달
- 첫 초안 기대치: 60~70점이면 충분, 나머지 30점은 대화 3~4회로
- 후기: 3개(3유형), 최소 1개는 숫자 포함
- 레퍼런스: 1~2개
- 전자책 미리보기: 3페이지 첨부
- 5초 테스트(처음 보는 사람에게 5초 보여주기) / 실천 미션에서는 3초 훑어보기
- 수정 요청: 보통 3~4번
- 전환율 재확인: 월 1회
- 휴식: 대화가 길어지면 5분
- 저자 실적: 3개월간 신규 강의·전자책 상세페이지 6개 제작
- 첫 화면 숫자 예: "전환율 2.4%", "수강생 210명"
- 후기 예시 숫자: 하루 30분씩 일주일, 첫 주 3건 판매

## 흔한 실수 / 문제 해결

### 흔한 실수
- 판매 부진 시 콘텐츠부터 의심하고 뜯어고치기 (먼저 상세페이지 확인).
- 강의 자료 만들던 습관대로 상세페이지 제작(정보 전달 ≠ 구매 욕구).
- 경쟁 강의 구조·톤·색감 그대로 베끼기 → 톤 불일치로 신뢰 하락.
- 강의 목차를 그대로 복사해 넣기.
- 후기를 무작정 전부 넣기 / 후기 없다고 빈칸·가짜 후기.
- 재료 없이 "예쁘게 만들어줘" 요청 → 일반적 결과물.
- 초안이 마음에 안 든다고 통째로 다시 요청 → 좋았던 부분까지 사라짐.
- 막연한 수정 요청("전체적으로 좀 더 좋게").
- 여러 수정 사항 한꺼번에 요청 → 누락.
- 모바일 점검 건너뛰기.
- 1단계(재료 모으기) 건너뛰고 싶을 때가 가장 위험.
- 지친 밤에 첫 시도 → 예민해짐(오전 추천).

### 부록 9: 자주 발생하는 문제와 해결법
| 상황 | 해결 |
|---|---|
| 초안이 내 콘텐츠와 전혀 다른 느낌으로 나올 때 | 재료가 너무 짧거나 추상적이지 않았는지 확인. 커리큘럼과 후기를 조금 더 구체적으로 다시 붙여넣고 요청 |
| 수정을 요청했는데 오히려 이상해질 때 | 최근 요청이 앞선 좋은 부분까지 건드렸을 수 있음. "이 부분은 유지하고"를 꼭 함께 |
| 색감이나 톤이 계속 마음에 안 들 때 | 색상 이름·"이런 느낌" 설명 대신 원하는 톤의 다른 페이지 캡처를 보여주기 |
| 후기가 부족해서 빈약해 보일 때 | 저자 본인의 진짜 경험을 그 자리에. 후기 없다고 미루지 말 것 |
| 여러 번 수정해도 첫 화면이 계속 심심할 때 | 숫자나 구체적 결과 하나만 추가 |
| 다음 콘텐츠에 같은 디자인을 적용했는데 안 어울릴 때 | 디자인 시스템은 뼈대만 유지, 색·톤은 콘텐츠 성격에 맞게 조정 |

### 기타 팁
- 결과가 별로면 왜 별로인지 딱 한 줄 메모 → 다음 수정 요청의 재료.
- 초안도 캡처 저장 → 나중에 비교 학습.
- 네 단계를 메모 앱에 고정, 시작 전 훑어보기. 처음 2~3번은 단계별 시간 측정.
- 이 순서는 SNS 홍보 이미지 제작에도 그대로 사용 가능.

## FAQ 요점
- Q1 디자인 경험 없어도? → 가능. 감각보다 재료와 순서의 문제.
- Q2 결과물이 마음에 안 들면? → 다시 만들기 말고 섹션만 짚어 수정. 3~4번이면 만족.
- Q3 후기·실적 없어도? → 저자 진짜 경험(왜 만들었는지, 시행착오)으로 채우면 더 신뢰.
- Q4 채널마다 따로? → 뼈대 유지, 첫 화면 강조 포인트만 조정.
- Q5 재사용? → 4단계(디자인 시스템 저장)로 다음 강의·전자책에 재사용.
- Q6 꼭 40분? → 익숙해진 뒤 기준. 처음엔 1시간 넘어도 OK.
- 오해 "AI가 알아서 예쁘게?" → 반은 맞고 반은 틀림. 재료 챙기기와 방향 잡기는 사용자 몫. AI는 손 빠른 파트너.
- 인터뷰: 이 방식이 안 맞는 경우 = 전담 디자이너가 있거나 복잡한 브랜드 가이드라인을 따라야 하는 경우. 1인 창업자에게 최적.
