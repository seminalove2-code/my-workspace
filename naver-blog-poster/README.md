# 네이버 블로그 자동포스팅 (나만 쓰는 용도)

사진과 메모를 폴더에 넣으면, AI(Claude)가 **잘 되는 레퍼런스 글과 같은 구조로** 글을 쓰고 내 PC의 브라우저로 네이버 블로그에 올려 줍니다.

```
레퍼런스 글 저장 ─→ 글 폴더 만들기(메모+사진) ─→ write.bat(AI 글쓰기) ─→ draft.md 확인 ─→ post.bat(발행)
```

---

## 1. 처음 한 번만: 설치

1. **파이썬 설치**: <https://www.python.org/downloads/> 에서 설치합니다. 첫 화면의 **"Add python.exe to PATH"를 꼭 체크**하세요.
2. 이 폴더(`naver-blog-poster`)를 PC에 받습니다. (GitHub에서 `Code → Download ZIP` 후 압축 풀기, 또는 `git clone`)
3. **`setup.bat`** 을 더블클릭합니다. 필요한 프로그램이 자동으로 설치됩니다.
4. **API 키 넣기**: <https://console.anthropic.com> 에서 API 키를 발급받고, 폴더 안의 `.env` 파일을 메모장으로 열어 `ANTHROPIC_API_KEY=` 뒤에 붙여넣습니다.
5. **`config.yaml`** 을 메모장으로 열어 `blog_id` 를 내 블로그 아이디로 바꿉니다. (`blog.naver.com/아이디`의 아이디 부분)
6. **`login.bat`** 을 실행하면 브라우저가 열립니다. 네이버에 직접 로그인(‘로그인 상태 유지’ 체크)한 뒤 검은 창에서 Enter를 누르세요.
   - 비밀번호는 프로그램에 저장되지 않습니다. 로그인 상태만 `browser_profile` 폴더에 남습니다.
   - 로그인이 풀리면 `login.bat` 만 다시 실행하면 됩니다.

## 2. 레퍼런스 글 넣기 (따라 쓸 글)

**`fetch_reference.bat`** 을 실행하고 차례로 입력합니다.

| 물어보는 것 | 입력 예시 |
|---|---|
| 블로그 또는 글 주소 | `https://blog.naver.com/hth1890` (블로그 주소면 최근 글 여러 개, 글 주소면 그 글 하나) |
| 글 종류 이름 | `출고후기` |
| 가져올 글 개수 | `5` |

→ `references/출고후기/` 에 저장됩니다. 사진만 있는 짧은 글은 자동으로 건너뜁니다.
소제목, 인용구(`[인용]`), 사진 위치(`[사진]`), 문단 구조가 그대로 남습니다.

글 종류마다 따로 저장해 두세요. 예:
- `references/출고후기/` ← 출고 후기 잘 되는 글
- `references/차량정보/` ← 차량 소개 잘 되는 글

> AI는 레퍼런스의 **구조와 말투만** 따라 하고, 문장은 새로 씁니다. 문장을 그대로 베끼면 네이버가 유사문서로 판단해 노출이 떨어지기 때문입니다. 레퍼런스에 나온 가격이나 사양도 가져오지 않습니다.

## 3. 글 쓰기

1. `posts/` 안에 글 하나당 폴더 하나를 만듭니다. (예: `posts/520i-김고객님/`)
2. 그 폴더에 넣을 것:
   - **사진들**: jpg, png, webp, gif. 파일 이름 순서대로 AI에게 전달됩니다. 아이폰 HEIC 사진은 jpg로 바꿔서 넣으세요. (아이폰 설정 → 카메라 → 포맷 → ‘높은 호환성’)
   - **`topic.txt`**: 맨 위 두 줄에 종류와 키워드, 그 아래에 메모를 씁니다. → `posts/예시-출고후기/topic.txt` 참고
     ```
     종류: 출고후기
     키워드: 강북 BMW 520i 출고

     - 고객님: 40대, 첫 BMW ...
     - 모델/색상/가격 ...
     ```
     - **종류**: `references/` 안의 어느 폴더를 따라 쓸지 정합니다.
     - **키워드**: 상위노출을 노리는 검색어입니다. 제목 앞쪽, 본문 2~4번, 태그에 자연스럽게 들어갑니다.
     - **가격, 사양, 프로모션은 메모에 정확히** 적으세요. AI는 메모에 없는 사실을 지어내지 않도록 되어 있습니다.
3. **`write.bat`** 실행 → 폴더마다 `draft.md` 가 만들어집니다.
4. `draft.md` 를 메모장으로 열어 확인하고 필요하면 고칩니다.

```
# 제목
태그: 태그1, 태그2, 태그3

일반 문단은 그대로 씁니다.
줄바꿈도 그대로 들어갑니다.

> 인용구 상자로 들어가는 소제목

## 굵은 글씨로 들어가는 소제목

[사진: 01.jpg]
```

다시 쓰게 하고 싶으면 `draft.md` 를 지우고 `write.bat` 을 다시 실행하세요.

**`config.yaml`의 `style`** 에 인사말(소속, 이름)과 항상 지킬 규칙을 적어두세요.

## 4. 발행하기

- **처음엔 꼭 테스트부터**: `test_post.bat` 실행 → 폴더 이름을 입력하면, 발행 버튼 직전까지만 입력하고 멈춥니다. 브라우저에서 제대로 들어갔는지 확인하세요.
- **실제 발행**: `post.bat` 실행 → `draft.md` 는 있고 아직 안 올린 글을 모두 올립니다.
  - 올린 글 폴더에는 `posted.txt` (발행 시각, 주소)가 생기고, 다음부터는 건너뜁니다.
  - `config.yaml` 에서 `publish: false` 로 바꾸면 발행 대신 **임시저장**만 합니다.
- 실패하면 `logs/` 폴더에 화면 캡처가 저장됩니다.

## 5. (선택) 정해진 시간에 자동 실행

`auto.bat` 은 **새 글 AI 작성 → 발행**을 한 번에 하고, 기록을 `logs/auto.log` 에 남깁니다.

1. 윈도우 검색에서 **작업 스케줄러** 실행 → `기본 작업 만들기`
2. 이름 입력 → 트리거: `매일` + 시간 지정
3. 동작: `프로그램 시작` → `auto.bat` 선택, **시작 위치**에 이 폴더 경로 입력
4. PC가 켜져 있고 로그인된 상태여야 실행됩니다.

> 자동 실행하면 AI가 쓴 글을 확인하지 않고 바로 올립니다. 처음 몇 번은 `write.bat` → 확인 → `post.bat` 순서로 직접 해보는 걸 권합니다.

## 주의사항

- **조금씩 올리세요.** 하루에 많은 글을 기계적으로 올리면 저품질 블로그로 판정되거나 계정이 제한될 수 있습니다. 개인 용도로 하루 1~3개 정도를 권합니다.
- **AI 비용**: 글 1편에 보통 수백 원 정도입니다. (사진 수와 레퍼런스 길이에 따라 다름) <https://console.anthropic.com> 에서 사용량을 볼 수 있습니다.
- **네이버 화면이 바뀌면** 입력이 실패할 수 있습니다. `post.py` 맨 위의 `SEL` 부분(버튼 위치 정보)만 고치면 됩니다. Claude에게 `logs/` 의 캡처를 보여주며 고쳐달라고 하면 됩니다.
- `posts/`, `references/`, `.env`, `browser_profile/` 은 GitHub에 올라가지 않도록 설정되어 있습니다.

## 파일 구성

| 파일 | 역할 |
|------|------|
| `config.yaml` | 블로그 아이디, 카테고리, 발행/임시저장, AI 말투 규칙 |
| `generate.py` / `write.bat` | 메모+사진+레퍼런스로 `draft.md` 작성 |
| `post.py` / `post.bat` / `test_post.bat` | 스마트에디터에 입력하고 발행 |
| `fetch_reference.py` / `fetch_reference.bat` | 블로그 글 주소로 레퍼런스 저장 |
| `login.py` / `login.bat` | 네이버 로그인 상태 저장 |
| `auto.bat` | 작성+발행 한 번에 (작업 스케줄러용) |
