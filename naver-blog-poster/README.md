# 네이버 블로그 자동포스팅 (나만 쓰는 용도)

사진과 메모를 폴더에 넣으면, AI(OpenAI, Claude, Gemini 중 선택)가 **잘 되는 레퍼런스 글과 같은 구조로** 글을 쓰고 내 PC의 브라우저로 네이버 블로그에 올려 줍니다.

```
레퍼런스 글 저장 ─→ 글 폴더 만들기(메모+사진) ─→ write.bat(AI 글쓰기) ─→ draft.md 확인 ─→ post.bat(발행)
```

---

## 쓰는 법 (프로그램 화면)

바탕화면의 **BMW 블로그** 아이콘을 더블클릭하면 프로그램 창이 열립니다.

1. **[설정] 탭 (처음 한 번):** AI 고르기, API 키 붙여넣기 → `AI 설정 저장`, `네이버 로그인`
2. **[글 쓰기] 탭:**
   - 글 종류, **차량(목록에서 고르기)**, 외장·시트 색상
   - 고객 이야기: 카톡으로 받은 글을 그대로 붙여넣기 (모르면 비워두기)
   - 사진을 끌어다 놓기, 번호판: `자동으로 가리기` 또는 `이미 가렸음`
   - **✍️ 글 만들기** → 가린 사진과 글이 미리보기로 나옵니다.
   - 번호판을 놓친 사진은 클릭 → `바꿔 넣을 사진` 올리기 → `선택한 사진 바꾸기`
   - 글은 화면에서 바로 고치고 `💾 고친 내용 저장`, 마음에 안 들면 `🔄 다시 쓰기`
   - **📤 네이버에 올리기** → 임시저장 (설정에서 `바로 발행`으로 바꿀 수 있음)
3. **[총정리 글] 탭:** 차종별 색상·트림·가격 총정리 글 (하루 한 편 자동)
   - 처음 한 번: Approach Book PDF(전체)를 올리고 `📥 색상·시트·휠 사진 뽑기` → 차종을 하나씩 골라 사진과 이름이 맞는지 확인
   - 실제 출고 사진이 있는 차종은 `썸네일에 쓸 실제 사진`을 올려두면 썸네일에 씁니다 (없으면 흰 배경 차 사진)
   - `▶ 매일 자동 켜기` → 매일 정한 시각(기본 08:30)부터 1시간 안에, `data/총정리_순서.txt` 순서대로 아직 안 쓴 차종 한 편을 씁니다
   - 처음 3편은 임시저장, 그 뒤로는 바로 발행 (`config.yaml` 의 `guide_review_count`). 임시저장 글을 직접 발행했다면 글 주소를 넣어주세요
   - 발행된 총정리 글이 있는 차종은 출고후기 끝에 "🔎 ○○ 색상·트림·가격 한눈에 보기 →" 링크가 자동으로 붙습니다
   - 기록: `logs/총정리.log`
4. **[지난 글] 탭:** 지금까지 쓴 글과 상태(초안/임시저장됨/발행됨). 불러와서 다시 고칠 수 있습니다.

프로그램을 끌 때는 [설정] 탭 맨 아래 `프로그램 종료`를 누르고 창을 닫으세요.
아래 설명은 처음 설치와, 화면 없이 bat 파일로 쓰는 방법입니다.

## 1. 처음 한 번만: 설치

1. **파이썬 설치**: <https://www.python.org/downloads/> 에서 설치합니다. 첫 화면의 **"Add python.exe to PATH"를 꼭 체크**하세요.
2. 이 폴더(`naver-blog-poster`)를 PC에 받습니다. (GitHub에서 `Code → Download ZIP` 후 압축 풀기, 또는 `git clone`)
3. **`setup.bat`** 을 더블클릭합니다. 필요한 프로그램이 자동으로 설치됩니다.
4. **API 키 넣기**: 폴더 안의 `.env` 파일을 메모장으로 열어, 쓰는 회사의 키를 붙여넣습니다.
   - OpenAI: `OPENAI_API_KEY=` 뒤에 (<https://platform.openai.com/api-keys>)
   - Claude: `ANTHROPIC_API_KEY=` 뒤에 (<https://console.anthropic.com>)
   - Gemini: `GEMINI_API_KEY=` 뒤에 (<https://aistudio.google.com/apikey>)
5. **AI 고르기**: `config.yaml` 의 `ai: "openai"` 를 `claude` / `openai` / `gemini` 중 하나로 둡니다. (지금은 openai)
   - **`models.bat`** 을 실행하면 내 키로 쓸 수 있는 모델 이름이 나옵니다. `config.yaml` 의 `models:` 아래 이름이 목록에 없으면 목록에 있는 이름으로 바꾸세요.
   - 블로그 아이디(`hotpickconnect`)와 카테고리는 이미 설정되어 있습니다.
6. **`login.bat`** 을 실행하면 브라우저가 열립니다. 네이버에 직접 로그인(‘로그인 상태 유지’ 체크)한 뒤 검은 창에서 Enter를 누르세요.
   - 비밀번호는 프로그램에 저장되지 않습니다. 로그인 상태만 `browser_profile` 폴더에 남습니다.
   - 로그인이 풀리면 `login.bat` 만 다시 실행하면 됩니다.

## 2. 레퍼런스 글 넣기 (따라 쓸 글)

**가장 쉬운 방법: `fetch_recommended.bat` 더블클릭.** 검색 상위에 오른 딜러 글 13개(출고후기 5, 차량정보 5, 프로모션 3)를 한 번에 저장합니다. 목록은 `data/recommended_refs.txt` 에서 바꿀 수 있습니다.

직접 고른 글을 넣고 싶으면 아래 방법을 씁니다.

**`fetch_reference.bat`** 을 실행하고 차례로 입력합니다.

| 물어보는 것 | 입력 예시 |
|---|---|
| 블로그 또는 글 주소 | `https://blog.naver.com/hth1890` (블로그 주소면 최근 글 여러 개, 글 주소면 그 글 하나) |
| 글 종류 이름 | `출고후기` |
| 가져올 글 개수 | `5` |

→ `references/출고후기/` 에 저장됩니다. 사진만 있는 짧은 글은 자동으로 건너뜁니다.
소제목, 인용구(`[인용]`), 사진 위치(`[사진]`), 문단 구조가 그대로 남습니다.

글 종류마다 따로 저장해 두세요. 예:
- `references/출고후기/` ← 출고 후기 잘 되는 글
- `references/차량정보/` ← 차량 소개 잘 되는 글

> AI는 레퍼런스의 **구조와 말투만** 따라 하고, 문장은 새로 씁니다. 문장을 그대로 베끼면 네이버가 유사문서로 판단해 노출이 떨어지기 때문입니다. 레퍼런스에 나온 가격이나 사양도 가져오지 않습니다.

## 3. 가격표 넣기 (매달 한 번)

AI는 `data/가격표.txt`에 있는 판매가격과 사양만 글에 씁니다. 이 파일은 딜러 자료(가격표 PDF, Approach Book)에서 뽑은 것이라 **GitHub에는 올라가지 않습니다.**

1. 새 달 가격표 PDF(정가)와 Approach Book(사양)이 나오면 Claude에게 보내고 "가격표 업데이트해줘"라고 말합니다. 할인 금액 열은 가져오지 않습니다.
2. Claude가 만들어 준 `가격표.txt`를 받아 `naver-blog-poster/data/` 폴더에 넣습니다. (기존 파일은 덮어쓰기)

차종별로 제목에 넣을 검색 키워드는 `data/키워드.txt`, 글 종류별 제목 형식과 구조는 `data/글종류/` 에 있습니다. 메모장으로 고칠 수 있습니다.

## 4. 글 쓰기

1. `posts/` 안에 글 하나당 폴더 하나를 만듭니다. (예: `posts/1021-X3/`)
2. 그 폴더에 넣을 것:
   - **사진들**: jpg, png, webp, gif. 아이폰 HEIC 사진은 jpg로 바꿔서 넣으세요.
     - **번호판은 자동으로 가립니다.** `write.bat` 이 AI로 번호판을 찾아 모자이크한 사본을 글 폴더의 `가림` 폴더에 만들고, 블로그에는 그 사진만 올라갑니다. 원본은 그대로 남습니다.
     - 자동 가리기는 100% 완벽하지 않습니다. **`가림` 폴더의 사진과 `가림_결과.txt`("못 찾음" 표시)를 꼭 확인**하고, 놓친 사진은 직접 가려서 `가림` 폴더의 같은 이름 파일을 바꿔 넣으세요.
     - 사진을 **미리 직접 가렸다면** `topic.txt` 에 `번호판: 직접 가림` 한 줄을 넣으세요. 자동 가리기를 건너뛰어 API 비용이 들지 않습니다.
   - **`topic.txt`**: 아래 형식으로 씁니다. → `posts/예시-출고후기/topic.txt` 참고
     ```
     종류: 출고후기
     차량: X3 xDrive 20 M Sport / 브루클린 그레이 / 블랙 시트
     출고: 2026년 10월
     고객 이야기: 첫 BMW, 가족 차로 바꾸심
     ```
     - **종류**: 출고후기 / 차량정보 / 프로모션 / 일상기록 / 상담견적 중 하나. 블로그 카테고리(BMW출고후기 등)가 자동으로 정해집니다.
     - **차량**: 최현정 대리가 알려준 정확한 트림과 색상. 이 줄로 가격표에서 가격을 찾습니다.
     - **고객 이야기**: 최현정 대리가 알려준 경우에만 씁니다. 없으면 줄을 지우세요. AI가 고객 이야기를 지어내지 않고 차량 중심으로 씁니다.
     - **키워드**: (선택) 비우면 `data/키워드.txt`에서 차종에 맞는 키워드를 자동으로 고릅니다.
     - 프로모션 글은 BMW코리아 공식 홈페이지의 금융 프로그램 내용을 메모에 붙여넣으세요. 딜러 할인 금액은 쓰지 않습니다.
3. **`write.bat`** 실행 → 폴더마다 `draft.md` 가 만들어집니다. 글 끝에 상담 안내(연락처)가 자동으로 붙습니다.
4. `draft.md` 를 메모장으로 열어 확인하고 필요하면 고칩니다.

```
# 제목
태그: 태그1, 태그2, 태그3

일반 문단은 그대로 씁니다.
줄바꿈도 그대로 들어갑니다.

> 인용구 상자로 들어가는 소제목

## 굵은 글씨로 들어가는 소제목

[사진: 01.jpg]
```

다시 쓰게 하고 싶으면 `draft.md` 를 지우고 `write.bat` 을 다시 실행하세요.

**`config.yaml`의 `style`** 에 인사말(소속, 이름)과 항상 지킬 규칙을 적어두세요.

## 5. 발행하기

- **처음엔 꼭 테스트부터**: `test_post.bat` 실행 → 폴더 이름을 입력하면, 발행 버튼 직전까지만 입력하고 멈춥니다. 브라우저에서 제대로 들어갔는지 확인하세요.
- **실제 발행**: `post.bat` 실행 → `draft.md` 는 있고 아직 안 올린 글을 모두 올립니다.
  - 올린 글 폴더에는 `posted.txt` (발행 시각, 주소)가 생기고, 다음부터는 건너뜁니다.
  - 지금은 `config.yaml` 이 `publish: false` 라서 **임시저장**만 합니다. 최현정 대리가 네이버에서 확인 후 발행하세요. 바로 발행하려면 `true` 로 바꿉니다.
- 실패하면 `logs/` 폴더에 화면 캡처가 저장됩니다.

## 6. (선택) 정해진 시간에 자동 실행

`auto.bat` 은 **새 글 AI 작성 → 발행**을 한 번에 하고, 기록을 `logs/auto.log` 에 남깁니다.

1. 윈도우 검색에서 **작업 스케줄러** 실행 → `기본 작업 만들기`
2. 이름 입력 → 트리거: `매일` + 시간 지정
3. 동작: `프로그램 시작` → `auto.bat` 선택, **시작 위치**에 이 폴더 경로 입력
4. PC가 켜져 있고 로그인된 상태여야 실행됩니다.

> 자동 실행하면 AI가 쓴 글을 확인하지 않고 바로 올립니다. 처음 몇 번은 `write.bat` → 확인 → `post.bat` 순서로 직접 해보는 걸 권합니다.

## 주의사항

- **조금씩 올리세요.** 하루에 많은 글을 기계적으로 올리면 저품질 블로그로 판정되거나 계정이 제한될 수 있습니다. 개인 용도로 하루 1~3개 정도를 권합니다.
- **AI 비용**: 글 1편에 보통 수백 원 정도입니다. (사진 수와 레퍼런스 길이에 따라 다름) 사용량은 각 회사 사이트(OpenAI / Anthropic 콘솔 / Google AI Studio)에서 볼 수 있습니다.
- **네이버 화면이 바뀌면** 입력이 실패할 수 있습니다. `post.py` 맨 위의 `SEL` 부분(버튼 위치 정보)만 고치면 됩니다. Claude에게 `logs/` 의 캡처를 보여주며 고쳐달라고 하면 됩니다.
- `posts/`, `references/`, `.env`, `browser_profile/` 은 GitHub에 올라가지 않도록 설정되어 있습니다.

## 파일 구성

| 파일 | 역할 |
|------|------|
| `config.yaml` | 블로그 아이디, 카테고리, 발행/임시저장, AI 말투 규칙 |
| `app.py` / `start_app.bat` / 바탕화면 **BMW 블로그** | 프로그램 화면 (글 쓰기, 지난 글, 설정) |
| `generate.py` / `write.bat` | 메모+사진+레퍼런스로 `draft.md` 작성 |
| `ai_providers.py` / `models.py` / `models.bat` | AI 회사 연결(Claude, OpenAI, Gemini), 쓸 수 있는 모델 확인 |
| `post.py` / `post.bat` / `test_post.bat` | 스마트에디터에 입력하고 발행 |
| `fetch_reference.py` / `fetch_reference.bat` | 블로그 글 주소로 레퍼런스 저장 |
| `login.py` / `login.bat` | 네이버 로그인 상태 저장 |
| `auto.bat` | 작성+발행 한 번에 (작업 스케줄러용) |
| `guide.py` / `auto_guide.py` / `task_schedule.py` | 차종 총정리 글: PDF 사진 뽑기, 카드, 하루 한 편 자동 (작업 스케줄러 등록) |
| `data/총정리_순서.txt` | 총정리 글을 쓸 차종 순서 |
