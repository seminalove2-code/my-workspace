# 커스텀커피 · 커스텀팩토리 분석 정리 (인계용, 2026-10-21)

기존 인계 문서(커스텀커피 단독 분석)에 이어, 커스텀팩토리 자료를 받아 반영한 내용과 대표 확인 결과를 정리한다.

## 1. 커스텀팩토리 개요
- 659-86-02411, 2021-07-01 개업, 대표 오병석
- 업종: 제조업 (그 외 기타 식료품 제조업)
- 본점·공장: 용인 처인구 포곡읍 석성로888번길 1 (B동), 임차 (임차보증금 1.9억)
- 주주: 오병석 70%, 김영식·김도희·윤성 각 10%
- 4대보험 7명

- 기계장치 취득가 8.97억 (감가상각누계 1.91억)
- 2026년 1~6월 부가세 과세표준 13.5억 (월 약 2.25억)

## 3. 대표 확인 사항
- 두 법인 간 내부거래가 월 2~3억 → **팩토리 매출 전부가 커스텀커피 공급**으로 본다 (다른 매출처 없음)
- 커스텀커피 기계장치 6.1억(2025 취득)은 팩토리 공장에 있음
- 사옥: **경기 남부**에 땅을 사서 신축. 땅은 넓게 사고 건물은 필요한 공간만 (제조장, 직영매장, 직원사무실). 면적 상세는 2차 미팅에서 정리
- 신청 주체: **커스텀커피**. 팩토리 명의는 회사 규모에 비해 대출금액이 너무 커서 안 됨
- 해석: 실질 매출은 커스텀커피 전부이고, 그중 제조 부분이 팩토리 매출로 잡혀 있다고 보고 진행
- 자기자금: 대표가 상담일지를 확인해야 함. **제안서에서 금액은 빼고 초안 작성**

## 4. 판단
1. 두 법인 매출은 더하지 않는다. 실질 매출은 커스텀커피 89.1억 (팩토리 28.6억은 내부거래)
2. 커스텀커피 2025년 상품매입 43.5억 중 약 28.6억이 팩토리 몫으로 추정 → 커스텀커피 장부에 제조 흔적이 없던 이유
3. 새 사옥 제조장을 팩토리가 쓰면 관계사 임대 면적으로 보여 대출에서 빠질 수 있음 → **커스텀커피에 제조업 추가, 사옥에서 커스텀커피가 직접 로스팅** (보유 로스터 6.1억 활용)
4. 자금 트랙은 신성장기반자금(혁신성장지원) 시설자금 (커스텀커피 업력 7년 초과)
5. 초과 토지는 대출 제외 가능성이 크고 비사업용 토지 세금 문제 → 2단계 증축 부지로 계획, 자기자금으로 관리
6. 과밀억제권역(수원·성남·안양·군포·의왕·과천·광명 등)은 본점·공장 신축 시 취득세 중과 가능 → 용인·화성·평택·오산·안성·이천 등 우선 (세무사 확인)
7. 토지 계약 전 인허가 사전 검토 필수: 용도지역, 식품제조가공업 등록, 로스터 대기배출시설, 진입로·하수·전기
8. 신축이라 입주는 2028년 상반기 전후
