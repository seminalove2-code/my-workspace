클로드에 링크 하나만 붙여 넣으면 설치되는 무료 "유튜브 에이전트 스킬" 11개(대본·제목/썸네일·편집 포인트·댓글·주간 계획·바이럴 분석)로 채널 운영을 자동화할 수 있다는 소개 영상.

## 핵심 내용

### 도입 (0:00)
- "클로드가 이제 유튜브 채널을 통째로 굴린다, 완전 공짜로"라는 훅으로 시작.

### 스킬 묶음 소개 (0:03)
- 이름은 "유튜브 에이전트 스킬". 스킬 1개가 아니라 **11개** 묶음.
- 공개 한 달도 안 돼 GitHub 별 1,000개 돌파. (자막에는 "기터부"로 나오지만 GitHub로 보인다.)
- 화면에 나온 저장소: **`Jakeschincariol/youtube-agent-skill`**
  - 설명: *"Eleven Claude skills that run a YouTube channel."*
  - 배지: MIT, 무료, Star / 강조 문구: "완전 무료", "가입 없음", "API 키 없음", "MIT"
- 화면의 "채널 운영" 표: 대본 · 제목·썸네일 · 편집 목록 · 댓글 답장 · 주간 계획 · 바이럴 분석, 6개 항목이 모두 "직접" 대신 "Claude"로 켜져 있다.

### 스킬별 기능 (0:03 ~ 0:20)
- **대본 `/yt-script`** (대본 + 훅 점수): **훅 공식 21개**로 대본을 쓰고 점수를 매긴다.
  - 자막 "훅 공식 2개"는 화면상 "스물한 개"를 잘못 받아 적은 것이다.
  - 화면에 나온 21개 공식:
    통계 · 남의 결과 · 실수 · 통념 뒤집기 · 공개 · 최상급 · 시간 · 해 봤더니 · 질문 · 전후 비교 · 들여다보기 · 도구 모음 · 경고 · 목록 · 증거 · 내부자 · 불가능한 주장 · 비교 · 기원 · 마감 · 직접 호칭
- **제목 + 썸네일 `/yt-package`**: 제목과 썸네일을 한 쌍으로 기획한다.
  - 예시: 썸네일 "클로드가 유튜브를 굴린다" ↔ 제목 "클로드가 이제 유튜브 채널을 통째로 굴립니다"
  - 자동 검사 3가지: **잘림 검사**, **중복 검사**, **모호함 검사**
- **편집 `/yt-edit`** (편집 목록): 잘라낼 곳을 초 단위로 찍어 준다.
  - 예시: `00:04 자, 오늘은요` → 군더더기 / `00:12 (4초 공백)` → 공백 / `00:19 이게... 다시 말하면` / `00:31 핵심은 바로 이거예요`
  - 파형 위에 잘라낼 구간을 표시한다.
- **댓글 `/yt-comment`** (댓글 4갈래 + 답장): 댓글을 4가지로 나누고 내 말투로 답장을 쓴다.
  - 분류: **질문** · **정정** · **칭찬** · **미끼**(답 안 함)
  - 예시: 시청자 질문 "이거 쇼츠에도 써요?" → 답장 "네, 그대로 돼요! 저도 매일 써요" (내 말투)
- **주간 계획 `/yt-plan`** (이번 주 계획): 요일별 업로드 계획을 짜 준다. (자막 "이번 주 개까지"는 "계획까지"로 보인다.)
  - 예시 배치: 월 쇼츠 · 화 **핵심 1** · 수 쇼츠 · 목 가벼운 1 · 금 쇼츠 · 토·일 비움
  - 합계: 핵심 1 · 가벼운 1 · 쇼츠 3

### 가장 강조한 기능: 바이럴 분석 (0:20)
- 내 분야에서 **평소보다 몇 배 터진 영상만** 골라낸다.
- 그 영상이 **어떤 공식으로 터졌는지**까지 짚어 준다.

### 설치·CTA (0:25)
- 링크 하나를 클로드에 붙여 넣으면 설치 끝.
- 화면에 나온 설치 문장:
  ```
  github.com/Jakeschincariol/youtube-agent-skill
  Install this skill, then confirm /yt-script works.
  ```
  → 클로드 응답: "설치 완료 · 스킬 11개 · `/yt-script` 작동 확인"
- 링크와 설치 문장은 무료로 준다며 "좋아요 + 댓글에 '에이전트'"를 요청한다. 댓글 키워드로 자료를 주는 방식이다.

## 기억할 포인트

- 저장소: `Jakeschincariol/youtube-agent-skill` (MIT, 가입·API 키 없음). 저장소 이름은 화면 캡처에서 읽은 것이고, 이 환경에서는 GitHub 접속이 막혀(403) 직접 확인하지 못했다.
- 확인된 명령어: `/yt-script`(대본 + 훅 점수), `/yt-package`(제목 + 썸네일), `/yt-edit`(편집 목록), `/yt-comment`(댓글 4갈래 + 답장), `/yt-plan`(이번 주 계획). 바이럴 분석의 명령어 이름은 캡처에 없다.
- 설치 문장은 화면에 그대로 나온다: "github.com/Jakeschincariol/youtube-agent-skill — Install this skill, then confirm /yt-script works."
- 댓글 분류 4갈래(질문 / 정정 / 칭찬 / 미끼는 무시)와 주간 배합(핵심 1 + 가벼운 1 + 쇼츠 3)도 그대로 참고할 만하다.
- 영상에서는 11개라고 했지만 구체적으로 소개된 것은 6개(대본, 제목·썸네일, 편집, 댓글, 주간 계획, 바이럴 분석)다.
- **훅 공식 21개**는 그대로 우리 훅 체크리스트로 쓸 수 있다(목록은 위 "핵심 내용" 참고).
- 제목·썸네일 검사 기준 3가지(잘림 / 중복 / 모호함)도 바로 쓸 수 있다.
- 영상에 나온 바이럴 기준은 "평소보다 몇 배"다. 채널 평균 조회수 대비 배수로 이상치를 찾는 방식(outlier 분석)으로 보인다.
- (의견) GitHub 별 1,000개라는 수치는 영상 속 주장이라 확인하지 못했다. 실제로 설치할 때는 저장소를 직접 보고 스킬 내용을 읽어 본 다음 쓰는 게 안전하다.

## 콘텐츠팩토리에 적용할 아이디어

(모두 내 의견)
- **바이럴 분석 스킬을 직접 만들기**: 우리 분야 채널들의 최근 영상 조회수를 채널 평균과 비교해 3배 이상 나온 영상만 뽑는다. 그 영상들의 훅, 제목, 썸네일 패턴을 정리해 `notes/youtube/`에 쌓는다.
- **제목·썸네일을 한 쌍으로 기획하기**: 제목과 썸네일 문구가 같은 말을 반복하지 않고 서로 보완하도록 같이 짠다.
- **대본 점수표 만들기**: 훅 공식 21개 중 우리 분야에 맞는 것을 골라, 대본 첫 3초가 어느 공식에 해당하고 몇 점인지 매기는 체크리스트를 만든다.
- **제목·썸네일 검사 3종 도입**: 업로드 전 잘림(모바일에서 제목이 잘리는지), 중복(썸네일과 제목이 같은 말인지), 모호함(무슨 영상인지 바로 알 수 있는지)을 확인한다.
- **편집 목록 자동화**: 자막 타임스탬프에서 "자, 오늘은요" 같은 군더더기 표현과 긴 공백을 찾아 컷 목록으로 뽑는다.
- **댓글 운영 규칙 정하기**: 질문은 빠르게 답하고, 정정은 고맙다고 한 뒤 고정 댓글이나 설명란에 반영하고, 칭찬은 짧게 답하고, 미끼(분란·어그로)는 답하지 않는다. 말투 예시 몇 개를 정해 두면 답장 톤을 맞추기 쉽다.
- **주간 업로드 배합**: "핵심(공들인 영상) 1 + 가벼운 영상 1 + 쇼츠 3"을 기본 틀로 쓰고, 핵심 영상은 주 초반(화)에 두고 쇼츠는 하루씩 건너 배치한다.
- **이 영상 구조를 그대로 템플릿으로 쓰기**: 30초 쇼츠가 "강한 약속(공짜·통째로) → 숫자로 신뢰(11개, 별 1,000개) → 기능 나열 → '제일 미친 건 따로 있다'로 마지막 기능 강조 → 댓글 키워드 CTA" 순서다. 도구를 소개하는 쇼츠에 그대로 쓸 수 있다.
- **댓글 키워드 CTA**: "댓글에 ○○ 남기면 링크 드림" 방식은 댓글 수를 늘리는 장치다. 우리 자료 배포에도 쓸 수 있다.
