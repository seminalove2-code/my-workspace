## 한 줄 요약

유튜브 채널 일을 나눠 맡는 무료(MIT) 클로드 스킬 11개 묶음 `youtube-agent-skill`을 소개하는 쇼츠. 대본·제목/썸네일·편집 목록·댓글·주간 계획·바이럴 분석 등을 써 주지만, **업로드는 내가 직접** 한다.

- 이름은 "유튜브 에이전트 스킬". 스킬 1개가 아니라 **11개** 묶음이다.
- 영상에서는 "공개 한 달도 안 돼 GitHub 별 1,000개 돌파"라고 한다. 자막의 "기터부"는 GitHub다.
- 배포 자료 기준으로는 2026-09-16 공개, 10/12 기준 별 1,180 · 포크 368이다.
- 저장소: **`Jakeschincariol/youtube-agent-skill`**
  - 설명: *"Eleven Claude skills that run a YouTube channel."*
  - MIT, 무료, 가입 없음, API 키 없음.
- 화면의 "채널 운영" 표에는 대본 · 제목·썸네일 · 편집 목록 · 댓글 답장 · 주간 계획 · 바이럴 분석, 6개 항목이 모두 "직접" 대신 "Claude"로 켜져 있다.

### 스킬별 기능 (0:03 ~ 0:20)
- **대본 `/yt-script`** (대본 + 훅 점수): **훅 공식 21개**로 대본을 쓰고 점수를 매긴다.
  - 자막 "훅 공식 2개"는 "스물한 개"를 잘못 받아 적은 것이다(화면 기준).
  - 화면에 나온 21개 공식:
    통계 · 남의 결과 · 실수 · 통념 뒤집기 · 공개 · 최상급 · 시간 · 해 봤더니 · 질문 · 전후 비교 · 들여다보기 · 도구 모음 · 경고 · 목록 · 증거 · 내부자 · 불가능한 주장 · 비교 · 기원 · 마감 · 직접 호칭
- **제목 + 썸네일 `/yt-package`**: 제목과 썸네일을 한 쌍으로 기획한다.
  - 예시: 썸네일 "클로드가 유튜브를 굴린다" ↔ 제목 "클로드가 이제 유튜브 채널을 통째로 굴립니다"
  - 자동 검사 3가지: **잘림 검사**, **중복 검사**, **모호함 검사**
- **편집 `/yt-edit`** (편집 목록): 잘라낼 곳을 초 단위로 찍어 준다.
  - 예시: `00:04 자, 오늘은요` → 군더더기 / `00:12 (4초 공백)` → 공백 / `00:19 이게... 다시 말하면` / `00:31 핵심은 바로 이거예요`
  - 파형 위에 잘라낼 구간을 표시한다.
- **댓글 `/yt-comment`** (댓글 4갈래 + 답장): 댓글을 4가지로 나누고 내 말투로 답장을 쓴다.
  - 분류: **질문** · **정정** · **칭찬** · **미끼**(답 안 함)
  - 예시: 시청자 질문 "이거 쇼츠에도 써요?" → 답장 "네, 그대로 돼요! 저도 매일 써요" (내 말투)
- **주간 계획 `/yt-plan`** (이번 주 계획): 요일별 업로드 계획을 짜 준다. 자막 "이번 주 개까지"는 "계획까지"다.
  - 예시 배치: 월 쇼츠 · 화 **핵심 1** · 수 쇼츠 · 목 가벼운 1 · 금 쇼츠 · 토·일 비움
  - 합계: 핵심 1 · 가벼운 1 · 쇼츠 3

### 가장 강조한 기능: 바이럴 분석 (0:20)
- 내 분야에서 **평소보다 몇 배 터진 영상만** 골라낸다.
- 그 영상이 **어떤 공식으로 터졌는지**까지 짚어 준다.
- 명령어는 `/yt-viral`이다(배포 자료 기준).

### 설치·CTA (0:25)
- 링크 하나를 클로드에 붙여 넣으면 설치가 끝난다.
- 화면에 나온 설치 문장을 붙여 넣으면 클로드가 "설치 완료 · 스킬 11개 · `/yt-script` 작동 확인"이라고 답한다.
- 링크와 설치 문장은 무료로 준다며 "좋아요 + 댓글에 '에이전트'"를 요청한다. 댓글 키워드로 자료를 주는 방식이다.

## 배포 자료 정리 (README 기준)

### ⚠️ 업로드는 하지 않는다
대본·제목·편집 목록·답장을 **써 주는** 도구다. 영상을 올리는 건 내가 한다. 작성자가 README에 직접 밝힌 내용이다.
영상의 "채널을 통째로 굴린다"는 과장이다.

### 설치 방법 (셋 중 하나)
1. 클로드에 그대로 붙여 넣기 (가장 쉬움)
   ```
   https://github.com/Jakeschincariol/youtube-agent-skill

   Install this skill, then confirm /yt-script works.
   ```
2. 클로드 코드 터미널
   ```
   git clone https://github.com/Jakeschincariol/youtube-agent-skill.git
   cp -r youtube-agent-skill/skills/yt-* ~/.claude/skills/
   ```
3. 플러그인
   ```
   /plugin marketplace add Jakeschincariol/youtube-agent-skill
   /plugin install youtube-agent
   ```

### 설치 후 제일 먼저: 내 말투 파일 `voice.md`
- 저장소의 `templates/voice.md`를 `~/.claude/youtube/voice.md`로 복사해서 채운다.
- 또는 클로드에게 내 영상 세 개를 주고 "이걸로 내 voice.md 써 줘"라고 한다.
- **11개 스킬이 전부 이 파일을 읽는다.** 소리 내어 읽을 대본이라 말투가 제일 중요하다.

### 명령 11개

| 명령 | 하는 일 |
|------|---------|
| `/yt-script` | 아이디어 하나를 대본으로. 훅 공식 21개로 훅 5개를 뽑아 점수를 매기고, 시청 유지 지점까지 표시 |
| `/yt-package` | 제목과 썸네일을 한 쌍으로 검사(잘림·중복·모호함) |
| `/yt-edit` | 자막 파일을 편집 목록으로 만든다. 공백·군더더기·다시 말한 곳을 타임코드로 표시(영상을 직접 자르지는 않음) |
| `/yt-comment` | 댓글을 질문·정정·칭찬·미끼로 나누고 내 말투로 답장, 고정할 댓글 하나 추천 |
| `/yt-plan` | 내가 쓸 수 있는 시간에 맞춘 한 주: 핵심 1편·가벼운 1편·쇼츠 3편 |
| `/yt-viral` | 내 분야 영상을 채널 평소 대비 몇 배 터졌는지로 정렬, 제목이 어떤 공식인지 표시 |
| `/yt-retention` | 시청 유지 데이터를 읽고 사람들이 나간 초와 그때 한 말을 짚음 |
| `/yt-shorts` | 긴 영상 안에 숨은 쇼츠 구간 + 새 첫 줄 |
| `/yt-seo` | 설명란, 쓸모 있는 태그만, 이 영상이 이겨야 할 검색어 3개 |
| `/yt-chapters` | 자막으로 챕터를 만들고 유튜브 규칙에 맞는지 검사 |
| `/yt-audit` | 채널 전체를 보고 고칠 것 딱 하나 |

영상에 나온 건 앞의 6개다. `/yt-retention`, `/yt-shorts`, `/yt-seo`, `/yt-chapters`, `/yt-audit` 5개는 배포 자료에만 있다.

### 작성자가 직접 적은 주의점
- 훅 점수는 참고용이다. 낮으면 다시 보라는 신호일 뿐, 높다고 터진다는 약속은 아니다.
- `/yt-viral`은 공개된 목록만 읽는다. 내 계정으로 로그인하지 않는다.
- 숫자를 지어내지 않는다. 필요한 숫자가 없으면 물어본다.
- 클로드 코드 없이 채팅에 SKILL.md 하나만 붙여도 돌아간다. 다만 그러면 파이썬 도구 6개는 못 쓴다.

## 기억할 포인트

- **업로드는 안 해 준다.** 써 주는 도구다.
- 설치 후 첫 작업은 `~/.claude/youtube/voice.md`(내 말투)를 채우는 것이다. 모든 스킬이 이 파일을 쓴다.
- 클로드 코드로 설치해야 파이썬 도구 6개까지 쓸 수 있다. 채팅에 SKILL.md만 붙이면 일부 기능만 된다.
- 바로 가져다 쓸 수 있는 기준들:
  - 훅 공식 21개(목록은 위 "핵심 내용")
  - 제목·썸네일 검사 3가지: 잘림 / 중복 / 모호함
  - 댓글 4갈래: 질문 / 정정 / 칭찬 / 미끼(무시) + 고정 댓글 1개
  - 주간 배합: 핵심 1 + 가벼운 1 + 쇼츠 3
  - SEO: 이 영상이 이겨야 할 검색어 3개
- 바이럴 기준은 "채널 평소 대비 몇 배"다. 채널 평균 대비 배수로 이상치를 찾는 방식이다.
- (의견) 설치 전에 저장소를 직접 열어 SKILL.md와 파이썬 도구 내용을 읽어 보는 게 안전하다.

## 콘텐츠팩토리에 적용할 아이디어

(모두 내 의견)
- **`voice.md`부터 만들기**: 이 스킬을 쓰든 안 쓰든, 우리 채널 말투를 정리한 파일 하나를 두고 대본·댓글·설명란 작업할 때마다 클로드에 같이 주면 톤이 일정해진다. 기존 영상 세 개의 자막으로 초안을 뽑는다.
- **바이럴 분석 루틴**: `/yt-viral`로 우리 분야 이상치 영상을 뽑고, 그 제목 공식과 훅을 `notes/youtube/`에 정리해 쌓는다.
- **긴 영상 → 쇼츠 재활용**: `/yt-shorts`로 긴 영상에서 쇼츠 구간과 새 첫 줄을 뽑으면, 주간 배합의 "쇼츠 3"을 따로 찍지 않고 채울 수 있다.
- **업로드 전 체크리스트**: `/yt-package`(제목·썸네일 검사) → `/yt-seo`(설명란·태그·검색어 3개) → `/yt-chapters`(챕터) 순서로 돌린다.
- **업로드 후 회고**: `/yt-retention`으로 이탈 지점과 그때 한 말을 찾고, 다음 대본(`/yt-script`)에 반영한다. 월 1회는 `/yt-audit`로 "고칠 것 하나"만 정한다.
- **댓글 운영 규칙**: 질문은 빠르게 답하고, 정정은 고맙다고 한 뒤 반영하고, 칭찬은 짧게 답하고, 미끼는 무시한다. 댓글 하나는 고정한다.
- **이 영상 구조를 템플릿으로 쓰기**: 30초 쇼츠가 "강한 약속(공짜·통째로) → 숫자로 신뢰(11개, 별 1,000개) → 기능 나열 → '제일 미친 건 따로 있다'로 마지막 기능 강조 → 댓글 키워드 CTA" 순서다. 도구를 소개하는 쇼츠에 그대로 쓸 수 있다.
- **댓글 키워드 CTA + 정리 자료**: 댓글을 단 사람에게 이번 배포 자료처럼 "설치법 + 한글 요약 + 주의점 + 출처" 구성의 한 장짜리 자료를 준다. 신뢰를 주기 좋은 형식이다.
