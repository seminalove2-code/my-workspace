# 리쿠르팅 페이지 레퍼런스 분석 (2026-10-22)

첫 화면 캡처: `notes/business/refs/*-fold.png` (390px 휴대폰 기준)

## 1. 인카다이렉트 보험설계사 모집 (dazabi.com/recruit_incar/)
- **같은 "인카다이렉트" 이름을 쓰는 기존 모집 페이지가 이미 있다.** 전화번호가 걸려 있고, 우리 페이지와 검색에서 겹친다. 누가 운영하는지 사용자 확인 필요.
- 첫 화면: "지인영업보다 시스템으로 시작하는 인카다이렉트 보험설계사 모집" + 전화 버튼 + 체크 3개
- 수수료·시상표(보험사별 %)를 공개. 이건 강하다.
- 약점: 문구가 추상적("방향 + 구조 + 함께하는 환경", "브랜드형 설계사 성장 관점"). 사진은 외국인이 나오는 AI 생성 같은 사무실 이미지. DB가 어디서 오는지 구체적인 말이 없다.
- → 우리는 "매주 베이비페어 / 평일 매일 2건"처럼 구체적인 숫자로 차별화.

## 2. 보맵파트너스 리크루트 (bomapp-partners.com)
- 첫 화면: "DB 영업 파트 경력직 보험설계사 공개 채용" + "채용 미팅 바로 신청" 버튼이 첫 화면 안에 있음
- DB 품질을 숫자로: 계약 체결률 30%, 30대 전문직 여성 비중 70%, 최대 1787%, 1,200만원 지원
- "신청하기 전 꼭 확인해주세요" 약속 5개 (말 바꾸지 않아요 / 노하우 전수 / 강요하지 않아요 / 약속 지켜요)
- 신청폼이 좋다: 경력 연차 선택 → 이동 규모(개인/조직 10명 미만…) → 이름·연락처. 버튼만 눌러서 답하는 방식.
- 약점: 파란 배경 + 3D 캐릭터 일러스트 = 흔한 템플릿 느낌.

## 3. THE금융서비스 퍼스트 (thefirst.co.kr/recruit/)
- 첫 화면: "만날 고객이 없어서 그만두게 되는 일은 이제 없습니다." → 우리 핵심 메시지와 똑같은 고민을 짚음
- 대표 소개영상, 대표 1인칭 메시지("제 관심사는 오직 설계사의 생존입니다", "안되는 건 안된다고 솔직하게")
- 실제 성과 사례: 직급 + 이전 직업(배달업 → 지점장, 전업주부 → 팀장). 신입에게 가장 설득력 있음
- "90년대생은 배정되지 않아요"처럼 DB 고객 연령대를 밝힘
- 육아 스케줄 우선, 자율 출퇴근 → 경단녀/육아맘 타깃
- 약점: 혜택 나열이 길고 "★" 남발, 섹션이 많아 산만함.

## 4. 토스인슈어런스 '뉴 스탠다드' (2026-07 공개)
- 이 환경에서 접속 불가. 기사 기준: 재직 설계사 후기, 무경력자용 콘텐츠, 직무 설명회 신청.
- 토스 앱 상담 신청 고객이 설계사에게 배정되는 구조 = "DB가 어디서 오는지"가 명확한 사례.

## 가져올 것
1. 첫 화면 안에 신청 버튼 (보맵)
2. DB/시장의 품질을 숫자로 (보맵, 퍼스트) → 우리는 매주 / 월 2~3회 / 평일 매일 2건
3. 대표(리더) 1인칭 목소리 + 얼굴 (퍼스트) → AI 티를 빼는 가장 확실한 장치
4. 실제 사례: 직급 + 이전 직업 한 줄 (퍼스트). 지어내지 않는다.
5. 버튼 눌러서 답하는 신청폼: 경력 연차, 관심 시장(베이비페어/사업자) (보맵)
6. 육아 스케줄, 박람회 골라서 참석 같은 생활 조건 (퍼스트)

## 버릴 것
- AI 생성/외국인 스톡 사진 (인카 기존 페이지)
- 3D 캐릭터 일러스트, 파란 단색 배경 (보맵)
- "★" 혜택 나열, 섹션 과다 (퍼스트)
- "방향·구조·환경" 같은 추상 명사 문구 (인카 기존 페이지)
- 수수료 % 경쟁: 우리 브리프에 수수료 공개 여부 미정 → 사용자 확인 전까지 쓰지 않는다

## 업계 밖 레퍼런스 (2026-10-22)

사용자 평가: 보험업계 레퍼런스 3곳(인카 기존, 보맵, 퍼스트)은 디자인이 "쓰레기". 디자인 참고로 쓰지 않는다 (내용 구성만 참고).

캡처: `notes/business/refs/non-insurance-sheet.png` (토스 채용, 당근 채용, 우아한형제들 채용, 무신사 채용, flex, 토스뱅크)
- 대부분 공고 목록형 채용 포털이라 구조는 우리와 안 맞음. 볼 것은 첫 화면과 사진 쓰는 법.
- 우아한형제들: 실제 직원 사진을 화면 가득 + 굵은 흰 글씨. 스톡 느낌 0. → 사진 많은 우리에게 가장 맞음 (시안 C 방향)
- 무신사: 흰 바탕, 영문 대형 타이틀, 사진 한 장, 여백. 패션 브랜드식 절제.
- flex: 검정 바탕 + 강한 그라데이션 한 장. 세련되지만 우리 업종엔 과함.
- 토스/당근: 검색창, 목록 중심. 리쿠르팅 랜딩 참고로는 약함.
