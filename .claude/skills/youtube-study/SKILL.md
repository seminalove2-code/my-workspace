# 유튜브 영상 학습·정리

## 1. 영상 내용 가져오기

- 사용자가 자막(스크립트)을 붙여넣었으면 그것을 그대로 쓴다.
- 링크만 있으면 자막을 가져와 본다. 예: `pip install youtube-transcript-api` 후
  `YouTubeTranscriptApi().fetch(video_id, languages=["ko", "en"])`.
- 네트워크가 막혀서 자막을 못 가져오면 지어내지 말고 사용자에게 알린다.
  유튜브에서 "스크립트 표시"로 자막을 복사해 붙여넣어 달라고 안내한다.

## 2. 정리본 작성

`notes/youtube/YYYY-MM-DD-짧은-제목.md` 파일로 저장하고, 아래 형식을 따른다.

```markdown
# 영상 제목

- 링크: https://www.youtube.com/watch?v=...
- 채널:
- 정리한 날짜: YYYY-MM-DD
- 태그: #태그1 #태그2

## 한 줄 요약

## 핵심 내용
(영상 흐름 순서대로, 소제목과 bullet로 정리)

## 기억할 포인트
(실제로 써먹을 수 있는 팁, 수치, 도구 이름 등)

## 콘텐츠팩토리에 적용할 아이디어
(이 영상 내용을 콘텐츠 제작에 어떻게 쓸 수 있는지)

## 원문 인용
(중요한 문장 몇 개만, 가능하면 타임스탬프와 함께)
```

- 자막에 없는 내용을 사실처럼 쓰지 않는다. 내 의견은 의견이라고 표시한다.
- 한국어로 쓴다. 영어 영상이어도 정리는 한국어로 한다.

## 3. 목록 갱신

`notes/youtube/INDEX.md` 표 맨 위에 한 줄을 추가한다.
(날짜 | 제목(파일 링크) | 한 줄 요약 | 태그)

## 4. 저장

작업 브랜치에 커밋하고 push한다. 다 끝나면 사용자에게 한 줄 요약과 파일 경로를 알려 준다.

## 이전에 학습한 내용 활용

사용자가 "전에 배운 내용", "학습한 거 바탕으로" 같은 요청을 하면
먼저 `notes/youtube/INDEX.md`를 읽고, 관련된 정리본을 찾아 읽은 뒤 답한다.
