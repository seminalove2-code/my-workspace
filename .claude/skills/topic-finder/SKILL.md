# 팔리는 주제 발굴기

원본 도구: `tools/팔리는-주제-발굴기.html` (책 8번). 이 스킬은 그 도구의 프롬프트·점수 공식을 그대로 옮긴 것이다.

## 1. 입력 모으기

`me/profile.md`를 먼저 읽는다. 아래 항목 중 비어 있는 것만 사용자에게 한 번에 묻는다(최대 1회). 사용자가 귀찮아하면 있는 정보로 진행한다.

- 지금 하는 일 (직업, 연차, 업무 내용)
- 최근 누가, 무엇을 물어봤나 ("어떻게 하는 거예요?" 소리를 들었던 것들)
- 오래 해왔거나 잘하는 것 (일, 취미, 극복한 경험)
- 관심 분야 (복수 선택/상관없음): 오피스·문서작성, 부업·재테크, SNS·마케팅, 자기계발·생산성, 외국어·어학, 취업·이력서, 디자인·이미지툴, 육아·가정살림, 건강·운동, 사진·영상편집
- 원하는 형태: 전자책, 템플릿, 체크리스트, VOD 강의, 1:1 코칭
- 판매할 곳: 크몽, 탈잉, 클래스101, 스마트스토어, 래피드, 아직 모름
- 쓸 수 있는 시간: 주 3시간 이하 / 주 5~10시간 / 주 10시간 이상
- 이미 생각해둔 주제 (있으면 같이 채점)

새로 알게 된 정보는 `me/profile.md`에 저장한다.

## 2. 주제 6개 뽑기 (원본 프롬프트의 원칙)

- 이 사람의 일, 경험, 질문받은 내용에서 출발한다. 뻔한 주제 말고 이 사람의 경험이 드러나는 구체적인 각도로 좁힌다.
- 제목은 **'검색어 + 구체적 결과'** 공식. 사람들이 실제로 검색할 단어가 앞에, 사면 얻는 결과가 구체적으로.
- 판매량·매출·검색량 숫자를 지어내지 않는다. 근거는 수요 패턴과 논리로 설명한다.
- 점수는 1~5 정수. 후하게 주지 말고 주제마다 차이를 둔다.
  - **수요(demand)**: 이 문제를 이미 찾고 돈을 쓸 사람이 꾸준히 있는가 (반복 질문, 꾸준한 검색, 시즌 수요)
  - **내 경험(experience)**: 입력된 경험으로 볼 때 신뢰 있게 만들 수 있는가
  - **만들기 쉬움(ease)**: 가용 시간 안에 첫 버전을 만들기 쉬운가 (5 = 아주 쉬움)
  - **시장 검증(market)**: 비슷한 상품이 이미 팔리는가 (5 = 경쟁 상품 많음 = 검증됨, 3 = 애매, 1 = 거의 없음 = 수요 불확실)
- 사용자가 직접 적은 주제는 6개와 별도로 같은 기준으로 채점하고 "내가 적은 주제"로 표시한다. 뜻은 바꾸지 않고 제목만 다듬는다.
- 참고용 꾸준히 팔리는 패턴(그대로 쓰지 말고 각도만 참고):
  - 오피스: 엑셀 실무 함수 모음, 보고서 검토 체크리스트, PPT 템플릿 30선, 회의록 템플릿, 구글시트 업무 대시보드
  - 부업·재테크: 퇴근 후 2시간 부업 로드맵, 사회초년생 월급 관리 루틴, 중고거래 부수입, 스마트스토어 소싱 체크리스트, 청년 정책자금 총정리
  - SNS: 릴스 기획~편집, 블로그 SEO 체크리스트, 카드뉴스 템플릿, 스레드 팔로워 전략
  - 자기계발: 하루 30분 루틴, 노션 대시보드, 번아웃 감정 정리 워크북, 습관 트래커
  - 어학: 영어 이메일 템플릿, 여행 회화 30문장, 토익스피킹 로드맵
  - 취업: 자소서 문장 템플릿, 경력기술서 작성법, 면접 답변 스크립트
  - 디자인: 미리캔버스 썸네일 30선, 캔바 로고, 명함·전단지 가이드
  - 육아·살림: 이유식 스케줄표, 맞벌이 살림 분담 루틴, 냉장고 파먹기 식단표
  - 건강: 홈트 4주 루틴, 거북목 스트레칭, 식단 기록 템플릿
  - 영상: 브이로그 컷편집, 스마트폰 제품사진, 캡컷 숏폼 템플릿

각 주제마다: 제목, 분야, 형태, 타겟, 타겟의 문제(한 문장), 왜 팔릴까, 내가 유리한 점, 경쟁 상황 추정, 4개 점수, 판매처에서 직접 검색해볼 검색어 2~3개.

## 3. 점수 계산 (원본과 동일)

```
종합 = 수요×0.30 + 내경험×0.25 + 만들기쉬움×0.20 + 시장검증×0.25   (소수 둘째 자리)
4.0 이상 = 최우선 추천 / 3.0 이상 = 추천 / 2.0 이상 = 검토 필요 / 그 미만 = 보류
```

종합 점수 내림차순 표로 보여 준다. 맨 위에 이 사람의 '팔 수 있는 강점' 1~2문장 요약.
"다른 각도로 더"를 요청하면 이미 낸 제목과 겹치지 않게 4개를 추가한다.

## 4. 고른 주제 심화 (사용자가 하나 고르면)

**제목 5개** — 유형 순서대로 하나씩: 검색어+결과형, 타겟 공략형, 결과 직접 제시형, Q&A형, 체크리스트형. 각 제목에 먹히는 이유 한 줄. 과장 문구(무조건, 100% 등) 금지.

**기획서** — 처음 살 사람 1명 묘사, 그 사람의 구체적 고민 3개, 목차 6~8개, 구매를 돕는 보너스 자료 1개, 추정 가격 범위와 이유(비슷한 상품 기준, 숫자 지어내지 않기), **만들기 전 이번 주에 해볼 수요 검증 행동 3개**, 주의할 점 1개.

## 5. 저장

- 결과를 `output/topics/YYYY-MM-DD-주제발굴.md`에 저장(표 + 고른 주제 심화).
- 고른 주제는 `me/progress.md`의 "현재 상품"에 적는다.
- 커밋·push 후, 다음 단계(보통 `threads-post`로 수요 검증 → `ebook-maker`)를 한 줄로 제안한다.
