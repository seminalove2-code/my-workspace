# 자리 비움 시스템 (월 1,000 자동화)

상세 근거: `playbooks/10-auto-ops.md` (표·문구 원문, 운영 점검 프롬프트 6선).
자리 비움 = 반복 일은 사람 없이, 사람 일은 몰아서, 고장은 알림으로 내가 먼저 안다.
결과물은 `output/ops/`에 저장한다.

## 0. 자가진단 (처음)
8문항을 한 번에 묻고 "네" 개수로 시작점 결정: 6개+ 점검만 / 3~4개 연결·감시부터 / 2개 이하 1주차부터.
(결제 후 전달에 손 안 감 · 하루 이틀 폰 안 봐도 불안 X · 실패 시 알림 옴 · 응답 약속이 상품 페이지에 있음 · 쉬는 날 정해짐 · 노트북 고장 나도 일함 · 채널 하나 막혀도 판매 지속 · 지난달 시간 쓴 곳을 말할 수 있음)

## 1주차 — 분류 (`분류표.md`)
사용자에게 "지난 7일 반복한 일 10가지"만 받는다. 각 일을 반복 빈도·실수 비용·사람 온도(높음/중간/낮음)로 평가해 판정:
자동화 / 자동화+실패 알림 / 템플릿+사람 한 줄 / 템플릿 자동+예외는 사람 / 사람이 직접 / AI 초안+사람 결정 / 자동 집계+사람 확인 / 체크리스트.
- 사람이 직접 하는 일은 20~30%가 출발점. 환불·불만 답변은 항상 사람.
- 첫 자동화 대상 1개 추천(보통 "결제 후 파일 전달").

## 2주차 — 연결 (`연결.md`)
- 결제 후 10분 안에 고객이 받아야 할 3가지: 결제 확인 · 상품 접근 방법 · 문의 방법.
- 고객 흐름 8칸(상품 페이지→결제→완료 안내→파일 수령→궁금→문의→답변→후기)에 칸별 처리 주체 표시.
- 응대 약속 구간표(파일 미수령 / 사용법 / 환불·불만 / 후기 / 협업) — "바로 답한다" 대신 "언제까지 답한다".
- 자동 안내 문구 3종을 사용자 상품에 맞게 채워 준다: 결제 완료 안내 / 문의 접수 확인 / 자리 비움 안내. 지난 한 달 문의를 3~4유형 FAQ로 묶어 상품 페이지·구매 완료 안내·자동 응답 3곳에 연결.
- 시험 구매 점검표: 완료 안내 1분 내 / 사람 손 0회 / 모바일 열림 / 문의 방법 보임 / 자동 응답 즉시.

## 3주차 — 감시 (`알림-장애.md`)
- 알림 설계표 5줄: 결제 실패(즉시 푸시) / 자동 전달 실패(즉시) / 문의 대기(약속 시간 80% 경과) / 유입 급락·계정 경고(주간) / 플랫폼 공지(주간). 울려야 할 것만.
- 장애 대응 5단계: 인지 5분 → 분류 5분(결제 고객 영향?) → **임시 조치 15분(원인보다 고객 보호 먼저, 수동 전달)** → 복구 당일 → 기록 당일.
- "장애 났어" 요청 시: 위 순서로 지금 할 일을 하나씩 안내하고, 메모를 받아 장애 일지 5줄(날짜·증상·영향·원인·조치와 재발 방지)로 `장애일지.md`에 추가.
- 분기 집중도 점검: 판매 경로 한 곳 의존? 고객 연락처를 내가 따로 보관? 로그인이 한 폰 인증에만 묶임?

## 4주차 — 리듬 + 이동 (`주간리듬.md`)
- 주간 3칸: 제작일(주 2일, 결제·전달 실패 알림만) / 점검일(주 1~2일, 알림 전체) / **비움일(최소 1일, 긴급만)**. 한 번 정하면 최소 한 달 유지.
- 이동·여행 시: 출발 7·5·3·1일 전 + 도착 당일 체크리스트, 비상 시나리오 3종(노트북 고장 / 인터넷 두절 / 로그인 막힘), 클라우드 백업·2단계 인증 복구 코드, 자리 비움 안내 문구 3가지 톤. 세무는 일반 정보만, 개인 상황은 세무사 확인을 권한다.

## 반복 루틴 (요청 시)
- **주간 마감** ("주간 마감 해줘"): 5질문(판매 건수·순수익 / 장애·알림 / 사람이 직접 한 일 / 가장 시간 쓴 일 / 다음 주 꼭 할 일 하나) → 다음 주 자동화 후보 3개를 시간 절약 순으로. `주간마감/YYYY-WW.md`.
- **월간 회고**: 대시보드 6지표(매출·순수익 / 상품별 판매 / 장애 건수 / 응답 시간 / 상품당 제작 시간 / **비움일 사용 일수**) + 회고 8문항. 모르는 칸 = 다음 달 최우선 개선.
- **목표 역산**: 필요 매출 = 목표 순수익 ÷ (1 − 비용 비율), 필요 건수 = 매출 ÷ 객단가, ÷30 = 하루 건수.
- **확장해도 돼?**: 4질문(3개월 목표 유지 / 장애 월 1회 이하 / 비움일 주 1일+ 실제 사용 / 확장해도 점검일 유지) 모두 "네"일 때만 확장.
- **수익 하락 시**: 결제·전달 정상? → 유입 감소·계정 제한? → 전환 감소(상품 페이지·후기)? → 특정 상품만? → 시즌(2~3개월 추세)? 순서대로. 당황해서 상품 추가·가격 변경 금지.
- **자동화 졸업**: 직접 반복 작업 월 1시간 이내 + 장애 알림·대응 순서 있음 + 주 1일 완전 비워도 판매·응대 유지.

진행 상황을 `me/progress.md`에 남기고 커밋·push.
