# 유튜브 자막 추출 + 대본 분석

## 1. 자막 가져오기

```bash
pip install -q yt-dlp youtube-transcript-api   # 없을 때만
python3 .claude/skills/youtube-script-analysis/scripts/fetch_transcript.py "<링크>" notes/youtube/analysis/<파일명>-자막.md
```

- 스크립트가 영상 정보(제목, 채널, 길이, 조회수, 설명)와 타임스탬프가 붙은 자막을 저장한다.
  한국어 자막을 먼저 찾고, 없으면 영어 자막을 쓴다.
- 종료 코드가 2이면 자막을 못 가져온 것이다. 클라우드 세션(claude.ai/code)에서는 유튜브가
  서버 IP를 막는 경우가 많다. **자막을 지어내지 말고** 사용자에게 이렇게 안내한다.
  - 유튜브에서 영상 아래 `...더보기 → 스크립트 표시`를 누르고 전체를 복사해 붙여넣어 달라고 한다.
  - 영상 정보(제목, 채널 등)는 가져와졌으면 그대로 쓴다.
- 사용자가 자막을 붙여넣으면 그 내용으로 같은 `-자막.md` 파일을 만들어 저장한다.

## 2. 대본 분석

`notes/youtube/analysis/YYYY-MM-DD-짧은-제목.md` 로 저장한다. 형식:

```markdown
# 대본 분석: 영상 제목

- 링크:
- 채널: / 길이: / 조회수:
- 분석한 날짜: YYYY-MM-DD
- 자막 파일: [자막](./YYYY-MM-DD-짧은-제목-자막.md)
- 태그: #태그1 #태그2

## 한 줄 요약

## 후킹 (처음 0~30초)
- 첫 문장 원문:
- 어떤 기법인지 (질문 / 충격 수치 / 결과 먼저 보여주기 / 공감 / 반전 등)
- 시청자가 "끝까지 봐야겠다"고 느끼게 만드는 약속은 무엇인지

## 전체 구조 (타임라인)
| 구간 | 시간 | 내용 | 역할 (도입/문제제기/해결/근거/사례/정리/CTA) |

## 시청 유지 장치
(예고 문구 "잠시 후 ~", 열린 질문, 리스트 카운트, 장면 전환, 반복되는 핵심 문장 등. 원문과 타임스탬프 함께)

## 말투와 문장 스타일
(문장 길이, 반말/존댓말, 자주 쓰는 표현, 설명 속도, 전문 용어 수준)

## CTA (행동 유도)
(구독·댓글·링크 유도 위치와 문구)

## 잘된 점 / 아쉬운 점
(내 의견임을 표시)

## 내 콘텐츠에 가져다 쓸 템플릿
(이 영상 구조를 빈칸 채우기 형식의 대본 틀로 정리. 쇼츠용 30~60초 버전도 하나)
```

- 자막에 없는 내용을 사실처럼 쓰지 않는다. 분석과 의견은 의견이라고 표시한다.
- 인용은 원문 그대로, 가능하면 타임스탬프를 붙인다.
- 영어 영상이어도 분석은 한국어로 쓴다. 인용은 원문과 번역을 함께 쓴다.

## 3. 목록 갱신

`notes/youtube/INDEX.md` 표 맨 위에 한 줄을 추가한다. 태그에 `#대본분석`을 넣는다.
(날짜 | 제목(분석 파일 링크) | 한 줄 요약 | 태그)
