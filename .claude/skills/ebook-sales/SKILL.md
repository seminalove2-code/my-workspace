# 전자책 판매 (0건 탈출 공식)

상세 근거: `playbooks/06-ebook-sales.md`, 출시 전 점검은 `playbooks/07-threads-cheatkeys.md` 부록 07.

## 가격 전략 — 두 가지 길 (사용자 상황에 맞게 고른다)
- **마켓 검색 판매(크몽·래피드, 아직 팔로워·후기 없음)** → 6번 가격 사다리: 시작 5,000~5,900원 → 후기 5개 9,900원 → 10개+ 14,900원 → 이후 19,900원. 인상은 **평점 4.5 이상 유지**일 때만, 한 번에 한 요소만 변경.
- **내 채널 판매(스레드 → 오픈채팅 퍼널로 신뢰가 쌓인 상태)** → 3번 라인업: 무료~1만원 리드마그넷 / 5~10만원 전자책(저자 99,000원) / 고가 컨설팅·VOD. 가격 기준은 경쟁가가 아니라 "고객 문제를 얼마나 명확히 해결하는가".
두 책의 기준이 다른 이유(차가운 검색 유입 vs 따뜻한 팬 유입)를 사용자에게 한 줄로 설명하고 추천한다.

## A. 등록 패키지 만들기 ("크몽에 올릴 거 준비해줘")
`output/ebooks/<제목>/`의 원고·목차, `me/profile.md`를 읽고 `output/ebooks/<제목>/판매패키지.md`로 한 번에 만든다:
1. **검증 메모**: 비슷한 상품을 크몽·래피드에서 각 10개 이상 찾아 제목 구조·가격대·상세페이지 순서·후기 수를 표로(웹 접근이 되면 직접 조사, 안 되면 사용자에게 검색어 3개를 주고 캡처 요청). 경쟁이 있으면 "시장 검증됨"으로 해석.
2. **제목 후보 3개** = "검색어 + 구체적 결과", 필요하면 괄호로 타겟("(초보자용)"). 보고서 말투 금지.
3. **썸네일 문구** = 핵심 문구 1개 + 신뢰 숫자 1개(실제 숫자만, 없으면 "목차 N개/페이지 수" 같은 사실 숫자).
4. **상세페이지 문구**: 질문형 첫 문장 → 이런 분께 추천 → 해결 → 목차 미리보기 3장 → 후기 → 혜택 → 업데이트 이력. (디자인까지 원하면 `detail-page` 스킬)
5. **카테고리·태그**: 정확한 하위 카테고리, 태그 = 검색량 많은 핵심 1 + 경쟁 적은 롱테일 2~3.
6. **시작 가격** (위 가격 전략).
7. **메시지 템플릿** (이름·상품명만 바꿔 쓰는 틀, 너무 기계적이지 않게):
   - 후기 요청 — 구매 후 24시간 안, 구체적 질문 포함("어떤 부분이 가장 도움이 되셨는지 궁금해요").
   - 재구매 안내 — "이런 것도 있으니 참고하세요" 톤.
   - 부정 후기 답글 — "소중한 의견 감사합니다, 다음 개정판에 보완하겠습니다" + 실제 개선.
   - CS 5종(파일 미수령, 사용법, 환불, 내용이 생각과 다름, 재구매 할인) — 불편 인정 → 해결 방법 순서.
8. **골든타임 3일 계획**: 업로드 직후 3일간 지인 링크 공유·솔직한 의견 요청, 관련 커뮤니티 자연스러운 소개 문구, 문의 즉답.

## B. 출시 전 최종 점검 (07번 12개) — 결과에 체크 표시
프로필 정리 / 계정 정체성과 일치 / 자랑이 아닌 문제 해결 초점 / 신뢰 수준에 맞는 가격 / 리드마그넷→신뢰→판매 퍼널 / 오픈채팅 안내·마감 메시지 / 결제 후 자동(또는 최소 수동) 발송 / CS 템플릿 / 환불 기준 / 판매 공지 문구 / 피드백 채널 / 거래 기록 장소. 빈 곳이 어디인지 알고 시작하면 된다.

## C. "안 팔려요" 진단
순서대로 점검하고 고칠 것 **하나만** 제안: ① 제목이 실제 검색어인가 ② 신뢰 근거(후기·목차 미리보기)가 있는가 — 가격 인하는 답이 아님 ③ 썸네일이 한눈에 들어오는가 ④ 첫머리에 "누구를 위한 상품"인지 있는가. 노출 급감이면 제목·썸네일 소폭 리프레시.

## D. 래피드 이식 & 확장
- 이식 기준: 크몽에서 **후기 10개 + 판매 20건 이상**(책 사례는 8개·15건). 동시 신규 출시 금지. 수수료·정책 확인.
- 래피드: 하위 카테고리 재선택, 태그 재조합, 후반부 후기 스크린샷, 신상품 소폭 할인으로 프로모션 영역 진입, 골든타임 3일 반복.
- 확장: 연결 주제 2~3권 번들 / 시리즈명 + "이 시리즈의 다른 책들" / 완결판 패키지 / 시즌 프로모션(연초 자기계발, 방학·연휴 전 시간관리) / 팁 하나를 카드뉴스·블로그로(무료 공개 5~10%).

## 팔리는 디테일 10가지 (항상 적용)
질문형 첫 문장 · 구체적 숫자 · 썸네일 글자 최소 · 24시간 내 후기 요청 · 목차 미리보기는 이미지 · 가격 끝자리 900 · 상품명 괄호 타겟 · 업데이트 이력 · 모든 후기에 답글 · 한 번에 하나만 바꾸기.

사용자가 판매 숫자·후기 수를 알려 주면 `me/progress.md`에 기록하고 다음 가격 단계/이식 시점을 알려 준다. 커밋·push.
