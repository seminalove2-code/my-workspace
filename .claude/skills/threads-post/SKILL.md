# 스레드 글쓰기 · 퍼널

상세 근거: `playbooks/03-threads-knowledge-startup.md`, `playbooks/07-threads-cheatkeys.md` (원고 예시 9개, 페르소나 10선, 12주 로드맵, 정지 대응 5단계).

## 0. 브리핑 준비 (처음 한 번)
`me/profile.md`의 "페르소나" 칸을 읽는다. 비어 있으면 한 번에 묻고 저장:
**페르소나 · 독자 · 문체 · 금지어** (+ 경험담은 매번 새로).
페르소나는 07번 부록 06의 10가지(AI 부업 선배 / 실전 코치 / 다정한 언니·형 / 데이터 분석가 / 솔직한 실패담 / 바쁜 직장인 / 엄격한 멘토 / 초보 눈높이 선생님 / 유머러스한 동료 / 신뢰감 있는 전문가) 중 고르게 할 수 있다.

## 1. 오늘 글 쓰기 (기본 요청: "오늘 글 써줘")
1. **소재 = 사용자가 오늘 겪은 일 한 줄.** 없으면 바로 지어내지 말고, 클로드가 먼저 질문해서 끌어낸다("최근 AI로 시간 아낀 일 있어요? 반대로 기대만큼 안 된 일은요?"). 사용자가 "그냥 알아서"라고 하면 profile의 경험·주제로 정보형 글을 쓰되, 없는 경험담·숫자를 지어내지 않는다.
2. 글 **2개**를 만든다(유형이 다르게: 정보형 / 공감형 / 스토리형 중 2개).
3. 각 글 구조:
   - **첫 줄 = 후킹 5공식 중 하나**: 질문형("혹시 아직도 ~하시나요?") / 반전형("다들 ~라고 하는데, 사실은 아닙니다") / 숫자형 / 경고형("이거 모르면 계속 손해") / 고백형("저도 처음엔 이거 몰라서 3주 실패").
   - 본문 = **공감 → 문제 제기 → 해결 팁(1초 안에 따라 할 수 있는 것 하나, 가능하면 복사해 쓸 문장) → 행동 유도(저장/질문으로 마무리)**.
   - **3초 룰**: 한 줄에 한 문장, 줄바꿈 많이, 초등학생도 이해할 말. 스레드 문화상 기본은 반말(사용자 문체 설정이 우선).
   - 금지어: "~할 수 있습니다", "따라서", "결론적으로" + 사용자 금지어. 해시태그 도배 금지.
4. 각 글 아래에 첫 줄 대안 2개(다른 후킹 유형)를 붙인다.
5. 마지막에 한 줄: "본인 말투·감정 한 줄만 얹어서 올리세요(3분)."
6. `output/threads/YYYY-MM-DD.md`에 저장. 업로드 가이드: 골든타임 07~09 / 12~13 / 20~23시, **같은 계정 2시간 간격**, 계정당 하루 2개 정도.

## 2. 기타 요청
- **프로필**: 3단계 — ① 닉네임 | 전문 분야·핵심 목표 ② 숫자로 증명하는 대표 성과(실제 숫자만) ③ 무료 자료/오픈채팅 링크 안내 + 👇👇. 처음엔 판매 링크 대신 리드마그넷 링크. 포지셔닝 문장 "나는 [무엇]을 [어떤 방식]으로 증명한 사람이다" 후보 3개.
- **계정 3개 분산**: 메인(스토리형·판매 링크) / 서브A(정보형) / 서브B(공감형). 요청 시 3계정용 글을 역할별로 나눠 쓴다.
- **답글**: 같은 의미, 다른 표현 3버전(이모티콘도 다르게) — 같은 문구 반복은 정지 원인.
- **후킹 실험 주간**: 같은 소재로 5유형 버전 → 사용자가 반응(좋아요·저장·댓글)을 알려 주면 상위 3개 첫 줄 패턴 분석 → 다음 주 그 패턴으로.
- **재활용**: 반응 좋았던 글은 후킹 유형·문단 순서만 바꿔 며칠 뒤 재게시(2~3회). 카드뉴스 5장(한 장 한 문장) / 60초 쇼츠 대본(오프닝 3초 후킹 → 본문 → 마무리).
- **시리즈**: 반응 최고 글에 이름 붙여 "OO공식" 3부작.
- **오픈채팅 퍼널(4단계)**: 스레드 → 무료 리드마그넷(20페이지 내외) → 오픈채팅 입장 시 **바로 주지 않고 "7일 뒤에 드릴게요"** → 1~7일차 안내·가치 정보 + "이제 5일/3일 남았어요" → 판매 시 **전체태그 공지**. 요청 시 입장 인사말, 1~7일차 메시지, 전체공지 문구(부담 없지만 행동 유도)를 한 번에 만든다. `output/funnel/`에 저장.
- **업로드 전 정지 방지 체크**: 2시간 이내 재업로드 X / 댓글 문구 동일 X / DM 과다 X / 프로필 링크 스팸성 X / 같은 해시태그·키워드 도배 X.
- **계정 정지 대응 5단계**: ① 그림자 정지(로그인 O·노출 X)인지 완전 정지인지 ② 최근 반복 댓글·DM 과다·짧은 간격 점검 ③ 메타 공식 이의제기 — 감정 없이 담담하게(요청 시 소명문 초안) ④ 서브 계정·오픈채팅으로 즉시 안내 전환 ⑤ 실패해도 보완해 재시도 + 백업 병행.
- **월말 회고**: 조회수·판매·반응 좋은 글을 받아 다음 달 개선점 3가지.
