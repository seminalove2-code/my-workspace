# 이메일 펀널 (스티비 4단계 자동화 공식)

상세 근거: `playbooks/05-email-funnel.md`. 순서를 건너뛰지 않는다: 도달이 안 되면 나머지는 소용없다.

## 0. 현재 위치 진단
`me/progress.md`를 보고, 없으면 묻는다: 스티비 가입 여부 / 내 도메인 보유 여부 / 구독자 수 / 오픈율 / 웰컴 메일 유무 / 팔 상품.
→ 4단계 중 어디인지 알려 주고, 그 단계부터 진행.

## 1. 도달 (Deliver) — 사용자가 직접 설정, Claude는 단계별 안내
1. 진단: 평소 왕래 없는 다른 계정(네이버·다음·지메일 각각)으로 받아 스팸함 확인.
2. 도메인이 없으면 가비아 등에서 구매(무료 메일 주소로는 대량 발송 인증 불가).
3. 스티비 → "발신 도메인 인증"에서 SPF(TXT), DKIM(CNAME 또는 TXT), DMARC(TXT) 값 확인 → 도메인 업체 DNS 관리에 그대로 붙여넣기(레코드 타입 정확히, 앞뒤 공백·따옴표 주의).
4. **DMARC는 `p=none`(관찰 모드)으로 시작** — 처음부터 reject 금지.
5. 반영 수 분~48시간 → 스티비 "인증 확인" → MXToolbox로 확인. 오픈율은 1~2주에 걸쳐 오름. 이 기간에 발송 빈도 늘리지 않기.

## 2. 공감 (Relate) — Claude가 작성
- **세그먼트**: 시작은 2그룹(신규/기존 또는 구매/미구매) → 나중에 3~4그룹(가입 기간 / 클릭 행동 / 구매 여부). 그룹별 메시지 한 줄씩 제안. 10개 이상 쪼개지 않기.
- **웰컴 시퀀스 3통** (`output/emails/welcome.md`), 한 통에 메시지 하나:
  1. 가입 직후 — 소개와 공감(내가 누구인지, 왜 시작했는지, 독자 고민 공감). **판매 언급 0.** 제목은 개인적·다정하게(예: "안녕하세요, 저를 소개할게요").
  2. 2~3일 후 — 가치 증명(바로 써먹을 노하우 하나를 구체 예시로).
  3. 5~7일 후 — 자연스러운 제안(처음으로 상품 소개).
  하루 간격 연속 발송 금지. 각 메일에 제목 A/B 2안을 붙인다. 사용자 경험은 `me/profile.md`에서 가져오고 없는 사실은 지어내지 않는다.
- 스레드 오픈채팅 퍼널과 연결하려면: 리드마그넷 신청을 이메일로 받고 "7일 뒤 지급"을 웰컴 시퀀스와 맞춘다(3번 책 퍼널 + 7번 확장 아이디어 1번 '뉴스레터 연계').

## 3. 정교화 (Refine)
- 매 발송마다 **확실히 다른 접근의 제목 2개**(숫자·구체 정보형 vs 질문형/단정형). 과장 금지 — 오픈율만 오르고 클릭·구매는 떨어진다.
- 스티비 A/B: 전체의 20~30%에 테스트 → 몇 시간 뒤 승자 자동 발송. 오픈율(제목) + **클릭률(내용, 더 중요)** 기록. 한 번 결과로 단정하지 않기. 발신자 이름(개인명 vs 브랜드)·발송 시간도 테스트.
- 사용자가 숫자를 주면 `output/emails/지표.md`에 주차별로 쌓고 패턴을 요약한다.

## 4. 지속 (Sustain)
- 발송 요일·시간 고정, 며칠 전 완성해 예약.
- 반응 기반 자동 메일 1개+: 특정 링크 클릭 → 며칠 뒤 관련 후속 메일 / 장기 미오픈 → 리마인드.
- **휴면 정리(분기 1회)**: 3개월+ 미오픈 → 재참여 메일 1통("저희 소식 계속 받아보실래요?") → 무반응은 정기 리스트에서 분리(삭제 X).
- 자동 메일 문구도 직접 보낸 것처럼 자연스럽게. 월 1회 자동화 규칙 점검(끝난 프로모션 안내 사고 방지), 분기 1회 MXToolbox.

## 기준값
업계 오픈율 평균 20%, 30%+ 잘함. 저자: 15% → 28%(인증 2주 후) → 38%, 첫 구매 전환 3% → 11%, 업무 주 5시간 → 40분.

진행 상황을 `me/progress.md`에 남기고 커밋·push.
