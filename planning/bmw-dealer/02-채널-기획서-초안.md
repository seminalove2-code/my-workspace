# BMW 공식딜러 채널 기획서 (초안)

- 작성: 2026-10-21
- 근거: `01-수입차-딜러채널-분석.md`

## 0. 전제 조건

- **공식딜러라 프로모션·할인 금액은 영상에 못 쓴다.** → 월별 프로모션 영상, 할인액 썸네일, 실구매가 공개는 하지 않는다.
- **전시장에 차량이 항상 있다.** → 실물 차량으로 비교·설명·출고 영상을 언제든 찍을 수 있다. 이게 우리 최대 자산이다.
- 목표: **구매 문의(전화·문자·카톡 상담)**

## 1. 포지션

**"BMW 사기 전에 가장 먼저 물어보고 싶은 딜러"**

- 다른 딜러 채널: 할인 경쟁 (매달 같은 프로모션, 과장 문구)
- 우리: **실물로 보여 주고, 솔직하게 골라 주는 딜러**
- 가격을 못 쓰는 제약을 장점으로 바꾼다
  - "가격은 영상에 담을 수 없어서, 상담으로만 정확하게 알려드립니다" → 영상이 곧 상담으로 이어지는 동선

## 2. 콘텐츠 기둥 (비율)

| 기둥 | 비율 | 내용 | 전시장 활용 | 왜 |
|---|---|---|---|---|
| **① 구매 결정 가이드** | 40% | "520i vs 530i", "X5 5인승 vs 7인승", "X3 20 vs 30", "이런 분은 X5 말고 X3" | **두 대를 나란히 세우고** 실물 비교 | 살 사람이 검색해서 들어온다. 문의에 가장 가깝다. 경쟁 영상 1~4만 꾸준 |
| **② 고객 출고 스토리** | 30% | "왜 이 차를, 왜 이 딜러에게" 고객 인터뷰 + 출고 현장 | 출고 세리머니 | 사회적 증거. 딜러 채널 최고 히트가 여기서 많이 나옴 (노부부 iX60 12만, X7 가족 13만) |
| **③ 솔직 리뷰·비추천** | 20% | "이런 분은 이 차 사지 마세요", "카탈로그에 없는 단점", "딜러가 직접 타 보니" | 시승차·전시차로 직접 시연 | "단점도 말해 주는 딜러" = 신뢰 (비엠조스타 X7 솔직 리뷰 15만) |
| **④ 출고 후 사용법** | 10% | 디지털키, 자동 주차, 카플레이, 숨은 기능 | 전시차로 시연 | 오너들이 검색해서 봄 → 다음 차·지인 소개 (자동 주차 3.6만, 세팅 가이드 2.2만) |

※ 프로모션형은 하지 않는다.

## 3. 첫 달 업로드 순서 (12편, 주 3편)

| 주차 | 순서 | 기둥 | 제목 초안 |
|---|---|---|---|
| 1주 | 1 | ① | 520i 살까, 530i 살까? 전시장에 두 대 세워 놓고 직접 비교했습니다 |
| | 2 | ③ | BMW 딜러가 솔직하게 말합니다. 이런 분은 X5 사지 마세요 |
| | 3 | ② | (첫 출고 고객) "○○ 고객님이 이 차를 고른 진짜 이유" |
| 2주 | 4 | ① | X5 5인승 vs 7인승, 3열 직접 앉아 봤습니다 |
| | 5 | ④ | BMW 출고 첫날 꼭 해야 할 세팅 7가지 (디지털키·자동 주차·카플레이) |
| | 6 | ① | X3 20 vs 30, 차이를 모르면 돈 낭비합니다 |
| 3주 | 7 | ③ | 카탈로그에는 없는 5시리즈 단점 3가지 |
| | 8 | ② | (출고 스토리) 첫 수입차로 3시리즈를 고른 사회초년생 |
| | 9 | ① | 3시리즈 vs 5시리즈, 1,000만 원 차이 값어치 할까? (가격 대신 차이점 중심) |
| 4주 | 10 | ① | 전기차 처음이라면? i4 vs i5 vs iX3 실물 비교 |
| | 11 | ④ | BMW 자동 주차, 이렇게 쓰면 됩니다 (실제 시연) |
| | 12 | ② | (출고 스토리) 다른 지역에서 일부러 찾아오신 고객님 이야기 |

- ①은 검색어가 제목 앞쪽에 오게 쓴다 ("520i 530i", "X5 7인승")
- ②는 매달 최소 3편. 고객 동의가 확보되는 대로 순서를 앞당긴다
- 할인·가격 숫자 대신 **차이점·적합한 사람**으로 결론을 낸다

## 4. 영상 구조 (구매 결정 가이드 기준, 10~15분)

| 구간 | 내용 |
|---|---|
| 0~30초 | 질문 그대로 시작 ("520i랑 530i, 매장에서 제일 많이 받는 질문입니다") → 흔한 통념 ("다들 520i면 충분하다고 하시죠") → 반전 예고 ("그런데 이런 분은 530i를 사셔야 후회 안 합니다") → 약속 ("끝까지 보시면 내가 어느 쪽인지 바로 아실 겁니다") |
| 본문 | 두 대를 나란히 놓고 항목별 비교 (외관 → 실내 → 주행 → 유지) / 항목마다 "이런 분께는 ○○" 결론 |
| 솔직 구간 | 각 차의 단점 하나씩 반드시 |
| 결론 | "이런 분은 520i, 이런 분은 530i" 한 화면 정리 |
| 마무리 | "가격과 이번 달 조건은 영상에 담을 수 없어서, 상담으로 정확히 알려드립니다" + 상담 방법 안내 |

앞서 분석한 공통 원칙도 적용한다: 통념 뒤집기 훅, 소리만 들어도 이해되는 설명, 단점도 말하는 차분한 톤.

## 5. 썸네일 규칙

- **딜러 본인 얼굴 + 실물 차량** (전시장 조명)
- 글씨는 2줄 이내, 질문형·고백형: "520i면 충분할까?", "이런 분은 사지 마세요"
- 출고 스토리는 고객과 차 (리본·꽃다발), 얼굴은 동의 범위에 맞춰 흐림 처리
- 할인액·가격·"역대급" 같은 문구는 쓰지 않는다

## 6. 문의 동선 (리드 확보)

1. **채널 소개**: 실명 + 소속 전시장 + 직함 + 상담 연락처
2. **영상 설명란 첫 줄**: 상담 연락처와 전시장 위치
3. **고정 댓글**: "이 영상의 차, 지금 전시장에서 직접 보실 수 있습니다. 시승·상담 예약은 ○○로"
4. **영상 마지막 멘트**: 가격은 상담에서 → 전시장 방문·시승 유도
5. **문의 들어오면 출처 기록**: "어떤 영상 보고 연락하셨어요?" → 잘 되는 영상 유형을 더 만든다
