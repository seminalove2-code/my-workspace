## 1. 영어권 공통 구조 (한국 경제상담소와 다른 점)

- **짧다 (5~14분), 연대기 구조가 많다.** 그런데도 터지는 이유: 대상이 세계적 브랜드라 검색·추천 수요 자체가 크다. 한국어로는 같은 방식(연대기)이 경제상담소 딤채·테무처럼 부진할 위험이 있다 → **우리는 영어권 "사실·원인"만 가져오고, 구조는 한국식 원인 N가지로 바꾼다.**
- **훅은 "모순 한 줄"**:
  - 스타벅스: 중국에선 15시간마다 새 매장 ↔ 호주에선 3분의 2를 닫았다
  - 월마트: 세계 최대 고용주가 독일에서 9년 만에 1조 원대 손실 후 철수
  - 코스트코: 세상 모든 게 올랐는데 1.5달러는 40년 그대로 → "왜 일부러 손해를 볼까?"
- **통념 먼저 말하고 깨기**는 영어권에도 있다: 토이저러스 "아마 아마존 때문이라고 생각하셨죠? 그보다 훨씬 깊다"(실제로는 사모펀드 차입 인수 빚)
- **현지 문화 vs 본사 방식 충돌**이 해외 철수의 기본 원인 틀: 스타벅스(호주 카페 문화·플랫화이트, 단 음료·비싼 값, 너무 빠른 확장), 월마트(독일 법·노조·직원 미소 강요·알디·리들)
- **같은 조건의 성공 사례 대비**: 스타벅스 실패 ↔ 같은 미국 체인 글로리아진스는 호주 400곳 성공 → 원인을 증명하는 장치

## 3. 결말 비교

- 영어권은 결말이 약하다 ("앞으로 지켜보자", "댓글로 다음 주제 추천"). Cheddar만 한 줄 교훈("현지인이 언제나 옳다").
- 생존형 Claire's는 **화자의 개인 추억**(어릴 때 쇼핑몰)으로 시작하고 끝낸다 → 듣는 시청자가 몰입. 우리도 각 항목 ② 전성기 추억에 이 방식(누구나 겪은 장면)을 쓴다.

## 4. 결론

- 해외 주제는 영어권에 이미 정리된 **원인·숫자를 출처로 확인해 재료로 쓰고**, 구조는 한국식(TOP N 또는 원인 N가지 + 자가진단 + 찬반 질문)으로 다시 짠다.
- 모든 해외 편은 **한국 연결 장면을 훅 안에** 넣는다 (한국 매장 철수일, 한국계 창업자, 한국 회사가 인수 등).
