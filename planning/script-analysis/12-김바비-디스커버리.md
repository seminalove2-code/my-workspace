# 대본 분석 12: 김바비의 바비위키 "듣보잡 디스커버리가 1년 만에 초대박 터진 이유" (티핑포인트 ep.13)

- 영상: https://youtu.be/Ii7SqMvpzLE (61만 회, 약 3년 전, 약 11:50)
- 채널: 김바비의 바비위키 (구독 20만대, 진행자 얼굴 출연형)
- 자료: 사용자가 준 챕터·자막 전문. 원문은 저장하지 않음
- 유형: 역주행·부활 (우리 T3 "본고장에선 망했는데 한국에서만 대박"과 대상이 크게 겹침)

## 1. 훅 (1분 10초)

1. **누구나 본 현상**: 요즘 많이 보이는 코닥·예일·팬암 옷이 다 한국 브랜드
2. **한국식 비유 한 방**: "우리나라로 치면 EBS 패딩, 아침마당 패딩" — 웃기고, 한 번 들으면 안 잊힌다
3. **질문**: 왜 굳이 패션과 상관없는 남의 나라 방송국·대학·카메라 회사 로고를 입을까?
4. **자연 실험 미끼**: 같은 옷을 "더 도어"로 냈다가 망했는데, **로고만 디스커버리로 바꿔서** 3년 만에 2,500억
5. **큰 질문**: 어떻게 연매출 2조 상장사가 됐나 → 시리즈 고정 문장("거대한 변화는 작은 사건에서 시작합니다") + 진행자 소개

## 2. 구성

| 장 | 내용 | 장치 |
|---|---|---|
| 1 | 코엑스에서 본 팬암 매장(진행자 경험) → 팬암은 오래전 망한 미국 항공사(영화 "캐치 미 이프 유 캔") → CNN·코닥·폴라로이드·내셔널지오그래픽·빌보드·예일 | 개인 목격담 + 영화 고리 |
| 2 | 창업자: 핑크퐁 삼성출판사 창업주의 둘째 아들 → 아트박스 → 베네통 합작(1992) → "브랜드를 사와서 내 옷에 붙이면?" 역발상 | 뜻밖의 인맥 연결 |
| 3 | 1997 MLB 라이선스(당시엔 MLB를 모르는 사람이 많았다, NFL도 했는데 실패) → IMF에 돈줄 베네통 포기 → 1998 박찬호 신드롬 → 모자가 매출의 30% | 대담한 결정 + 시대의 행운 |
| 4 | 2009 노스페이스 4천억(78개 브랜드 합친 매출과 맞먹어 "현타") → 채도 낮추고 핏 강조한 일상형 아웃도어 "더 도어" → **8개월 만에 중단** | 교복 노스페이스의 집단 기억 |
| 5 | 같은 옷에 디스커버리 이름·와펜 → 2년 1,380억, 3년 2,500억, 빅3 → MLB 아시아 판권으로 중국 진출, 두 브랜드 1조 → 내셔널지오그래픽·코닥·예일·CNN·팬암이 따라 함 | **자연 실험 결과 공개** |
| 결말 | 진행자 의견("저는 부정적으로 안 봐요, 곰표 밀맥주도 그럼 문제여야") → 소비자는 상품이 아니라 이미지를 산다 → 시리즈 문장 회수 → "유명한 로고만 붙인다고 팔리진 않는다" 경고 | 의견 표시 + 균형 |

## 3. 핵심 기법

1. **자연 실험이 반전의 증거**: 같은 제품, 다른 이름 → 망함 vs 2,500억. "브랜드의 힘"을 말로 주장하지 않고 결과로 보여 준다 (분석 01의 "자연 실험" 기법과 같음)
2. **한국식 비유로 낯선 현상 번역**: "EBS 패딩"
3. **뜻밖의 연결 고리**: 핑크퐁 집안, 박찬호, 공유 광고, 노스페이스 교복 — 시청자가 아는 것들로 사슬을 만든다
4. **결정의 순간을 극적으로**: "회사 돈줄을 외환위기 한복판에 포기"
5. **진행자 의견은 의견으로**: "저는 그렇게 보진 않아요" + 반론 예시(곰표)
6. 결말에 경고 한 줄로 균형

## 4. 우리 T3에 주는 영향 (중요)

- 이 영상이 이미 **"라이선스로 남의 이름을 빌려 성공한 F&F 이야기"**(MLB·디스커버리)를 깊게 다뤘다(61만). 우리가 같은 각도로 다시 설명하면 재탕이 된다
- 우리 T3의 각도는 **"본고장에선 망했는데 한국에선 대박"**이다. 이 각도에 가장 잘 맞는 건 **본사가 실제로 무너진 이름**:
  - 코닥(2012 파산 신청) → 한국 코닥어패럴 2025년 1,044억, 일본 하라주쿠 역진출
  - **팬암(미국 항공사, 1991년 운항 중단)** → 한국 의류 브랜드 (이 영상이 알려 준 사례, 우리 목록에 없던 것)
- 반대로 MLB·디스커버리는 **본고장이 망한 게 아니다**(리그·방송은 멀쩡). 우리 각도와 덜 맞고, 이 영상과 가장 많이 겹친다
- **T3 수정 제안**: 근거가 약한 아웃백을 빼고 **팬암**을 넣는다. MLB·디스커버리는 "본고장엔 옷이 없는데 한국에서 생긴 브랜드" 한 항목으로 묶고, 김바비가 다룬 F&F 창업 이야기는 짧게 지나간다. 대신 우리만의 새 숫자(2025년 매출, 역수출)와 현장 화면(매장)으로 차별화
- 가져올 장치: "우리나라로 치면 ○○ 패딩" 같은 한국식 비유, 같은 옷 다른 이름의 자연 실험(더 도어 → 디스커버리)은 2위 항목의 반전 증거로 짧게 인용(출처 명시)
