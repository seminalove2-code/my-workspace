# 대본 분석 01: 경제상담소 "차라리 일본 가고 맙니다" 동남아 휴양지 몰락 TOP5

- 영상: https://youtu.be/UOa3y1H9e2Q (294만 회, 2026-10-20 기준, 22분 22초)
- 자료: 사용자가 제공한 자동 자막 스크립트 (오탈자 있음). 원문 전체는 저장하지 않고 분석만 남김.
- 대본에 나오는 수치·인용은 아직 따로 확인하지 않았음

## 1. 전체 구조

| 구간 | 내용 | 역할 |
|---|---|---|
| 훅 (약 0:00~0:40) | 전성기 장면 → 지금은 텅 빔 → 통념("물가 때문이죠?") 부정 → "진짜 이유는 따로" → 5곳 약속 | 첫 30초 |
| 5위 태국 푸켓 | 원인: **환율** | 본문 |
| 4위 세부 | 원인: **옆 나라와 가격 비교 (반값 베트남)** | 본문 |
| 3위 앙코르와트 | 원인: **뉴스 하나가 만든 공포** | 본문 |
| 2위 코타키나발루 | 원인: **붐의 착시 (절반은 원래 안 돌아왔다)** | 본문 |
| 1위 보라카이 | 원인: **하늘길이 한 편씩 끊김** | 본문 |
| 결말 | 다섯 이유 요약 → 빈자리는 다른 나라가 채움 → 일본엔 다섯 가지가 다 있다 → 제목 문장의 의미 뒤집기 | 여운 + 댓글 유도 |

**핵심: TOP5가 같은 이유의 반복이 아니라, 다섯 개의 서로 다른 원인이다.** 그래서 22분이 지루하지 않다.

## 2. 첫 30초 (훅) 분해

1. **제목 문장 그대로 시작**: "그 돈이면 일본 가요" → 썸네일·제목의 약속을 0초에 확인
2. **전성기의 구체적 장면**: "여권만 들고 가면 섬 전체가 환호", "비행기가 모자라 하루 20편", "현지 상인들이 한국어로 호객"
3. **급반전**: "그런데 지금 그 관광지에 한국인이 없습니다. 1년 만에 40%가 발길을 끊었습니다"
4. **통념 제시 후 부정**: "물가가 비싸져서 일본으로 돌렸다고 생각하시죠? 천만에요. 진짜 이유는 따로 있었습니다"
5. **미스터리 미끼**: "단순히 비싸서라기엔 지난 1년 동안 벌어진 일들이 너무 이상했거든요"
6. **약속 + 즉시 출발**: "다섯 곳을 따라가며 진짜 이유를 하나씩… 5위부터 시작합니다"

→ 유튜브랜딩 영상의 "증거 제시 + 이득 못 박기"보다 한 단계 위: **통념을 먼저 꺼내고 깨는 구조**가 훅 자체다.

## 3. 순위마다 반복되는 8단 구조 (가장 중요)

| 단계 | 하는 일 | 푸켓 예 | 세부 예 |
|---|---|---|---|
| ① 수상한 현재 장면 | 최근의 이상한 장면 하나로 시작 (미스터리 단서) | 방콕 공항 환전소에서 원화 거절 | 막탄섬 한국인 전용 24시간 경찰 창구 |
| ② 전성기 추억 | 시청자 기억을 건드리는 한국인 디테일 | 신혼 앨범의 푸켓, 2007년 신문 "신부 무료", "속도위반 할인" | 필리핀 영어캠프, 교육청이 학생 보냄, "경기도 세부시" |
| ③ 지금 숫자 | 감이 오는 표현으로 바꾼 숫자 | 한국 손님 9위, 프랑스·독일보다 뒤 | 어학원 학생 7명 중 1명 |
| ④ 흔한 용의자 (통념) | 시청자가 떠올릴 이유를 먼저 말해 줌 | 물가 | 총기 사건 |
| ⑤ 반전 증거 | 공식 증언·통계로 통념을 뒤집음 | 태국 관광청 "물가 아니라 환율" | 전 관광장관 출신 행정관 "총 아니라 값" |
| ⑥ 지갑 환산 | 추상 숫자를 내 돈으로 | 1바트 41원→47원 = 41만 원 여행이 47만 원 | 세부 한 번 갈 돈이면 베트남 두 번 |
| ⑦ 한 줄 통찰 | 외우고 싶은 문장으로 원인을 정리 | "셈이 쉬워서 고르던 바다는 셈이 어긋나는 순간 가장 먼저 목록에서 내려온다" | "값으로 모인 손님은 값이 어긋나면 흩어진다" |
| ⑧ 처음 장면 회수 + 다음 예고 | 오프닝 장면으로 돌아와 마무리하고, 다음 순위를 대비시켜 예고 | "신부는 무료라던 바다가 지금 아홉 번째" → "4위는 사정이 달라요" | "경찰이 밤새 지켜도 반값 베트남은 안 사라진다" → "3위는 견줘볼 틈조차 없었어요" |

### 순위 사이 연결 문장 (리텐션 장치)
- 5→4: "4위는 사정이 달라요. 옆 나라 바다와 나란히 놓이는 순간 승부가 끝난 섬"
- 4→3: "3위는 견줘볼 틈조차 없었어요. 뉴스 하나에 예약이 한꺼번에 취소된 곳"
- 3→2: "2위는 다릅니다. 이렇다 할 사건 하나 없이 조용히 손님이 빠져나간 바다"
- 2→1: "1위는 그 반대입니다. 떠났다가 다시 돌아오기까지 했던 섬"

→ 다음 순위의 **원인 유형만 살짝 공개**해서 궁금증을 건다. 시청자가 "다음은 뭐지?"로 계속 본다.

## 4. 반전 증거를 만드는 기법

- **공식 관계자의 증언**: 관광청, 주 행정관, 관광장관 (그것도 "예전에 한국 손님을 맞던 사람"이라는 이력 반전까지)
- **자연 실험**: "비행기가 줄어서? 그런데 새 직항이 생겼는데도 손님은 더 줄었다" (코타키나발루)
- **지도 펼치기**: "사건은 남쪽 산에서 났는데 시엠립은 한참 떨어져 있다" (앙코르와트)
- **과거 비교**: "2018년 6개월 폐쇄 뒤엔 40만 명이 돌아왔다. 그런데 지금은?" (보라카이)
- **숫자의 착시 깨기**: "720명→6만 8천 명이라 붐 같았지만, 코로나 전의 절반도 안 돌아온 것" (코타키나발루)

## 5. 숫자 표현법

- 퍼센트 대신 분수·비율: "열에 둘", "넷에 하나", "일곱에 한 명", "절반도 안 돼요"
- 지갑 환산: 환율 차이를 "41만 원 여행이 47만 원"으로
- 체감 비교: "섬 전체 하루 한국 손님 260명 ≈ 전성기 상인 한 명이 자기 구역에서 맞던 200명"
- 순위: "9번째, 프랑스·독일·말레이시아보다 뒤"

## 6. 결말 구조

1. 다섯 이유를 한 줄씩 요약 (환율 / 가격 비교 / 공포 / 붐의 착시 / 하늘길)
2. **관점 뒤집기**: "그 빈자리는 비어 있었을까요? 아닙니다" → 다른 나라 손님이 채움 → "바다는 여전히 붐비는데 우리만 빠졌다"
3. **제목 회수**: 일본에는 다섯 가지(환율로 셈이 쉬움, 안심, 가까운 하늘길)가 다 있다 → "그 돈이면 일본"이라는 말 속의 "돈"은 지갑 속 돈만이 아니었다
4. **균형 잡기**: "이 중 하나라도 흔들리면 일본도 같은 질문 앞에 설 수 있다"
5. **댓글 유도를 내용과 연결**: "다시 부르려면 뭐가 먼저일까요?" + "다녀오신 그 바다 이름을 남겨 주세요" (개인 추억을 꺼내게 함)
6. **구독 유도도 내용형**: "다음 여행지 이야기도 받아보세요. 숫자 뒤에 가려진 진짜 사정을 계속 따라가겠습니다"

## 7. 문체

- 존댓말 대화체: "~거든요", "~죠", "~잖아요", "여러분"
- 짧은 문장, 30초마다 질문 던지기 ("왜 이렇게 됐을까요?", "손님도 따라 늘었을까요?")
- 의견은 표시: "제가 보기엔"
- 썸네일·제목은 자극적이지만 **대본 톤은 차분한 다큐**. 과장 대신 출처(신문, 관광청, 협회 통계, 교민 증언)로 설득

## 8. 우리 대본에 가져올 것 (초안, 다음 대본들과 비교 후 확정)

1. 훅: 제목 문장 → 전성기 장면 → 급반전 숫자 → 통념 부정 → 미스터리 미끼 → 약속
2. TOP N은 **원인이 서로 다른 항목**으로 고른다 (같은 이유 반복 금지)
3. 항목마다 8단 구조: 수상한 현재 장면 → 전성기 추억 → 지금 숫자 → 흔한 용의자 → 반전 증거 → 지갑 환산 → 한 줄 통찰 → 장면 회수 + 다음 예고
4. 숫자는 분수·지갑·체감 비교로
5. 결말은 관점 뒤집기 + 제목 회수 + 개인 추억 댓글 유도

## 9. 우리가 더 잘할 수 있는 부분 (제 의견)

- **출처 표시**: 대본은 출처가 풍부하지만, 화면에 출처가 나오는지는 확인 못 함. 우리는 화면 하단에 출처를 고정 표기해서 신뢰를 차별점으로
- **순위 기준 불명확**: 왜 보라카이가 1위인지(감소 폭?) 명시가 없음. 우리는 순위 기준을 훅에서 한 줄로 밝힌다
- **결말 길이**: 결말이 길어서 이탈 가능성. 우리는 요약을 표 화면 하나로 압축
