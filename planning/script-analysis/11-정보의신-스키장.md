## 2. 왜 터졌나 (대본에서 보이는 것)

1. **직접 가서 찍었다.** "6인 리프트에 저 혼자", "예전엔 40~50분 줄 섰던 케이블카에 대기 0" — 숫자보다 강한 증거. 다른 채널은 따라 할 수 없고, 저작권 문제도 없는 **자기 화면**
2. **시청자 자신에게 묻는 첫 문장**: "최근 스키장 가 본 적 있으신가요?" (파크랜드 "최근 정장 사 입어 본 적 있으십니까?"와 같은 장치. 히트작 3편 중 2편)
3. **"왜 망했나"에서 끝나지 않고 "지금 어떻게 버티나"**까지: 프리미엄 시즌권, 통합 시즌권, 시간권, 케이블카 카페 → 시청자가 바로 써먹을 정보(37만 원에 5곳 이용)가 섞여 있다
4. **제철**: 2월 초 시즌 한복판에 올렸다
5. 채널 힘(구독 51만)과 일찍 올린 것(2025년 2월, 경쟁 적을 때) — 대본 밖 요인

## 3. 흥망학회 TOP7과 비교

| | 정보의 신 (65만) | 흥망학회 (63회, 2일차) |
|---|---|---|
| 형식 | 현장 리포트 + 업계 대응 | TOP7 역순, 항목마다 다른 원인 |
| 대본 기교 | 적다(질문 사슬·콜백 거의 없음) | 많다(반대 방향 예고, 이중 반전, 자가진단) |
| 증거 | 직접 촬영 + 협회 데이터 | 기사·협회 데이터 |
| 길이 | 10분 | 20분 36초 |
| 채널 | 구독 51만 | 개설 3일 |

→ 대본 기교는 흥망학회가 위인데, 조회수 비교는 채널 크기·시기 차이 때문에 할 수 없다(분석 08 정정과 같은 이유). 확실히 말할 수 있는 건 **정보의 신에게는 흥망학회에 없는 "현장 화면"이 있었다**는 것.

## 4. 우리 채널에 가져올 것

1. **직접 찍은 현장 장면을 편마다 하나 이상** (직원 촬영). 남이 따라 할 수 없고, 신뢰가 오르고, 저작권 걱정이 없다
   - T2 약국: 한 거리에서 약국 간판 세어 보기, 같은 감기약을 편의점·약국·창고형 약국에서 사서 영수증 비교, 병원 건물 1층 약국 나란히 있는 장면
   - T1 철수: 옛 까르푸·월마트 자리의 지금(다른 마트·건물), 세포라 명동점 자리
   - T3 역주행: 코닥어패럴 매장, 써브웨이 매장의 점심 줄
2. **첫 문장 후보로 "최근 ○○ 해 보신 적 있으신가요?"** 를 늘 검토한다
3. 몰락·생존 편 결말 직전에 **"그래서 지금 어떻게 버티나 / 우리는 뭘 알면 이득인가"** 한 덩어리를 둔다
4. 조심: 자동 자막 숫자는 인용하지 않는다. 출처 원문으로만
