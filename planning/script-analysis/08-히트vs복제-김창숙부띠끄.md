# 대본 분석 08: 같은 주제, 히트작 vs 복제작 (김창숙부띠끄)

- 히트: 브랜드_B면 https://youtu.be/H_hJs4xSIFc — 44.8만 회(9일), 13:12 (분석 07)
- 복제: 경제 해부실 https://youtu.be/7CuvombdWEQ — 29회(1일), 9:56 "손님 없는 김창숙부띠끄는 왜 안 망할까? 34년 만의 반전"
- 자료: 사용자가 준 두 영상의 자동 자막 전문. 원문은 저장하지 않음
- 주의: 복제작은 히트작보다 8일 늦게 올라왔다. **늦게 온 것 자체가 큰 감점**이라 조회수 차이를 대본 탓으로만 볼 수는 없다. 아래는 "대본에서 보이는 차이"다

> **정정 (2026-10-23, 사용자 지적)**: "복제작은 거의 0이라 실패"라는 판단은 성급했다. 비교한 복제작들은 올린 지 1~3일, 대부분 **이제 막 시작한 채널**이다(흥망학회는 영상 3편, 개설 3일). 히트작 채널 브랜드_B면도 3주 전 첫 영상들은 680·339·1천 회였고 **7번째 영상에서 44만**이 나왔다. 그러니 조회수만으로 "복제라서 안 됐다"고 말할 수 없다. 이 문서는 **조회수의 원인 분석이 아니라 대본 품질 비교**로만 쓴다. 복제작들의 조회수는 2주 뒤 다시 확인한다.

## 1. 한눈 비교

| 항목 | 히트 (브랜드_B면) | 복제 (경제 해부실) |
|---|---|---|
| 훅의 핵심 숫자 | **이익 100억 가까이** (어떻게 버나 = 제목의 질문에 정면) | 기부 4억 (돈을 어떻게 버는지와 거리가 있음) |
| 두 번째 미스터리 | 54살 간판에 5살 회사 | 34년 전 4,500만 원 부도 |
| 구성 예고 | 없음. 질문만 던지고 출발 | **"네 가지로 나눠서 볼게요. 첫째… 둘째… 셋째… 넷째…"** 목차를 다 공개 |
| 장 넘어가는 방식 | 장 끝 질문 → "아니요/반만요/네, 근데" | "두 번째, ○○입니다" 강의식 제목 낭독 |
| 진짜 답의 근거 | **장부**: 회사 이름(마담에이츠, 2021년 설립)·매출 296억·영업이익 98억 6천·직원 38명·매장 100곳, 채용 공고 | 장부 없음. **"업계 사람들 이야기를 모아 보면"** |
| 어려운 말 풀기 | 어음 = 카드값 빠지는 날 통장이 빈 것 | "여기서 잠깐 어음이 뭔지 짚고 갈게요" 교과서식 정의 |
| 한계 밝히기 | "회사 말이고", "확인이 안 됩니다", "회사가 그렇게 말한 적은 없어요" 반복 | 없음. 동기를 사실처럼 단정("할인으로 버티려다 무너진 경험이 있는 회사라 그래서…") |
| 근거 없는 색칠 | 적음 | "1985년 이상한 결정(160→28개)", "아시안게임 유니폼", "사장님보다 선생님" 등 출처 없는 일화. 히트작 기준으로는 160→28은 부도 9년 뒤 인터뷰 시점의 숫자라 **연도 배치가 틀렸을 가능성** |
| 화자 | "저도 처음엔 ~줄 알았어요" 착각 고백 | 화자 없음 |
| 중간 끊김 | 없음 | **중간에 "구독·좋아요 부탁" 1번 + "댓글로 알려 주세요" 3번** |
| 답 공개 방식 | 질문 사슬 속에 섞어서 | 마지막 장에 "비밀은 네 가지, 첫째·둘째·셋째·넷째" 목록으로 |
| 결말 | 한 줄 답 → 요약 → 숫자 콜백 → "시계를 보세요" 현실 행동 | 히트작 결말 문장을 거의 그대로 가져옴("손님들은 이미 낮에 다녀갔다") + 댓글·구독 부탁 |

## 2. 복제작이 실패한 이유 (대본에서 보이는 것)

1. **제목의 질문에 답하지 않았다.** "왜 안 망할까"인데 돈 숫자가 없다. 기부 4억은 "착한 회사"이지 "버는 회사"의 증거가 아니다
2. **목차를 미리 다 보여 줘서 궁금증을 스스로 껐다.** 듣는 시청자에게 "다음엔 뭐가 나올지"가 사라진다
3. **근거가 흐리다.** "업계 사람들 이야기" vs 장부·채용 공고. 생존 미스터리의 재미는 "어디서 증거를 찾았나"인데 그게 없다
4. **흐름을 스스로 끊었다.** 중간 구독 부탁, 댓글 부탁 세 번
5. **강의 말투.** "첫 번째 ○○입니다", "여기서 잠깐 짚고 갈게요"
6. **확인 안 된 이야기를 사실처럼.** 신뢰를 잃을 위험
7. **늦었다.** 같은 주제를 8일 늦게, 같은 자료로

## 3. 우리 대본 사전 점검표 (복제작 실수 걸러내기)

올리기 전에 대본을 이 표로 확인한다. 하나라도 걸리면 고친다.

- [ ] 제목의 질문에 정면으로 답하는 숫자가 훅에 있는가? (생존형이면 "얼마를 버나")
- [ ] 목차·"N가지로 나눠서"를 미리 공개하지 않았는가? (순위형은 "5위부터"만, 항목 이름은 감춘다)
- [ ] 장이 바뀔 때 제목을 읽지 않고 질문으로 넘어가는가?
- [ ] 핵심 답의 근거가 1차 자료(공시·신용평가·채용 공고·판결·법령·통계)인가? "업계에 따르면"으로만 끝나지 않는가?
- [ ] 어려운 말을 정의 대신 생활 비유로 풀었는가?
- [ ] 확인 안 된 부분을 그 자리에서 밝혔는가? 회사·사람의 동기를 단정하지 않았는가?
- [ ] 출처 없는 일화가 없는가?
- [ ] 중간에 구독·댓글 부탁이 없는가? (마지막 1번만)
- [ ] 답을 마지막에 목록으로 몰아 공개하지 않고 질문 사슬 속에 풀었는가?
- [ ] 결말이 우리 문장인가? (다른 채널 결말 문장 가져오기 금지)
- [ ] 같은 주제를 다른 채널이 최근 2주 안에 올리지 않았는가? (올렸으면 각도를 바꾸거나 주제 교체)

## 4. 히트작도 완벽하진 않다 (우리가 더 잘할 점)

- 장부 숫자를 "감사받았는지 확인 안 됨"이라고만 하고 끝냈다 → 우리는 숫자를 화면 하단 출처로 고정 표기
- 결말에 시청자 질문이 없다 → 우리는 현실 행동 한 줄 + 구체적 질문 하나(채널 공통 규칙)
