# 대본 분석 13: 대신TV "파이브가이즈, 블루보틀, 잘나가던 브랜드도 한국만 들어오면 망한다?" (지식343)

- 채널: 대신TV (증권사 브랜드 채널, 구독 26만)

## 1. 훅 (1분 9초)

1. **"2년 전 파이브가이즈 열풍 기억나세요?"** — 시청자의 최근 집단 기억으로 시작
2. 생생한 디테일 둘: 개장일 700명 넘게 줄, 당근마켓에 버거 두 개+감자튀김을 10만 원에 되파는 글
3. 반전: 지금은 기다리지 않고 배달로도 먹는다
4. 두 번째 사례 같은 리듬: 블루보틀 성수 1호점 새벽 5시 줄, 4~5시간 대기 → "그냥 비싼 카페 중 하나"
5. 질문 + 이름 붙이기: 유독 한국에만 오면 빛났다 사라진다 → **"글로벌 F&B의 무덤"**

## 3. 우리 T1에 주는 영향 (중요)

1. **F&B 각도는 이미 이 영상이 했다.** 우리 T1은 유통·검색·화장품·치킨을 섞은 업종 횡단이라 겹치지 않는다. 다만 파이브가이즈·블루보틀·쉐이크쉑을 주 항목으로 쓰면 재탕이 된다 → 결말의 "명단 밖" 한 줄로만
2. **첫 장면은 오래된 역사보다 최근 집단 기억이 강하다.** 이 영상은 "2년 전 기억나세요?"로 52만. 우리 T1 원안의 첫 장면(1996년 부천 까르푸)은 40대 이상만 기억한다 → **최근에 줄 섰던 장면(세포라 명동점 개장 줄 등)으로 열고, 까르푸·월마트는 "그 전에도 있었다"로 이어 붙이는 순서**를 검토
3. **2025년에 철수한 사례**가 이 영상 뒤에 더 생겼다: 슈퍼두퍼(3년 만에 철수), 스무디킹(한국 매장이 한때 세계 매출 1위였는데 완전 철수) → T1 항목 후보. 특히 **스무디킹**은 "한국 매장이 세계 1위였다 → 철수"라는 반전이 강하다 (숫자 확인 전)
4. 원인 정리 틀(가격 / 현지보다 비싼 가격 / 현지화 / 트렌드 속도 / 운영 주체)은 T1 결말 표와 자가진단에 참고
5. 우리가 더 잘할 점: 이 영상은 결말이 "~했으면 좋겠습니다"로 약하고 시청자 질문이 없다

## 4. 공통 패턴 누적 (히트작 4편 중 3편)

- 첫 문장이 시청자 자신의 경험·기억을 묻는다: "최근 스키장 가 본 적 있으신가요?"(정보의 신) / "최근 정장 사 입어 보신 적 있으십니까?"(파크랜드) / "2년 전 파이브가이즈 열풍 기억나세요?"(대신TV)
