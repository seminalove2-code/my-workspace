# 종합: 세상속사정(가칭) 대본·화면·썸네일 공식

- 확정일: 2026-10-22 (분석 01~06 종합. 한 달 운영 후 지표 보고 수정)
- 근거 파일: 01 동남아 / 02 시선(구조 참고) / 03 경제상담소 8편 비교 / 04 생존·부활형 / 05 영어권 7편 / 06 화면 분석

## 0. 한 줄 요약

**"모두가 겪는 변화"를 TOP N(또는 원인 N가지)으로 쪼개고, 항목마다 통념을 깨는 진짜 이유를 출처로 증명한 뒤, 시청자가 자기 삶에 대 볼 수 있는 자가진단으로 끝낸다.**

## 1. 구조 선택 (가장 중요)

| 유형 | 구조 | 길이 | 금지 |
|---|---|---|---|
| 몰락 (국내·해외) | TOP5~7 역순, 항목마다 다른 원인 | 18~26분 | 한 대상의 연대기 (딤채·테무 1만 회) |
| 단일 대상 몰락 (포에버21 등) | "무너진 이유 N가지"를 순위처럼 세기 (5위 이유 → 1위 이유) | 15~20분 | 창업자 출생부터 시작 |
| 생존 ("왜 안 망할까") | 원인 N가지 = 수익 구조 N가지, 또는 "손님 없는데 안 망하는 곳 TOP5" | 15~20분 | 단일 업종 4분짜리 |
| 부활·역주행 | 3막: 전성기 → 몰락(통념대로) → 부활 이유 3~4개(통념과 다름) | 15~20분 | "포기하지 않았다" 교훈 결말 |

- 순위 기준을 훅에서 한 줄로 밝힌다 ("방문객이 가장 많이 줄어든 순서", "매출 감소율 기준"). 기준이 주관이면 솔직히 말한다.

## 2. 첫 30초 템플릿 (6단)

| 단계 | 내용 | 길이 |
|---|---|---|
| ① 대비 장면 | 제목·썸네일 약속을 0초에 확인. 잘되는 쪽 vs 무너진 쪽 숫자 두 개, 또는 전성기 장면 → 지금 | ~8초 |
| ② 통념 부정 | "○○ 때문이라고 생각하시죠? 아닙니다. 진짜 이유는 따로 있었습니다" | ~5초 |
| ③ 미리보기 | 순위 안 가장 강한 장면 2~3개를 한 줄씩 (이름은 감춤) | ~8초 |
| ④ 두 개의 약속 | **숨은 법칙**("출발은 달라도 무너지는 모양은 똑같습니다") + **자가진단**("○○가 다음 차례인지 30초 만에 확인하는 법까지") | ~6초 |
| ⑤ 출발 | "7위부터 바로 갑니다" + 순위 기준 한 줄 | ~3초 |

- 1위만 살짝 예고하는 미끼 한 줄을 ③이나 ④에 넣어도 좋다.
- 모든 문장은 귀로만 들어도 이해되게. 화면 지시어("이 그래프") 금지.

## 3. 항목 8단 구조 (분석 01 확정 + 보강)

① 수상한 현재 장면 → ② 전성기 추억(**시청자 인생 이벤트**: 결혼·신혼여행·MT·입학·첫 월급) → ③ 지금 숫자(귀로 이해되는 표현) → ④ 흔한 용의자(통념) → ⑤ 반전 증거(공식 통계·관계자 증언·자연 실험·지도·과거 비교) → ⑥ 지갑 환산 → ⑦ 한 줄 통찰 → ⑧ 장면 회수 + 다음 항목 유형만 예고

- 항목마다 **사람 한 명**(사장님, 예비 신부, 30년 근무 직원)과 **대중문화 고리 하나**(드라마·광고·노래)
- 전환 문장: "○위는 ○○입니다" 반드시 말로. 다음 예고는 유형만("4위부터는 순서가 다릅니다")
- 중간(절반 지점)에 묶음 요약 한 줄: "여기까지 세 곳은 모두 ○○였습니다. 그런데 3위부터는…"

## 4. 결말 7단

1. 원인 2~3개로 압축 (표 화면 하나)
2. **반대 사례**: 같은 조건에서 살아난 곳 → 몰락 채널이 희망으로 끝남 (흥망 정체성)
3. **자가진단 체크리스트 3개**: "하나도 안 걸리면 안심 / 하나면 지켜볼 만 / 둘 이상이면 다음 차례"
4. 오프닝 장면 회수 (그 장면의 지금)
5. 찬반 질문 (양쪽 근거를 다 말해 준 뒤, 내 의견은 "제가 보기엔")
6. 개인 경험 댓글 ("다녀오신 곳 이름", "집에 아직 있는 그 물건")
7. 고정 마무리 문장 — 경제상담소("숫자 뒤에 가려진 진짜 사정")와 다르게 우리 것으로: **"잘나가던 곳이 왜 무너지고, 무너진 곳이 왜 다시 일어서는지. 세상 모든 흥망의 속사정, 계속 따라가 보겠습니다."** (채널명 확정 시 맞춰 수정)
- 채널 공통 규칙: 마지막은 구체적 시청자 질문으로 끝낸다 (5번).

## 5. 말투·분량

- 존댓말 대화체(~거든요, ~죠), 짧은 문장, 숫자 하나에 문장 하나, 30초마다 질문 하나
- 썸네일·제목은 강하게, 대본 톤은 차분한 다큐. 과장 금지, 출처로 설득
- 근거와 한계를 같이 말한다 ("한 곳의 사례라 전체는 아닙니다") — 시선 SEESUN 138만의 신뢰 장치
- **분량 기준: 분당 약 1,000자(공백 포함)** → 20분 대본 ≈ 2만 자, 항목 하나(3~4분) ≈ 3~4천 자

## 6. 화면 규칙 (분석 06)

- 기본: 실사 스톡 영상 + 직접 만든 인포그래픽. 실제 사진은 위키미디어 공용·국가기록원 등 + 화면 안 출처 라벨
- 숫자 화면 하단에 자료 출처 고정 표기 (우리 차별점)
- 고정 장치: 가운데 큰 숫자 / 통념 선택지 카드 → 뒤집기 / 순위판(? 칸) / 인용 카드 / 실제 지도 + 지명 라벨
- 배경 교체 문장 1~2개마다(6~10초), 첫 30초 배경 4개 이상, 0초 프레임부터 자막
- AI 이미지는 실사가 없는 장면에만, 사실처럼 보이면 유튜브 합성 콘텐츠 표시
- 쓰지 말 것: 방송 뉴스·다큐·영화 화면
- 화면 스타일은 조회수를 결정하지 않았다(경제상담소 3편 = 3가지 방식, 모두 200만+). 제작 시간은 대본과 썸네일에 먼저 쓴다.

## 7. 썸네일 규칙 (기존 분석 + 확정)

- 전/후 분할: 몰락 = 북적 → 텅 빔 / 부활 = 텅 빔 → 북적 / 생존 = 주변 텅 빈 거리에 이곳만 불 켜짐
- 한국인이 알아보는 소품(한글 간판, 가격표)
- 하단 두 줄 고정: 1줄 인용구(8~13자) / 2줄 대상 + 유형("○○의 몰락 TOP7", "○○의 부활", "○○은 왜 안 망할까")
- 경제상담소 색(검은 띠·흰 글씨·하늘색)과 다른 채널 색 — 채널 세팅 단계에서 결정
- 썸네일 약속 = 0초 첫 문장

## 7-1. 2026-10-23 보강 (분석 07·08: 김창숙부띠끄 히트작 vs 복제작)

- **"연대기 금지" → "질문 없는 연대기 금지"로 수정.** 단일 대상도 장마다 질문 → "아니요/반만요/네, 근데" → 새 질문 사슬이면 터진다(44.8만). 진짜 답(장부)은 절반 지점까지 미룬다
- **생존형 훅 = 미스터리 두 개 겹치기 + 답의 방향 한 줄 미리.** 핵심 숫자는 제목 질문에 정면으로 답하는 "얼마를 버나"
- **목차·"N가지로 나눠서" 미리 공개 금지.** 순위형도 "5위부터"만 말하고 항목 이름은 감춘다
- **숫자 콜백**: 같은 숫자를 처음·중간·끝에 다른 의미로 다시 부른다(4,500만 원 부도 ↔ 4,500만 원 첫날 매출)
- **생활 비유로 번역**, **"번역하면"**(공식 발언의 속뜻), **화자의 착각 고백**, **장면 상상 연출**("~입장이 돼 볼까요?")
- **뜻밖의 1차 자료**(채용 공고, 매물 광고, 판결문)가 생존형의 재미다
- **중간 구독·댓글 부탁 금지.** 마지막에 한 번
- **결말 = 한 줄 답 → 요약 → 숫자 콜백 → 현실 행동 한 줄 → 구체적 시청자 질문**
- 사전 점검표: `script-analysis/08-히트vs복제-김창숙부띠끄.md` 3항

## 7-2. 2026-10-23 보강 (분석 09: 파크랜드 104만)

- 김창숙(차분·질문 사슬·답 늦게)과 파크랜드(과장 다큐·답 1분 40초에 공개)는 스타일이 정반대인데 둘 다 터졌다 → **생존형의 성패는 대상 선택에서 거의 결정된다**
- 생존형 대상 거름망 4가지: ① 40~60대가 아는 간판 ② 모두 "요즘 누가 써?" ③ 그런데 매출·이익이 크다(공시로 확인) ④ 그 돈이 보이는 가게가 아닌 곳에서 나온다
- 답을 일찍 공개해도 된다. 단 "어떻게?"가 더 큰 궁금증일 때만
- 첫 장면은 시청자가 운전하며·걸으며 보는 시점, 광고 모델 이름 하나로 세대 기억 소환

## 7-3. 2026-10-23 보강 (분석 10·11: 스키장 흥망학회 vs 정보의 신)

- **대본만으로는 차별화가 안 된다.** 경제상담소 공식을 잘 쓰는 신생 채널이 이미 여럿이다
- **편마다 직접 찍은 현장 장면 하나 이상**(직원 촬영): 따라 할 수 없고, 신뢰가 오르고, 저작권 걱정이 없다. 정보의 신 65만 편의 가장 강한 장면은 "6인 리프트에 저 혼자"였다
- 첫 문장 후보: **"최근 ○○ 해 보신 적 있으신가요?"** (히트작 3편 중 2편)
- 결말 직전에 **"지금 어떻게 버티나 / 우리가 알면 이득인 것"** 한 덩어리
- 자동 자막의 숫자는 인용하지 않는다
