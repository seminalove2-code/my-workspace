→ 우리는 화면을 하나로 고정해 **채널 정체성**으로 삼되, "화면을 더 화려하게"에 제작비를 몰지 않는다. 대본·썸네일·첫 30초에 쓴다.

## 2. 세 편 공통

- 맨 위 가운데 작은 글씨로 **"이 영상은 AI를 기반으로 제작된 콘텐츠입니다"** 상시 표시 (동남아 편에서 확인)
- 배경 화면은 **문장 1~2개마다 한 번** 바뀐다 (첫 30초: 약 6~10초마다 배경 교체, 글자 요소는 2~4초마다 추가). 본문 20초 간격 캡처 30장이 모두 다른 장면 → 배경 교체가 20초보다 짧다. 자동 장면 감지는 디졸브 전환 때문에 측정이 안 됨
- 귀로 들은 숫자를 **가운데 큰 숫자 한 개**로 확인 ("하루 20편씩", "40%", "41원대 → 47원", "2,761명", "-18%")
- **선택지 카드**: 통념 장면에서 "흔한 생각: 물가가 비싸져서 / 일본·중국으로" 카드를 띄운 뒤 "천만에요" 빨간 상자로 뒤집음 → 통념 뒤집기를 화면으로도 보여 줌
- **순위판**: "한국에서 무너진 명품 TOP 7" 7칸 카드에 지난 항목은 이름, 남은 칸은 "?" → 지금 어디인지 알려 주고 남은 걸 궁금하게 함
- 순위 소개 카드: 큰 "6위" + 나라 라벨 + 대상 이름 + 한 줄 요약("값을 내려 주던 명품의 추락")
- 그래프는 단순: 막대 2개(2017년 637억 vs 2023년 1조 456억), 가격표 모양 카드(전년 → 올해, -18.3%)
- 인용 카드: 큰 따옴표 + 인용 문장 + 출처 작은 글씨("당시 지사장 인터뷰" 등)
- 지도: 실제 위성·항공 사진 위에 지명 라벨(보코산, 시엠립)
- 사진 속 사진: 큰 배경 위에 빨간 테두리 작은 사진(실제 장소)
- **첫 프레임(0초)**: 동남아 편은 사람 가득한 해변 + 두 줄 자막("한국인 여권만 들고 가면 / 섬 전체가 환호하던 시절") — 0초부터 글자가 있다

## 3. 첫 30초 화면 흐름 (동남아 편, 2초 간격)

| 시간 | 화면 | 글자 |
|---|---|---|
| 0~6초 | 사람 가득한 해변 (항공) | 전성기 문장 두 줄 |
| 6~12초 | 구름 하늘 + 비행기 | "비행기가 모자라 띄운 비행기 / **하루 20편씩**" + 한국어 호객 |
| 12~22초 | 텅 빈 선베드 | "그런데 지금 그 관광지에" → **"한국인이 없다"**(빨간 상자) → "1년 만에 발길 끊은 한국인 **40%**" |
| 22~30초 | 일본 시부야 횡단보도 (군중) | "다들 어떻게 생각하시죠?" 선택지 카드 2개 → **"천만에요"** → "진짜 이유는 따로 있었다" |

→ 30초 안에 **배경 4개, 핵심 숫자 2개, 반전 1번.** 장면이 문장의 뜻과 정확히 맞는다(전성기=북적, 반전=텅 빔, 통념=다른 나라 군중).

## 4. 우리 채널 화면 규칙 (제안)

1. **실사 스톡 + 직접 만든 인포그래픽**을 기본으로 한다 (동남아 편 방식). 이유: 우리 차별점이 "출처·신뢰"라서 AI 그림보다 실제 장소·실제 자료가 맞다.
2. 실제 사진은 위키미디어 공용·국가기록원 등에서 쓰고 **화면 안에 출처 라벨**(명품 편 방식). 숫자 화면에는 하단에 **자료 출처 고정 표기**(예: "출처: 한국관광공사 2025").
3. AI 이미지는 실사가 없는 장면(과거 재현, 상징 장면)에만. 사실처럼 보이면 유튜브 "변경·합성 콘텐츠" 표시.
4. 고정 화면 장치 4개: 가운데 큰 숫자 / 통념 선택지 카드 → 뒤집기 / 순위판(? 칸) / 인용 카드
5. 배경 교체는 문장 1~2개마다(약 6~10초), 첫 30초에는 배경 4개 이상.
6. 0초 프레임에 첫 문장 자막이 이미 떠 있어야 한다.
7. 색: 경제상담소(검은 띠 + 흰 글씨 + 하늘색/주황 강조, 노랑 띠)와 겹치지 않게 → 채널 색은 기획 5단계(채널 세팅)에서 확정.
