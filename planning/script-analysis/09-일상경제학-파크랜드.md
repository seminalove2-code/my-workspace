# 대본 분석 09: 일상경제학 "정장 아무도 안 입는데 왜 안 망할까? 파크랜드의 반전 스토리"

## 1. 김창숙(브랜드_B면)과 스타일이 정반대다

| 항목 | 김창숙 (44.8만, 13분) | 파크랜드 (104만, 9.5분) |
|---|---|---|
| 말투 | 차분한 대화체, 질문 핑퐁 | **과장된 다큐 내레이션**("피비린내 나는 초토화", "천문학적", "99%의 국민이 상상조차 못 한") |
| 진짜 답 공개 | 절반 지점(6:25)까지 미룸 | **1분 40초쯤 바로 공개**(매출 80%가 인도네시아 신발 공장) → 이후는 "어떻게 그렇게 됐나" |
| 한계 밝히기 | 반복해서 밝힘 | 없음. 단정형 |
| 출처 언급 | 대본·설명란 모두 자세함 | 대본에 거의 없음 |
| 화자 | "저도 처음엔" | 없음 |
| 결말 | 현실 행동 한 줄 | 교훈 한 문단("본질을 쥔 자만 살아남는다") + "지금까지 일상경제학이었습니다" |

→ **둘 다 터졌다. 그러니 터진 이유는 말투·답 공개 시점이 아니다.**

## 2. 두 히트작의 진짜 공통점 = 주제 선택 공식

1. **누구나 본 간판**: "지방 국도 사거리 목 좋은 곳에서 어김없이 마주치는 간판" / "시장 앞·역 앞에서 한 번쯤 본 가게"
2. **부모 세대의 추억**: 장동건·조인성 정장 광고, "부모님 손잡고 아버지 양복 사러" / "엄마 옷", 패러디 콩트 → 40~60대 시청자의 기억을 정확히 건드린다
3. **모두가 아는 쇠퇴**: "요즘 정장 누가 입어요" / "손님 한 명 안 보여요"
4. **그 쇠퇴와 정반대인 숫자**: 매출 8,000억 / 이익 100억 가까이
5. **보이는 가게는 빙산의 일각**: 매출 80%는 바다 건너 아디다스 공장 / 평일 낮 단골 + 5살 회사의 장부
6. **감정의 보상**: 한국 기술이 세계를 움직인다(부산 신발 수도의 기술자들, 아디다스가 놀란 공장) / 쓰러졌던 이름이 다시 일어섰다

→ 생존형의 성패는 **"익숙한 간판 × 모두 아는 쇠퇴 × 정반대 숫자 × 숨은 진짜 돈"** 네 가지가 다 있는 대상을 고르는 데서 거의 결정된다. 말투와 구성은 그다음이다.

## 4. 가져올 것 / 조심할 것

**가져올 것**
- 첫 장면을 **시청자가 운전하며·걸으며 보는 시점**으로 연다
- **광고 모델 이름 하나**(장동건·조인성)로 세대 기억을 한 번에 소환
- "최근에 ○○ 해 보신 적 있으십니까?" — 시청자 자신의 행동으로 쇠퇴를 확인시키는 질문
- 답을 일찍 줘도 "어떻게?"가 더 큰 궁금증이면 이탈하지 않는다 (대상의 반전 폭이 클 때)
- 숫자의 덩어리 비유: "전체의 20%에 불과한 껍데기", "진짜 심장은 바다 건너"
- 장면 회수: "국도변 늙은 마네킹 뒤편에서 5만 명의 노동자와 로봇이…"

**조심할 것 (우리 원칙과 충돌)**
- 과장 형용사("피비린내", "천문학적", "99%") — 우리는 쓰지 않는다. 숫자와 대비로만 놀라게
- **낡은 숫자**: 2026년 영상인데 핵심 숫자가 2020년 매출 → 우리는 최신 연도 숫자, 없으면 연도를 말로 밝힌다
- 확인 안 된 단정: "단 한 번의 부도 위기도 없이", 경영자의 속마음 대사("냄비 속 개구리처럼…") 같은 재구성을 사실처럼 → 우리는 "제가 보기엔", "~였을 겁니다"로 표시
- 자막상 "32년"은 2013년(아디다스 자동화 설비)으로 보인다. 원출처 대조 없이 인용 금지

## 5. 우리 시험 3편에 주는 시사점

- **T2 약국 편**: 업종 전체라 "익숙한 간판"과 "부모 세대 추억"은 있지만, 김창숙·파크랜드 같은 **한 브랜드의 반전**은 없다. 왱의 안경점(63만)·철물점(46만)처럼 업종형도 터진 전례는 있어 시험 가치는 충분하다. 다만 생존형이 1위로 나오면, 다음 편부터는 **"익숙한 브랜드 × 숨은 진짜 돈"** 대상을 우선한다
- 다음 생존형 후보를 고를 때의 거름망(위 2항 네 가지):
  - 40~60대가 아는 간판인가?
  - 모두가 "요즘 누가 써?"라고 하는가?
  - 그런데 매출·이익은 큰가? (공시·신용평가로 확인)
  - 그 돈이 우리가 아는 가게가 아닌 다른 곳에서 나오는가?
