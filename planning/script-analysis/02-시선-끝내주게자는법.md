- 영상: https://youtu.be/cvQesuhENPI (138만 회, 업로드 2일 만, 12분 12초 / 2026-10-21 기준)

- 자료: 사용자가 제공한 자동 자막 (오탈자 있음). 원문은 저장하지 않고 분석만 남김.
- 장르가 우리(흥망)와 다르다(자기계발·생활 과학). **구조와 기법만 가져온다.**

## 1. 채널 성적: 개설 2주 만에 터졌다

| 영상 | 길이 | 조회수 | 썸네일 |
|---|---|---|---|
| 하루가 26시간이 되면 벌어지는 일 (초기) | 9:28 | 1천 | 어두운 실사 배경 |
| 오늘도 아무것도 시작하지 못한 당신에게 (초기) | 4:25 | 2.2천 | 어두운 실사 배경 |
| 당신의 낭비된 젊음에 대하여 | 7:43 | 1.9만 | 크림색 배경 + 캐릭터 |
| 위험할 정도로 강력한 학습 방법 4가지 | 9:25 | 13만 | 크림색 배경 + 캐릭터 |

- 처음 2개는 어두운 실사 썸네일 + 감성 에세이형 제목 → 부진
- 이후 **크림색 배경 + 해바라기 캐릭터 + 짧은 검은 글씨**로 통일 → 상승
- **"○○하는 법"(누구나 매일 겪는 문제의 해결)**이 "당신에게" 류 감성 제목보다 훨씬 잘 됨
- 교훈: **신생 채널도 주제와 포장이 맞으면 2주 만에 터진다.** 초반 몇 편으로 빠르게 시험하고, 반응이 오는 쪽으로 즉시 통일했다.

## 2. 왜 잘 되나 (7가지)

1. **누구나, 매일 밤 겪는 문제**: 잠. 시청자 전체가 대상이고, 몇 년 지나도 유효하다 (오래 가는 주제)
2. **극단적 인물로 훅 + 0원 버전으로 번역**: "1년에 20억을 몸에 쓰는 브라이언 존슨이 240일 연속 수면 만점" → 매번 "그는 ○○까지 하지만, 우리는 ○○만 해도 돼요"
   - 암막 커튼·차단 안경 → 큰 조명 하나 끄기 / 단계별 매트리스 온도 조절 → 이불이 너무 두껍지 않은지 / 오전 11시 식사 종료 → 저녁을 조금 일찍, 가볍게
3. **영상 전체를 꿰는 비유 하나**: 잠 = 물속 (睡眠과 水面이 같은 소리 "수면")
   - 알람 = 깊은 물에서 끌어올림, 수면 관성 = 물안경에 낀 김, 휴대폰 = 튜브, 커피 = 구명조끼, 술 = 몸에 단 추, 수면 점수 집착 = 허우적거림
   - 귀로만 들어도 장면이 그려진다 ("틀어 놓고 듣는" 시청에 최적)
4. **통념 뒤집기**: "오래 자면 개운하다" → "8시간 자고도 멍한 건 잠이 모자라서가 아니라 깊은 물에서 끌려 나왔기 때문"
5. **끝까지 보게 만드는 보류(오픈 루프)**: 훅에서 "1순위 습관은 마지막에. 그런데 그대로 따라 하면 오히려 잠이 멀어질 수 있다"
   - 마지막 반전: 1순위는 "측정"인데, 점수 집착이 오히려 불면을 만든다(오소somnia)
6. **근거 + 한계를 같이 말한다**: 연구 기관·연도·인원까지 말하고, "한 사람의 기록이니 모두에게 같진 않다", "90분은 평균, 70~120분까지 다르다", "6시간만 자도 된다는 말은 아니다"
7. **마지막에 딱 하나만 시킨다**: "열 가지 다 할 필요 없다. 오늘은 '들어가는 알람' 하나만" + 댓글로 각자 시간 계산하게 함

## 3. 대본 구조

| 구간 | 내용 |
|---|---|
| 훅 (~1분) | 원하는 결과를 감각적으로 묘사 ("알람 직전에 눈이 떠지고, 양치하면서 오늘 할 일이 떠오르는 아침") → 극단적 인물 + 숫자 → 약속("돈 안 들고 오늘 밤 되는 것만, 연구로 확인한 것만") → 통념 뒤집기 → 오픈 루프(1순위의 반전) |
| 원리 설명 | 잠 = 물속 비유, 렘·90분 주기, 알람이 깊은 곳에서 울리면 수면 관성 (논문 근거) |
| 해법 1: 잘 떠오르기 | 90분 역산 (7시 기상 → 11시 15분 소등, 구체 계산) → 개인차 주의 → 일정한 기상 시간 → 아침 햇빛 |
| 해법 2: 잘 가라앉기 | 걱정 처리("알려줘서 고마워, 지금은 잘 시간이야") → 휴대폰(튜브) → 침실 규칙 → 빛 → 온도 → 커피(연구) → 술(메타분석) → 야식 |
| 반전 (약속 회수) | 1순위 = 측정. 그러나 점수 집착 연구 → "점수보다 아침의 내 몸을 믿어라" |
| 감성 이야기 | 수영장에서 바닥 짚기 하는 아이: 힘을 빼고 숨을 내쉬자 가라앉았다 (비유의 완성) |
| 행동 하나 + 댓글 | "들어가는 알람"을 맞춰라 → "몇 시에 가라앉으면 될지 댓글로 같이 계산해 봅시다" |

## 4. 대본 속 근거 확인 (주요 연구, 확인됨)

| 대본 내용 | 확인 |
|---|---|
| 2013년 헨리포드 병원, 성인 12명, 잠들기 6시간 전 카페인 → 수면 1시간 넘게 감소, 본인은 잘 못 느낌 | ✅ Drake 외 2013, Journal of Clinical Sleep Medicine |
| 2013년 런던 수면센터, 술과 수면 연구 27편 분석: 초반엔 깊은 잠, 후반엔 자주 깨고 렘 감소 | ✅ Ebrahim 외 2013, Alcoholism: Clinical and Experimental Research |
| 2017년 러시대학교 의료센터, 수면 측정기 점수 집착 환자 = 오소somnia | ✅ Baron 외 2017, Journal of Clinical Sleep Medicine |
| 미국수면의학회: 성인 하루 7시간 이상 권장 | ✅ |
| 브라이언 존슨 240일 연속 만점, 술로 깊은 잠 80% 감소 | ⚪ 본인 공개 주장 (대본도 "한 사람의 기록"이라고 밝힘) |

→ 대본이 **정확하고 한계까지 밝혀서** 신뢰를 얻는다.

## 5. 썸네일

- 크림색 단색 배경 + 손그림 느낌의 해바라기 캐릭터(채널 마스코트)
- 제목 그대로 2~5단어, 굵은 검은 글씨, 강조어만 빨강 ("4가지")
- 캐릭터 표정·소품 하나로 주제 표현 (자는 얼굴 + 침, 휴대폰과 앱 아이콘)
- 복잡한 정보 없이 **"한눈에 무슨 영상인지"**만 전달

## 6. 우리 흥망 채널에 가져올 것

1. **영상 전체를 꿰는 비유 하나**를 기획 단계에서 정한다 (예: 몰락 = 썰물, 부활 = 불씨). 귀로 듣는 시청자에게 장면을 만들어 준다
2. **훅에서 가장 큰 반전을 예고하고 마지막에 회수**한다 ("1위는 마지막에. 그런데 1위의 이유는 여러분 예상과 정반대입니다")
3. **극단적 사례 → 내 생활 버전**: 해외 브랜드 이야기 뒤에 "그럼 한국에선?", "내 지갑에선?"을 반드시 붙인다
4. **근거와 한계를 함께 말한다**: "이건 한 사람의 증언이라…", "통계는 여기까지만 말해 줍니다"
5. **썸네일 브랜드 통일**: 우리도 채널 고유의 배경색·캐릭터(또는 고정 요소)를 정해서 모든 썸네일에 반복한다
6. **초반 5편은 시험**: 시선은 처음 2편 이후 바로 스타일을 바꿨다. 우리도 첫 주 5편의 클릭률을 보고 2주 차에 포장을 확정한다
7. **끝은 행동 하나 + 참여형 댓글**: "여러분 동네에서 사라진 가게 이름을 남겨 주세요"처럼 각자의 경험을 꺼내게 한다
