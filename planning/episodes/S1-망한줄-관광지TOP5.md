# 기획서 S1: 망한 줄 알았는데 다시 살아나는 국내 관광지 TOP5

- 작성: 2026-10-23 / "망한 줄 알았는데" 시리즈 1회
- 사용자 방향: **통계에 치우치지 말고**, 예전에 확실히 망했던 곳이 대박은 아니라도 다시 살아나는 이야기로 잘 만든다
- 길이 약 15분, TOP5, 나레이션 TOP = "탑"
- 숫자 원칙: 통계는 "살아나고 있다"를 받쳐 주는 정도로만 쓰고, 출처를 화면 하단에 밝힌다. 지자체 자체 집계는 "○○군 발표"라고 말한다. ✅ = 공식 통계 확인 / 🟡 = 보도·지자체 발표 / ⚠ = 확인 필요

## 1. 숨은 법칙 (가설 — 항목 조사로 확인 후 확정)

**"다시 살린 건 옛날 손님이 아니라 새 손님이었다."** 다섯 곳 모두 망하기 전의 주 손님(신혼부부·수학여행·공장 노동자·조선소·중국 단체)이 사라진 자리를 다른 손님으로 채웠다.
→ 훅의 약속이자 결말의 자가진단 기준

## 2. 제목·썸네일

- 제목 1안: "다들 끝났다고 했는데" 망한 줄 알았던 국내 관광지가 다시 살아나는 진짜 이유 TOP5
- 제목 2안: "부곡하와이 문 닫은 그 동네, 요즘 예약이 안 됩니다" 망한 줄 알았는데 다시 살아나는 관광지 TOP5 (부곡 숙소 예약 표현은 확인 후)
- 썸네일: 전/후 분할. 왼쪽 = 폐업·텅 빈 옛 장면(흑백 톤, 실제 사진 라이선스 확인), 오른쪽 = 같은 곳의 지금 사람 있는 장면(컬러). 가운데 위로 꺾이는 화살표
- 문구: 1줄 "다들 끝났다고 했는데" / 2줄 "다시 살아난 관광지 TOP5"

## 3. 첫 30초 대본 초안

> 부곡하와이 기억나세요? 38년 만에 문을 닫던 날, 다들 부곡은 이제 끝났다고 했죠. 경주는 지진이 난 뒤 수학여행 버스가 끊겼고, 군산은 큰 공장 두 곳이 차례로 문을 닫으면서 도시가 멈춘 것 같았습니다. 그런데 요즘 그곳들에 사람이 다시 들어오고 있어요. 예전처럼 북적이는 곳도 있고, 이제 막 숨을 돌린 곳도 있습니다. 재밌는 건 다시 살린 손님이 예전 그 손님이 아니라는 거예요. 오늘은 망한 줄 알았는데 다시 살아나고 있는 국내 관광지 다섯 곳을, 조금 살아난 5위부터 따라가 보겠습니다. 끝에서는 우리 동네 관광지가 다시 살아날 수 있을지 가늠해 보는 세 가지도 짚어 드릴게요. 5위부터 갑니다.

(사실 확인: 부곡하와이 1979년 개장 → 2017년 5월 폐업 = 38년 ⚠ / 군산 현대중공업 조선소 2017년 가동 중단, 한국GM 군산공장 2018년 폐쇄 ⚠)

### 경제상담소 부곡 편과 겹침 — **크게 겹친다**

- 경제상담소 "옆 숙소는 전국 1위 찍었습니다… 부곡하와이만 문 닫은 진짜 이유"(2026-10-21 업로드, 18:37, 8,070회) 챕터: "꺼진 이름, 남은 물" / "같은 물을 제대로 쓴 쪽" / "그 자리는 다시 살아날 수 있을까"
- 설명란: **"같은 물을 쓰는 옆 온천 숙소들이 가족탕으로 다시 일어서기까지"**, "온천 방문객 전국 1위"
- → 우리 2위(부곡 = 가족탕으로 부활)와 핵심이 같다. 이틀 전 영상이라 그대로 쓰면 재탕
- **제안: 부곡을 빼고 명동으로 교체.** 명동은 "망했다" 기억이 아주 강하다(코로나 때 중대형 상가 공실률 38.4%, 2021년 1분기 한국부동산원 ✅). 지금: 명동 상권 매출 전년 대비 +33%(쿠시먼앤웨이크필드, 2026년 3월), 임대가격지수 +3.19%(한국부동산원 2026년 2분기) 🟡 — 최신 공실률 원자료 확인 필요. 새 손님 가설에도 맞음(중국 단체 쇼핑 → 개별 외국인)
- 부곡은 결말 한 줄("부곡하와이는 9년째 멈춰 있지만, 같은 물을 쓰는 옆 숙소는 살아났다")로만

## 7-2. 부곡 각도 변경 (사용자 결정 2026-10-23: 부곡 유지, 각도는 다르게)

- 경제상담소 편 = "부곡하와이는 왜 무너졌나 + 같은 물을 쓴 옆 숙소는 살아났다"(하와이 중심)
- **우리 편 = "목욕하는 방식이 바뀌었다: 남과 같이 씻는 대중탕의 시대가 끝나고, 우리 가족만 쓰는 탕이 부곡을 살렸다"**(손님·문화 중심)
  - 부곡하와이 이야기는 10초 배경으로만(폐업 연도, "다들 끝났다고 했다"). 하와이 몰락 원인·철거비·매각은 다루지 않는다
  - 대비 장면: 같은 시기 동네 목욕탕은 줄줄이 문을 닫았다
    - 코로나 3년간 전국 목욕탕 폐업 960곳(행안부 자료 인용, 매일신문) vs 1,375곳(비즈한국) — **숫자가 엇갈림**, localdata.go.kr "목욕장업" 원자료로 확인 후 하나만 쓴다 ⚠
    - 장기: 2003년 9,919곳 → 2025년 5,668곳(복지부 공중위생영업소 실태 인용 뉴스레터) — 원보고서 확인 전엔 쓰지 않는다 ⚠
  - 부곡 장면 (중앙일보 2020-12-03, 창녕): 코로나 때 대중탕 대신 가족탕 손님 증가(로얄관광호텔 총지배인), **키즈룸 10개는 주말 두 달 전 예약**, 11월 22일 하루 210팀 가족탕 대실, **30~40대 가족을 겨냥해 객실 두 개를 터 큰 가족탕을 만드는 게 5년 전부터 유행**, 2~3시간 대실도 가능 🟡
  - (중앙일보 2025-02-26) 객실 1,355개, 주말 예약률 90% 이상, "단체 관광 → 가족 단위" 🟡
  - 창녕군 발표: 폐업 이듬해 300만 아래 → 2025년 300만 돌파 🟡(군 자체 집계라고 밝힘)
- 한 줄 통찰 초안: "부곡을 살린 건 하와이가 아니라, 문 잠그고 우리 가족만 들어가는 작은 탕이었다"
- 새 손님 가설과 일치: 신혼부부·관광버스 단체 → 아이 있는 30~40대 가족
