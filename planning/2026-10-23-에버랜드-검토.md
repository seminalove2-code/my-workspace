# 에버랜드 주제 검토 ("사람은 엄청 많은데 적자?")

- 작성: 2026-10-23 / 요청: 사용자 ("사람들은 엄청 돈 많이 번다고 생각할 것")
- 원자료: DART 삼성물산 사업보고서(2025.12), 접수 2026-03-12, 접수번호 20260312000856 — "II-4 매출 및 수주상황", "연결재무제표 주석 29. 영업부문"

## 1. 먼저 알아야 할 것

- **에버랜드는 따로 공시하는 회사가 아니다.** 삼성물산 **리조트부문** 안에 있다. 리조트부문 = 에버랜드 + 캐리비안베이 + 골프장 + 조경 (사업보고서 표현: "파크시설, 골프, 조경")
- 그래서 **"에버랜드만의 이익·적자"는 공시로 확인할 수 없다.** 대본에서는 반드시 "에버랜드가 속한 리조트부문"이라고 말한다

## 2. 공시 숫자 (✅ DART 원문 확인)

| 항목 | 2024년 | 2025년 | 변화 |
|---|---|---|---|
| 리조트부문 매출(외부 고객) | 7,821억 원 | 7,231억 원 | -7.5% |
| 리조트부문 영업이익 | 586억 원 | **186억 원** | **-68%** |
| 감가상각비 | 659억 원 | 673억 원 | 이익의 약 3.6배 |
| 리조트부문 총자산 | 2조 4,906억 원 | 2조 4,447억 원 | |
| 삼성물산 전체 매출 중 비중 | | **1.8%** | |

- 영업이익률 2025년 약 2.6% → **"만 원어치 팔면 260원 남는다"**
- 자산 2조 4천억 원을 굴려서 1년에 186억 원 → 은행 예금 이자보다 낮은 수익률(약 0.8%) — 제가 계산한 값, 대본에서 "계산해 보면"으로 표시

## 3. "적자"인가? → 연간은 흑자, 분기는 적자

- **2025년 연간: 흑자 186억 원** (공시). "적자"라고 하면 틀린다
- **분기 적자는 있었다**(보도, 원자료 분기보고서로 확인 필요 🟡): 2025년 1분기 리조트부문 영업손실 120억 원(한파·우천, 식자재 원가) / 3분기 영업손실 18억 원 보도도 있음(다른 보도와 숫자가 엇갈려 확인 필요)
- 과거: 2020·2021년 적자(코로나), 2022년 565억 → 2023년 660억 → 2024년 586억 → 2025년 186억 (2022·2023은 보도 🟡)
- 입장객: 2024년 588만 2천 명, 2019년 660만 6천 명의 89% (보도 🟡). 2025년 입장객은 미확인
- 보도된 원인: 푸바오 반환(2024년 4월) 뒤 성장 정체, 폭염·한파·우천, 식자재 원가

## 5. 첫 편 적합성

**장점**
1. 전 국민이 아는 간판, 수요가 검증됨(161만·86.7만·39만)
2. 통념과 정반대 숫자: "줄 서서 타는 곳" vs "만 원 팔아 260원, 1년 새 이익 68% 감소"
3. 새 숫자: 2026년 3월 공시 — 기존 영상보다 최신
4. 지금 화제(JTBC 쇼츠 142만, 하루 전)
5. 숨은 구조가 있다: 매출의 대부분이 입장권만이 아님, 감가상각(놀이기구·동물·시설)이 이익의 3.6배, 골프·조경이 같은 부문에 섞여 있음

**위험**
1. **"적자"는 연간 기준으로 틀린 말** → 제목·썸네일에 "적자" 단정 금지. "1분기 적자", "이익 3분의 1 토막"처럼 사실 그대로
2. 에버랜드 단독 숫자가 없다 → 대본에서 매번 "리조트부문"이라고 밝혀야 한다
3. **정보의 신 86.7만 편과 겹칠 수 있다** → 그 대본을 확인하고 각도를 다르게 잡아야 한다
4. 삼성 관련이라 근거 없는 지배구조·오너 이야기로 번지지 않게

**판단**: 첫 편 후보로 **강하다.** 다만 (1) 정보의 신 편 대본 확인, (2) 2025년 분기 실적 원자료 확인을 먼저 한다.
유형은 "몰락·역설"(사람은 많은데 남는 게 없다)이라, 시험 3편 중 **T1 몰락 자리를 에버랜드로 바꾸는 안**이 자연스럽다.
